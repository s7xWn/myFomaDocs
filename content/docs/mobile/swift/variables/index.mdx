---
title: Переменные
---

:::important
Swift — статически типизированный язык.
:::

**Переменные** — это именованные контейнеры для хранения данных.

## Правила именования переменных

Для имени переменной можно использовать следующие символы:

- буквы латинского алфавита;
- цифры **после первой позиции**;
- символы `_`;
- Unicode-символы, включая некоторые символы других языков

## Регистр символов

В Swift регистр символов имеет значение. Это означает, что заглавные и строчные буквы считаются разными.

```swift
var name = "Alex"
var Name = "John"
var NAME = "Bob"
```

## Указание типа

Swift умеет сам определять тип:

```swift
var name = "Alex"    // String
var age = 25         // Int
var height = 1.82    // Double
var isStudent = true // Bool
```

Но тип можно указать самостоятельно:

```swift
var name: String = "Alex"
var age: Int = 25
var height: Double = 1.82
var isStudent: Bool = true
```
