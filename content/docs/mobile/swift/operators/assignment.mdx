---
title: Операторы присваивания
---

| Оператор | Пример   | Эквивалент  |
| -------- | -------- | ----------- |
| `=`      | `x = 5`  | присвоить   |
| `+=`     | `x += 2` | `x = x + 2` |
| `-=`     | `x -= 2` | `x = x - 2` |
| `*=`     | `x *= 2` | `x = x * 2` |
| `/=`     | `x /= 2` | `x = x / 2` |
| `%=`     | `x %= 2` | `x = x % 2` |

## Побитовые операторы присваивания

| Оператор | Пример    | Эквивалент   |
| -------- | --------- | ------------ |
| `&=`     | `x &= y`  | `x = x & y`  |
| `\|=`    | `x \|= y` | `x = x \| y` |
| `^=`     | `x ^= y`  | `x = x ^ y`  |
| `<<=`    | `x <<= 2` | `x = x << 2` |
| `>>=`    | `x >>= 2` | `x = x >> 2` |
