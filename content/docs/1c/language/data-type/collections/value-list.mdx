`СписокЗначений` — это специальная коллекция, которая хранит набор значений, обычно в виде пар: `Значение` + `Представление`

`СписокЗначений` — это не таблица и не массив. Он особенно удобен, когда нужно сделать набор вариантов для выбора, где внутреннее значение может отличаться от текста, который видит пользователь.

```
ПеременнаяСписок = Новый СписокЗначений;
```

```
ПеременнаяСписок.Добавить("Красный", "Красный цвет");
ПеременнаяСписок.Добавить("Зеленый", "Зеленый цвет",,Картинка);
ПеременнаяСписок.Добавить("Синий", "Синий цвет");
```

<hr />

## Получение значения

```
ПеременнаяСписок[Индекс];
```

```
ПеременнаяСписок.Получить(Индекс);
```

<hr />

## Методы СписокЗначений

| Метод                          | Что делает                              | Пример                                                             |
| ------------------------------ | --------------------------------------- | ------------------------------------------------------------------ |
| `Добавить()`                   | Добавляет новый элемент в список        | `ПеременнаяСписок.Добавить(1, "Низкий");`                          |
| `Вставить()`                   | Вставляет элемент в указанную позицию   | `ПеременнаяСписок.Вставить(0, 1, "Низкий");`                       |
| `Получить()`                   | Возвращает элемент по индексу           | `Элемент = ПеременнаяСписок.Получить(0);`                          |
| `Удалить()`                    | Удаляет элемент                         | `ПеременнаяСписок.Удалить(0);`                                     |
| `Очистить()`                   | Удаляет все элементы списка             | `ПеременнаяСписок.Очистить();`                                     |
| `Количество()`                 | Возвращает количество элементов         | `Количество = ПеременнаяСписок.Количество();`                      |
| `Индекс()`                     | Находит индекс указанного элемента      | `Индекс = ПеременнаяСписок.Индекс(Элемент);`                       |
| `НайтиПоЗначению()`            | Ищет элемент по его значению            | `Элемент = ПеременнаяСписок.НайтиПоЗначению(1);`                   |
| `НайтиПоИдентификатору()`      | Ищет элемент по идентификатору          | `Элемент = ПеременнаяСписок.НайтиПоИдентификатору(Идентификатор);` |
| `СортироватьПоПредставлению()` | Сортирует список по представлению       | `ПеременнаяСписок.СортироватьПоПредставлению();`                   |
| `ЗагрузитьЗначения()`          | Загружает значения из массива/коллекции | `ПеременнаяСписок.ЗагрузитьЗначения(Массив);`                      |
| `ВыгрузитьЗначения()`          | Выгружает значения списка в массив      | `Массив = ПеременнаяСписок.ВыгрузитьЗначения();`                   |

<hr />

### `ВыбратьЭлемент()`

Метод позволяет пользователю выбрать один элемент списка.

```

ВыбранныйЭлемент = Список.ВыбратьЭлемент("Выберите приоритет");
```

После выбора переменная `ВыбранныйЭлемент` будет содержать **элемент списка**, а не непосредственно его значение.

#### Почему проверяем `Неопределено`?

```
Если ВыбранныйЭлемент <> Неопределено Тогда
    // Работаем с выбором
КонецЕсли;
```

<hr />

### `ОтметитьЭлементы()`

Метод позволяет пользователю отметить один или несколько элементов списка.

У каждого элемента `СписокЗначений` есть свойство: `Элемент.Пометка` (Оно содержит `Истина` или `Ложь`)

<hr />

## Свойства элементов

| Свойство        | Назначение                            |
| --------------- | ------------------------------------- |
| `Значение`      | Само хранимое значение                |
| `Представление` | Текстовое представление элемента      |
| `Пометка`       | Позволяет установить пометку элемента |
| `Картинка`      | Картинка, связанная с элементом       |
| `Идентификатор` | Уникальный идентификатор элемента     |
