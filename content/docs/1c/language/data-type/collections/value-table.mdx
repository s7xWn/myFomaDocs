---
title: ТаблицаЗначений
---

`ТаблицаЗначений` — это встроенная структура данных, похожая на обычную таблицу: она состоит из строк и колонок и используется для временного хранения и обработки данных в памяти.

Проще говоря: это как Excel-таблица, только внутри программы 1С.

<Callout>На сервере</Callout>

```
ПеременнаяТаблица = Новый ТаблицаЗначений;
```

<hr />

## Методы

| Метод                                             | Что делает                               | Пример                                           |
| ------------------------------------------------- | ---------------------------------------- | ------------------------------------------------ |
| `Добавить()`                                      | Добавляет новую строку                   | `Строка = Таблица.Добавить();`                   |
| `Удалить()`                                       | Удаляет строку                           | `Таблица.Удалить(Строка);`                       |
| `Очистить()`                                      | Удаляет все строки                       | `Таблица.Очистить();`                            |
| `Количество()`                                    | Возвращает количество строк              | `Таблица.Количество()`                           |
| `Индекс()`                                        | Возвращает индекс строки                 | `Таблица.Индекс(Строка)`                         |
| `Сортировать("ИмяКолонки Возр/Убыв")`             | Сортирует строки                         | `Таблица.Сортировать("Цена Убыв");`              |
| `Найти(Значение, Колонка)`                        | Ищет значение в указанной колонке        | `Таблица.Найти("Хлеб", "Товар")`                 |
| `НайтиСтроки()`                                   | Ищет строки по нескольким условиям       | `Таблица.НайтиСтроки(Отбор);`                    |
| `Скопировать(Строки, Колонки)`                    | Создаёт копию таблицы                    | `Копия = Таблица.Скопировать();`                 |
| `СкопироватьКолонки()`                            | Копирует структуру/колонки               | `Копия = Таблица.СкопироватьКолонки();`          |
| `СкопироватьСтроки()`                             | Копирует выбранные строки                | `Копия = Таблица.СкопироватьСтроки(Строки);`     |
| `ВыгрузитьКолонку()`                              | Получает значения колонки                | `Массив = Таблица.ВыгрузитьКолонку("Товар");`    |
| `ЗагрузитьКолонку()`                              | Загружает значения в колонку             | `Таблица.ЗагрузитьКолонку(Массив, "Цена");`      |
| `Свернуть("КолонкиГруппировки", "КолонкиИтогов")` | Группирует строки и вычисляет итоги      | `Таблица.Свернуть("Товар", "Количество,Сумма");` |
| `Итоги("ИмяКолонки")`                             | Вычисляет итог по колонке                | `Таблица.Итоги("Сумма");`                        |
| `ЗаполнитьЗначения()`                             | Заполняет указанное поле одним значением | `Таблица.ЗаполнитьЗначения(0, "Количество");`    |
| `ВыбратьСтроку()`                                 | Позволяет пользователю выбрать строку    | `Таблица.ВыбратьСтроку()`                        |

### `НайтиСтроки()`

```
ПараметрыОтбора = Новый Структура("Название Колонки", "Значение");
Переменная = ПеременнаяТаблица.НайтиСтроки(ПараметрыОтбора);
```

<hr />

### `Свернуть("КолонкиГруппировки", "КолонкиИтогов");`

— это метод для группировки строк и суммирования/агрегации данных.

<details>
  <summary>Пример</summary>

```
Таблица.Свернуть("Товар", "Количество,Сумма");
```

Здесь:

- `"Товар"` — по чему группируем;
- `"Количество,Сумма"` — что суммируем.

</details>

## Колонки

```
ПеременнаяТаблица.Колонки
```

```
ПеременнаяТаблица.Колонки.Добавить("Имя", Тип, Заголовок, Ширина)
```

- Имя -> необязательно
- Тип -> необязательно
- Заголовок -> необязательно
- Ширина -> необязательно

### Типизация

```
КвалификаторыЧисла = Новый КвалификаторыЧисла(10,2);
ОписаниеТипаЧисло = Новый ОписаниеТипов("Число",,,КвалификаторыЧисла);

КвалификаторыСтроки = Новый КвалификаторыСтроки(100);
ОписаниеТипаСтрока = Новый ОписаниеТипов("Строка",,,,КвалификаторыСтроки);


ПеременнаяТаблица.Колонки.Добавить("Имя", ОписаниеТипаЧисло);
ПеременнаяТаблица.Колонки.Добавить("Имя", ОписаниеТипаСтрока);
```

## Индексы

`Индексы` — это механизм индексации данных таблицы для ускорения поиска.

У `ТаблицаЗначений` можно создать индекс по одной или нескольким колонкам. После этого поиск по этим колонкам может выполняться эффективнее.

<details>
  <summary>Пример</summary>

Например, есть таблица:

| Товар  | Склад     | Количество |
| ------ | --------- | ---------: |
| Хлеб   | Основной  |         10 |
| Молоко | Основной  |         20 |
| Хлеб   | Резервный |          5 |

Можно создать индекс:

```
Таблица.Индексы.Добавить("Товар");
```

Теперь у таблицы есть индекс по колонке `Товар`.

</details>

### Зачем это нужно?

Представь `ТаблицаЗначений` на **100 000 строк** и тебе постоянно нужно искать:

```
Таблица.НайтиСтроки(
    Новый Структура("Товар", Товар)
);
```

Индекс по `Товар` позволяет оптимизировать такие операции поиска.

<hr />

### Индекс по нескольким колонкам

Можно индексировать комбинацию колонок:

```
Таблица.Индексы.Добавить("Товар,Склад");
```

Это полезно, например, когда ищешь конкретный товар на конкретном складе.

<hr />

### Методы

| Метод          | Назначение                   |
| -------------- | ---------------------------- |
| `Добавить()`   | Создать индекс               |
| `Удалить()`    | Удалить индекс               |
| `Количество()` | Получить количество индексов |
| `Очистить()`   | Удалить все индексы          |
| `Получить()`   | Получить индекс              |
