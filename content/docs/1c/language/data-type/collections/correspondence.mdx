---
title: Соответствие
---

В 1С **«соответствие»** — это способ связать одно значение с другим, то есть хранить пары вида: `Ключ` → `Значение`

|        | **Структура**     | **Соответствие**                 |
| ------ | ----------------- | -------------------------------- |
| Хранит | Ключ → значение   | Ключ → значение                  |
| Ключ   | **Только строка** | Практически любой подходящий тип |
| Доступ | По имени свойства | По ключу                         |
| Пример | `"Имя" → "Иван"`  | `СсылкаНаТовар → 100`            |

```
ПеременнаяСоответствие = Новый Соответствие;
```

```
ПеременнаяСоответствие.Вставить("Иванов", 100);
ПеременнаяСоответствие.Вставить(12, 7700);

Значение = ПеременнаяСоответствие.Получить("Иванов");
```

<hr />

## Получение значения

```
ПеременнаяСоответствие[Ключ1];
```

```
ПеременнаяСоответствие.Получить(Ключ1);
```

<hr />

## Методы соответствия

| Метод            | Что делает                         | Пример                                       |
| ---------------- | ---------------------------------- | -------------------------------------------- |
| `Вставить()`     | Добавляет пару **Ключ → Значение** | `ПеременнаяСоответствие.Вставить("А", 100);` |
| `Получить()`     | Возвращает значение по ключу       | `ПеременнаяСоответствие.Получить("А");`      |
| `СодержитКлюч()` | Проверяет, есть ли такой ключ      | `ПеременнаяСоответствие.СодержитКлюч("А");`  |
| `Удалить()`      | Удаляет элемент по ключу           | `ПеременнаяСоответствие.Удалить("А");`       |
| `Очистить()`     | Удаляет все элементы               | `ПеременнаяСоответствие.Очистить();`         |
| `Количество()`   | Возвращает количество элементов    | `ПеременнаяСоответствие.Количество();`       |
| `Ключи()`        | Возвращает коллекцию всех ключей   | `ПеременнаяСоответствие.Ключи();`            |
| `Значения()`     | Возвращает коллекцию всех значений | `ПеременнаяСоответствие.Значения();`         |

<hr />

### `Получить()`

- При успешном выполнении вернёт **значение**.
- Иначе вернёт `Неопределенно`
