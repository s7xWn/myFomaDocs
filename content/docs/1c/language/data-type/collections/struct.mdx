---
title: Структура
---

В 1С **Структура** — это специальный объект, который хранит данные в формате «ключ → значение».

```
ПеременнаяСтруктура = Новый Структура;
```

```
ПеременнаяСтруктура = Новый Структура("Ключ1,Ключ2,Ключ3...");
```

```
ПеременнаяСтруктура = Новый Структура("Ключ1,Ключ2,Ключ3...", "ЗначениеДляКлюча1", "ЗначениеДляКлюча2", ...);
```

```
ПеременнаяСтруктура.Вставить("Имя", "Иван");
ПеременнаяСтруктура.Вставить("Возраст", 25);
ПеременнаяСтруктура.Вставить("Город", "Москва");
```

<hr />

## Получение значения

```
ПеременнаяСтруктура["Ключ1"];
```

```
ПеременнаяСтруктура.Ключ1;
```

```
Переменная = Неопределенно;
ПеременнаяСтруктура.Свойство("ФИО", Переменная)
```

<hr />

## Методы структуры

| Метод          | Что делает                                               | Пример                                               |
| -------------- | -------------------------------------------------------- | ---------------------------------------------------- |
| `Количество()` | Возвращает количество элементов                          | `Количество = Структура.Количество();`               |
| `Вставить()`   | Добавляет новый ключ и значение                          | `Структура.Вставить("Имя", "Иван");`                 |
| `Удалить()`    | Удаляет элемент структуры                                | `Структура.Удалить("Имя");`                          |
| `Получить()`   | Получает значение по ключу                               | `Значение = Структура.Получить("Имя");`              |
| `Свойство()`   | Получает значение свойства и сообщает, существует ли оно | `Если Структура.Свойство("Имя", Значение) Тогда ...` |
| `Очистить()`   | Удаляет все элементы структуры                           | `Структура.Очистить();`                              |
| `Ключи()`      | Возвращает коллекцию ключей структуры                    | `Ключи = Структура.Ключи();`                         |
| `Значения()`   | Возвращает коллекцию значений                            | `Значения = Структура.Значения();`                   |

<hr />

## Ошибки

### Задано неправильное имя атрибута структуры

Выдёт при попытке добавления значении к ключу которого нет в структуре или неправильное добавление элемента в структуру.
