title: "Коллекции"

В 1С под коллекциями понимают объекты, которые позволяют хранить набор значений. Условно их делят на универсальные и специализированные.

| Универсальные                                            | Специализированные                                      |
| -------------------------------------------------------- | ------------------------------------------------------- |
| Создаются программистом для своих задач                  | Предоставляются платформой/объектами 1С                 |
| Не привязаны к конкретному объекту метаданных            | Связаны с конкретным объектом                           |
| `Массив`, `Структура`, `Соответствие`, `ТаблицаЗначений` | `ТабличнаяЧасть`, коллекции объектов метаданных и т. п. |
| Можно использовать практически где угодно                | Используются для конкретной задачи                      |

<hr />

## Универсальные коллекции

Это коллекции, которые можно использовать для хранения разных типов данных и которые не привязаны к конкретному объекту конфигурации.

Основные примеры:

- [Массив](./array.mdx) — последовательность элементов.
- [СписокЗначений](./value-list.mdx) — список значений с дополнительными представлениями и картинками.
- [ТаблицаЗначений](./value-table.mdx) — таблица со строками и колонками.
- [Структура](./struct.mdx) — набор пар «ключ → значение».
- [Соответствие](./correspondence.mdx) — набор пар «ключ → значение», где ключами могут быть разные типы значений.

<hr />

## Специализированные коллекции

Это коллекции, которые предназначены для работы с конкретными объектами или механизмами 1С.

- `ТабличнаяЧасть` — коллекция строк табличной части документа или справочника.
- `РезультатЗапроса` и его выборка — работа с результатами запросов.
- `КоллекцияСтрок` некоторых объектов 1С.
- Коллекции объектов метаданных, например `Метаданные.Справочники`.
