title: Массив
---

Массив в 1С — это коллекция элементов, расположенных в определённом порядке. Проще говоря, это список значений, с которыми можно работать по очереди.

<Callout>

Индексация начинается с 0

</Callout>

```
ПеременнаяМассив = Новый Массив;
```

Или задать многомерность:

```
ПеременнаяМассив = Новый Массив(2,2, ...);
```

<Callout>

В 1С **массив** может содержать **разные типы данных** одновременно

```
ПеременнаяМассив.Добавить("Иван");
ПеременнаяМассив.Добавить(25);
ПеременнаяМассив.Добавить(Истина);
```

</Callout>

<hr />

## Методы массива

| Метод           | Что делает                           | Пример                                 |
| --------------- | ------------------------------------ | -------------------------------------- |
| `Количество()`  | Возвращает количество элементов      | `ПеременнаяМассив.Количество();`       |
| `ВГраница()`    | Возвращает количество элементов - 1  | `ПеременнаяМассив.ВГраница()`          |
| `Добавить()`    | Добавляет элемент в конец массива    | `ПеременнаяМассив.Добавить(10);`       |
| `Вставить()`    | Вставляет элемент по индексу         | `ПеременнаяМассив.Вставить(0, 10);`    |
| `Удалить()`     | Удаляет элемент по индексу           | `ПеременнаяМассив.Удалить(0);`         |
| `Получить()`    | Получает элемент по индексу          | `ПеременнаяМассив.Получить(0);`        |
| `Установить()`  | Заменяет элемент по индексу          | `ПеременнаяМассив.Установить(0, 100);` |
| `Найти()`       | Ищет элемент и возвращает его индекс | `ПеременнаяМассив.Найти(10);`          |
| `Очистить()`    | Удаляет все элементы                 | `ПеременнаяМассив.Очистить();`         |
| `Сортировать()` | Сортирует элементы массива           | `ПеременнаяМассив.Сортировать();`      |
| `Сдвинуть()`    | Сдвигает элементы массива            | `ПеременнаяМассив.Сдвинуть(0, 1);`     |
| `Индекс()`      | Получает индекс элемента             | `ПеременнаяМассив.Индекс(Элемент);`    |

<hr />

### `Найти()`

- При успешном выполнении вернёт **индекс элемента**.
- Иначе вернёт `Неопределенно`

<hr />

## Ошибки

### Индекс находится за границами массива

Выдёт при попытке обращения к индексу которого нет в массиве.

### Значение индекса выходит за границы диапазона

Выдаёт при попытке удаления элемента с индексом, которого нет.
