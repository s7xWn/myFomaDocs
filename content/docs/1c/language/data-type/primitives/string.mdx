## Специальные символы

> Когда компьютеры только появились, главным способом взаимодействия с компьютером был текст. Неформатированный текст сложно воспринимать, поэтому появились специальные символы, которые обозначали различные операции, которые нужно сделать с текстом при выводе на экран.

| Последовательность / способ | Значение                                                 |
| --------------------------- | -------------------------------------------------------- |
| `""Текст""`                 | `""` -> ", "Текст"                                       |
| `Символы.ПС`                | Перевод строки                                           |
| `Символы.Таб`               | Табуляция                                                |
| `Символы.ВК`                | Возврат каретки                                          |
| `Символы.ВТ`                | Вертикальная табуляция                                   |
| `Символы.ПФ`                | Перевод страницы (Form Feed)                             |
| `Символы.НПП`               | Неразрывный пробел                                       |
| `Символы.БС`                | Backspace                                                |
| `Символы.НУЛ`               | Нулевой символ (NULL)                                    |
| `Символы.РазделительСтрок`  | Разделитель строк                                        |
| `Символ(код)`               | Получение символа по числовому коду                      |
| `СтрЗаменить()`             | Замена специальных символов/последовательностей в строке |
