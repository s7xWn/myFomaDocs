---
title: Если .. Иначе
---

Для сравнения используются [логические операторы](../operators/logical.mdx) и [операторы сравнения](../operators/compare.mdx).

```
Если <Условие> Тогда
  ...
Иначе
  ...
КонецЕсли;
```

<Callout>`<Условие>` нужно явно получить `Булево`</Callout>

## `Если`

— это условный оператор. Он выполняет код только тогда, когда условие истинно (`Истина`).

```
Если <Условие> Тогда
  ...
```

<hr />

## `Иначе`

— позволяет выполнить другой код, если условие ложно (`Ложь`).

```
Если <Условие> Тогда
  ...
Иначе
  ...
КонецЕсли;
```

<hr />

## `ИначеЕсли` - цепочка проверок

Если вариантов больше двух, добавляют `ИначеЕсли`. Проверки идут сверху вниз, выполняется первый подходящий блок.

```
Если <Условие> Тогда
  ...
ИначеЕсли
  ...
Иначе
  ...
КонецЕсли;
```
