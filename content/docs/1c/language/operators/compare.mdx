---
title: Операторы сравнения
---

Операторы сравнения возвращают логическое значение `Истина` или `Ложь`. Они используются в условиях (`Если`), циклах, фильтрации массивов и в любой логике, где нужно сравнить значения.

| Оператор | Описание         | Пример в 1С | Результат |
| -------- | ---------------- | ----------- | --------- |
| `=`      | равно            | `5 = 5`     | `Истина`  |
| `<>`     | не равно         | `5 <> 3`    | `Истина`  |
| `>`      | больше           | `5 > 3`     | `Истина`  |
| `<`      | меньше           | `3 < 5`     | `Истина`  |
| `>=`     | больше или равно | `5 >= 5`    | `Истина`  |
| `<=`     | меньше или равно | `3 <= 5`    | `Истина`  |
