---
title: Пока <Условие> Цикл
---

— это цикл, который выполняет код до тех пор, пока условие истинно.

```
Пока <Условие> Цикл

	// действия, которые повторяются

КонецЦикла;
```

`Пока <Условие> Цикл` удобно применять, когда заранее неизвестно, сколько раз должен выполниться цикл. Например:

- ждать корректный ввод пользователя;
- обрабатывать данные до определенного условия;
- выполнять повторяющиеся действия, пока не достигнута нужная цель.

Если же количество повторений известно заранее (например, нужно выполнить код 10 раз), чаще используют цикл со счетчиком.

<hr />

## Бесконечный цикл

```
Пока 1=1 Цикл

	// действия, которые повторяются

КонецЦикла;
```
