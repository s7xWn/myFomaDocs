---
title: Процедура и функция
---

- Процедура — выполняет действие, но ничего не возвращает.
- Функция — выполняет действие и возвращает значение, которое можно использовать дальше.

## `Процедура`

Процедура — выполняет действие, но ничего не возвращает.

Создание процедуры:

```
Процедура Название(Параметр1, Параметр2)
    ...
КонецПроцедуры
```

Вызов процедуры:

```
Название(Переменная1, Переменная2);
```

<hr />

## `Фунцкия`

Функция — выполняет действие и возвращает значение, которое можно использовать дальше.

Создание функции:

```
Функция Название(Параметр1, Параметр2)
    ...
    Возврат ПеременаяДляВозврата;
КонецФункции
```

Вызов функции:

```
Название(Переменная1, Переменная2);
```
