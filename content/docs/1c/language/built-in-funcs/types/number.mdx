## Простые преобразования

| Функция                                    | Назначение                                                        | Пример                                         |  Результат |
| ------------------------------------------ | ----------------------------------------------------------------- | ---------------------------------------------- | ---------: |
| `Число(Значение)`                          | Преобразует значение в число                                      | `Число("123.45")`                              |   `123.45` |
| `Цел(Число)`                               | Возвращает целую часть числа                                      | `Цел(12.75)`                                   |       `12` |
| `Окр(Число, Разрядность)`                  | Округляет число до указанной разрядности                          | `Окр(12.756, 2)`                               |    `12.76` |
| `Окр(Число, Разрядность, РежимОкругления)` | Округляет с заданным режимом                                      | `Окр(12.755, 2, РежимОкругления.ДоБлижайшего)` |    `12.76` |
| `Формат(Число, ФорматнаяСтрока)`           | Представляет число в заданном формате                             | `Формат(1234.5, "ЧДЦ=2")`                      | `1 234,50` |
| `Мин(Число1, Число2, ...)`                 | Возвращает минимальное значение                                   | `Мин(10, 5, 8)`                                |        `5` |
| `Макс(Число1, Число2, ...)`                | Возвращает максимальное значение                                  | `Макс(10, 5, 8)`                               |       `10` |
| `Модуль(Число)`                            | Возвращает абсолютное значение числа                              | `Модуль(-25)`                                  |       `25` |
| `СтрЗаменить(...)`                         | Может использоваться при обработке строкового представления числа | `СтрЗаменить("12,5", ",", ".")`                |   `"12.5"` |

## Математические функции

| Функция               | Назначение           | Пример      |                   Результат |
| --------------------- | -------------------- | ----------- | --------------------------: |
| `Sqrt(Число)`         | Квадратный корень    | `Sqrt(25)`  |                         `5` |
| `Pow(Число, Степень)` | Возведение в степень | `Pow(2, 3)` |                         `8` |
| `Sin(Число)`          | Синус                | `Sin(0)`    |                         `0` |
| `Cos(Число)`          | Косинус              | `Cos(0)`    |                         `1` |
| `Tan(Число)`          | Тангенс              | `Tan(0)`    |                         `0` |
| `ASin(Число)`         | Арксинус             | `ASin(0)`   |                         `0` |
| `ACos(Число)`         | Арккосинус           | `ACos(1)`   |                         `0` |
| `ATan(Число)`         | Арктангенс           | `ATan(0)`   |                         `0` |
| `Log(Число)`          | Логарифм             | `Log(10)`   | зависит от версии/контекста |
| `Exp(Число)`          | Экспонента           | `Exp(1)`    |                 ≈ `2.71828` |
