## Простые преобразования

| Функция                                              | Назначение                           | Пример                                 | Результат         |
| ---------------------------------------------------- | ------------------------------------ | -------------------------------------- | ----------------- |
| `СтрДлина(Строка)`                                   | Возвращает длину строки              | `СтрДлина("Привет")`                   | `6`               |
| `Лев(Строка, КоличествоСимволов)`                    | Возвращает символы с начала строки   | `Лев("Привет", 3)`                     | `"При"`           |
| `Прав(Строка, КоличествоСимволов)`                   | Возвращает символы с конца строки    | `Прав("Привет", 3)`                    | `"вет"`           |
| `Сред(Строка, НачальнаяПозиция, КоличествоСимволов)` | Возвращает часть строки              | `Сред("Привет", 2, 3)`                 | `"рив"`           |
| `СтрНайти(Строка, Подстрока)`                        | Ищет позицию подстроки               | `СтрНайти("Привет", "ив")`             | `3`               |
| `СтрЗаменить(Строка, ЧтоЗаменить, НаЧтоЗаменить)`    | Заменяет подстроку                   | `СтрЗаменить("Привет", "ивет", "ока")` | `"Пока"`          |
| `СокрЛ(Строка)`                                      | Удаляет пробелы слева                | `СокрЛ("  Привет")`                    | `"Привет"`        |
| `СокрП(Строка)`                                      | Удаляет пробелы справа               | `СокрП("Привет  ")`                    | `"Привет"`        |
| `СокрЛП(Строка)`                                     | Удаляет пробелы с обеих сторон       | `СокрЛП("  Привет  ")`                 | `"Привет"`        |
| `ВРег(Строка)`                                       | Переводит строку в верхний регистр   | `ВРег("Привет")`                       | `"ПРИВЕТ"`        |
| `НРег(Строка)`                                       | Переводит строку в нижний регистр    | `НРег("ПРИВЕТ")`                       | `"привет"`        |
| `СтрШаблон(Шаблон, ...)`                             | Формирует строку по шаблону          | `СтрШаблон("Товар: %1", "Молоко")`     | `"Товар: Молоко"` |
| `Строка(Значение)`                                   | Преобразует значение в строку        | `Строка(123)`                          | `"123"`           |
| `Число(Строка)`                                      | Преобразует строку в число           | `Число("123")`                         | `123`             |
| `Дата(Строка)`                                       | Преобразует строку в дату            | `Дата("20260101")`                     | Дата              |
| `ПустаяСтрока(Строка)`                               | Проверяет, является ли строка пустой | `ПустаяСтрока("")`                     | `Истина`          |

## Разбор строки

| Функция                                  | Назначение                                         | Пример                                       |
| ---------------------------------------- | -------------------------------------------------- | -------------------------------------------- |
| `СтрЧислоСтрок(Строка)`                  | Определяет количество строк в многострочной строке | `СтрЧислоСтрок("Раз\nДва")` → `2`            |
| `СтрПолучитьСтроку(Строка, НомерСтроки)` | Получает указанную строку из многострочного текста | `СтрПолучитьСтроку("Раз\nДва", 2)` → `"Два"` |
| `СтрЧислоВхождений(Строка, Подстрока)`   | Считает количество вхождений подстроки             | `СтрЧислоВхождений("аааа", "аа")`            |
| `СтрРазделить(Строка, Разделитель)`      | Разделяет строку на части                          | `СтрРазделить("А;Б;В", ";")`                 |
| `СтрСоединить(МассивСтрок, Разделитель)` | Объединяет строки с разделителем                   | `СтрСоединить(Массив, ";")`                  |
