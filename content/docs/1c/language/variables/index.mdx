---
title: Переменные
---

<Callout title="Типизация языка" type="idea">
  1С — динамически типизированный язык с сильной типизацией значений.
</Callout>

**Переменные** — это именованные контейнеры для хранения данных.

Для имени переменной можно использовать следующие символы:

- буквы латинского алфавита;
- цифры;
- символы `$` и `_`.

<Callout type="warning">**Первый символ должен быть буквой!**</Callout>
