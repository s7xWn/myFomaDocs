— это распределённая система контроля версий (Version Control System, VCS), которая помогает отслеживать изменения в файлах, особенно в исходном коде программ.

## Основные понятия

- Репозиторий (Repository) — папка проекта, в которой Git хранит историю изменений.
- Коммит (Commit) — сохранённый снимок состояния проекта.
- Ветка (Branch) — независимая линия разработки.
- Слияние (Merge) — объединение изменений из одной ветки в другую.
- Удалённый репозиторий (Remote) — копия проекта на сервере (например, на GitHub, GitLab или Bitbucket).

## Основные команды Git

```bash
git init          # создать репозиторий
git status        # посмотреть состояние файлов
git add .         # подготовить изменения к сохранению
git commit -m "Описание изменений"  # сохранить изменения
git log           # посмотреть историю коммитов
git branch        # список веток
git checkout -b feature  # создать новую ветку и перейти в неё
git merge feature # объединить ветку feature с текущей
git clone <URL>   # скачать удалённый репозиторий
git pull          # получить последние изменения
git push          # отправить изменения на сервер
```
