---
title: Version Control Systems (VCS)
---

— это система контроля версий, которая помогает отслеживать изменения в файлах проекта, особенно в исходном коде.

| VCS           | Тип         | Сегодня (2026)                        |
| ------------- | ----------- | ------------------------------------- |
| **Git**       | Distributed | Очень широко                          |
| **SVN**       | Centralized | Используется, но реже                 |
| **Mercurial** | Distributed | Используется нишево                   |
| **Perforce**  | Centralized | Популярен в крупных компаниях и играх |
| **CVS**       | Centralized | В основном legacy                     |
| **RCS/SCCS**  | Local       | В основном legacy                     |

<hr />

## Централизованные VCS

Есть центральный сервер, с которым работают все разработчики.

- **SVN (Apache Subversion)** — очень известная централизованная система.
- **Perforce Helix Core** — популярна в крупных проектах, особенно в game development.
- **CVS (Concurrent Versions System)** — исторически очень популярная, сейчас считается устаревшей.
- **TFVC (Team Foundation Version Control)** — система Microsoft, связанная с Azure DevOps.

<hr />

## Распределённые VCS (DVCS)

У каждого разработчика есть полноценная копия репозитория и его истории.

- **Git** — сегодня самый распространённый.
- **Mercurial (Hg)** — похож на Git, но проще по некоторым аспектам.
- **Fossil** — DVCS с дополнительными встроенными возможностями.
- **Bazaar (bzr)** — исторически использовался в некоторых open-source проектах.

<hr />

## Локальные VCS

История хранится на одном компьютере. <br/>
Сейчас практически не используются для современной разработки.

- **RCS (Revision Control System)** — одна из старых систем, работает с отдельными файлами.
- **SCCS (Source Code Control System)** — ещё более старая система, появилась в 1970-х.
