---
title: Эмуляторы терминала
---

Сам по себе терминал — это интерфейс, в котором ты вводишь команды:

```bash
ssh user@192.168.1.100
cd /var/log
ls -la
```

**Эмулятор терминала** — это программа с окном, которая предоставляет этот интерфейс и запускает оболочку (`zsh`, `bash` и т. д.).

| Terminal emulator    | OS                    | Особенности                                     | Для кого                                |
| -------------------- | --------------------- | ----------------------------------------------- | --------------------------------------- |
| **Windows Terminal** | Windows               | PowerShell, CMD, WSL, SSH, вкладки              | ⭐ Основной вариант для Windows         |
| **Terminal.app**     | macOS                 | Встроен в macOS, простой и стабильный           | Для большинства задач                   |
| **MobaXterm**        | Windows               | Terminal + SSH + SFTP + X11 + RDP/VNC и др.     | ⭐ Администрирование серверов           |
| **iTerm2**           | macOS                 | Вкладки, split panes, профили, мощные настройки | ⭐ Универсальный вариант для Mac        |
| **Warp**             | macOS, Linux          | Современный UI, AI, автодополнение              | Тем, кто любит современный интерфейс    |
| **Ghostty**          | macOS, Linux          | Очень быстрый, минималистичный                  | Для тех, кому важны скорость и простота |
| **WezTerm**          | macOS, Linux, Windows | Очень гибкая настройка, Lua                     | Продвинутым пользователям               |
| **Kitty**            | macOS, Linux          | GPU-ускорение, высокая производительность       | Продвинутым пользователям               |
| **Alacritty**        | macOS, Linux, Windows | Минималистичный, очень быстрый                  | Тем, кому нужен только терминал         |
| **ConEmu**           | Windows               | Вкладки, split, много настроек                  | Windows power users                     |
| **Tabby**            | macOS, Linux, Windows | SSH, Serial, локальный терминал, плагины        | Тем, кто хочет «всё в одном»            |
| **Hyper**            | macOS, Linux, Windows | Electron, темы, плагины                         | Тем, кто любит кастомизацию             |
