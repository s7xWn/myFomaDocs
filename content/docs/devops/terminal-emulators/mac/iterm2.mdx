— это продвинутый терминал для macOS. По сути, он заменяет стандартное приложение Terminal, но даёт гораздо больше возможностей.

- 🖥️ Несколько вкладок и окон — удобно работать с разными проектами.
- 📐 Разделение окна на панели — можно одновременно видеть, например, сервер и логи.
- 🔍 Поиск и удобная работа с выводом команд.
- 🎨 Настройка внешнего вида — темы, шрифты, цвета.
- ⌨️ Горячие клавиши и профили — можно настроить разные окружения.
- 📋 Удобная работа с буфером обмена.
- ⚡ Мощные функции для разработчиков — например, интеграция с shell, SSH и различными CLI-инструментами.

:::warning
Важно: iTerm2 — не отдельная командная оболочка. Он является терминальным эмулятором. Внутри него можно использовать zsh, bash, fish и другие shell.
:::

## Установка (образ с официального сайта)

1. Открыть [официальный сайт: iTerm2](https://iterm2.com)
2. Нажать Downloads и скачай актуальную версию.
3. Открыть скачанный `.zip` — появится приложение iTerm.
4. Перетащить iTerm в папку Applications (Программы).
5. Запуск через Launchpad или Spotlight (`⌘ + Space` → iTerm).

<hr />

## Установка (Homebrew)

```bash
brew install iterm2
```

или явно: `--cask` — это параметр Homebrew, который говорит: «установи не обычный консольный пакет, а macOS-приложение».

```bash
brew install --cask iterm2
```

> Современный Homebrew позволяет писать без `--cask` и обычно сам определяет, что iterm2 — это cask. Но --cask явно показывает, какой именно тип пакета ты устанавливаешь.

Запуск после установки:

```bash
open -a iTerm
```
