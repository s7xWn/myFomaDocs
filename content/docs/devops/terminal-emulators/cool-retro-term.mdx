Cool-retro-term — это эмулятор терминала для Linux и macOS, который имитирует внешний вид старых ЭЛТ-мониторов (CRT) и компьютеров 1980–1990-х годов.

- Ретро-дизайн: зелёный, янтарный или синий текст на тёмном фоне.
- Эффекты старого монитора: линии развёртки, свечение символов, мерцание, кривизна экрана и визуальный шум.
- Настройка внешнего вида: можно менять цветовую схему, шрифт, яркость и интенсивность эффектов.
- Настоящий терминал: можно выполнять обычные команды оболочки, например ls, cd, ssh, git и другие.

<hr />

## Установка

### Linux

```bash
sudo apt install cool-retro-term
```
