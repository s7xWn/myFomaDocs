---
title: Linux Family
---

— это группы дистрибутивов Linux, которые имеют общего «предка» и используют похожую структуру системы и управления пакетами.

| Семейство     | Примеры                                    | Пакетный менеджер      |
| ------------- | ------------------------------------------ | ---------------------- |
| **Debian**    | Debian, Ubuntu, Linux Mint, Pop!\_OS, Kali | `apt` / `dpkg`         |
| **Red Hat**   | Fedora, RHEL, Rocky Linux, AlmaLinux       | `dnf` / `rpm`          |
| **Arch**      | Arch Linux, Manjaro, EndeavourOS           | `pacman`               |
| **SUSE**      | openSUSE, SUSE Linux Enterprise            | `zypper` / `rpm`       |
| **Gentoo**    | Gentoo                                     | `emerge`               |
| **Alpine**    | Alpine Linux                               | `apk`                  |
| **Slackware** | Slackware                                  | `pkgtool` / `slackpkg` |
| **Void**      | Void Linux                                 | `xbps`                 |
