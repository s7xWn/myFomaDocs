```bash
sudo apt install curl
```

## GET-запрос

```bash
curl <url>
```

<hr />

## POST-запрос (`-X POST`)

```bash
curl -X POST <url>
```

### Передать данные (`-d`)

```bash
curl -X POST -d "name=Alex" <url>
```

<hr />

## Посмотреть только HTTP-заголовки: (`-I`)

```bash
curl -I <url>
```

<hr />

## Скачать файл (`-O`)

```bash
curl -O <url>
```

### Скачать файл и переименовать (`-o`)

```bash
curl -o <file_name> <url>
```

## Тихий надёжный curl с редиректами (`-fsSL`)

— очень популярная комбинация флагов curl, особенно в командах установки ПО.

> «Скачай содержимое по URL, следуй редиректам, не засоряй вывод, но сообщи об ошибке и считай HTTP-ошибки ошибкой команды».

```bash
curl -fsSL <url>
```

| Флаг | Длинная форма  | Что делает                                                                         |
| ---- | -------------- | ---------------------------------------------------------------------------------- |
| `-f` | `--fail`       | При HTTP-ошибке (`4xx`, `5xx`) завершает работу с ошибкой и не выводит тело ответа |
| `-s` | `--silent`     | Убирает progress bar и лишний вывод                                                |
| `-S` | `--show-error` | **Возвращает показ ошибок**, несмотря на `-s`                                      |
| `-L` | `--location`   | Следует за HTTP redirects (`301`, `302`, `307`, `308`)                             |
