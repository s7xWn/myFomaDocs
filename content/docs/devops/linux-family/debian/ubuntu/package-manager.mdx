---
title: Package Manager (`apt`)
---

```bash
apt
```

— это основной инструмент управления пакетами в Ubuntu. Он позволяет устанавливать, обновлять и удалять программы, а также управлять их зависимостями.

`apt` показывает справку по использованию команды и список основных подкоманд.

```
apt 3.x.x (amd64)
Usage: apt [options] command

apt is a commandline package manager...

Most used commands:
  list        - list packages based on package names
  search      - search in package descriptions
  show        - show package details
  install     - install packages
  remove      - remove packages
  update      - update list of available packages
  upgrade     - upgrade the system
  ...
```

| Команда                 | Что делает                                                          |
| ----------------------- | ------------------------------------------------------------------- |
| `apt update`            | Обновляет информацию о доступных пакетах из репозиториев            |
| `apt upgrade`           | Обновляет установленные пакеты                                      |
| `apt full-upgrade`      | Обновляет пакеты, при необходимости устанавливая/удаляя зависимости |
| `apt install <пакет>`   | Устанавливает пакет                                                 |
| `apt remove <пакет>`    | Удаляет пакет, но обычно оставляет конфигурацию                     |
| `apt purge <пакет>`     | Удаляет пакет вместе с конфигурацией                                |
| `apt autoremove`        | Удаляет ненужные зависимости                                        |
| `apt search <строка>`   | Ищет пакеты                                                         |
| `apt show <пакет>`      | Показывает информацию о пакете                                      |
| `apt list`              | Показывает список пакетов                                           |
| `apt policy <пакет>`    | Показывает версии и источники пакета                                |
| `apt download <пакет>`  | Скачивает `.deb`, не устанавливая его                               |
| `apt reinstall <пакет>` | Переустанавливает пакет                                             |
| `apt edit-sources`      | Редактирует источники репозиториев                                  |

```
-y, --yes, --assume-yes
    Не спрашивать подтверждение.

--no-install-recommends
    Не устанавливать рекомендуемые пакеты.

--install-recommends
    Устанавливать рекомендуемые пакеты.

--reinstall
    Переустановить уже установленный пакет.

--download-only
    Только скачать пакеты, не устанавливать.

--no-download
    Не скачивать пакеты.

--fix-broken
    Попытаться исправить сломанные зависимости.

--simulate
    Только показать, что будет сделано, ничего не менять.

-s
    Короткая форма --simulate.

--dry-run
    Аналогично пробному запуску.

--allow-downgrades
    Разрешить понижение версии пакета.

--allow-remove-essential
    Разрешить удаление критически важных пакетов (опасно).

--allow-change-held-packages
    Разрешить изменение пакетов, помеченных как hold.
```

## `install <пакет>`

Устанавливает пакет

### `-y` `--yes` `--assume-yes`

### `--dry-run`

Показывает, что произойдёт при обновлении пакета, но ничего не меняет

```bash
sudo apt install --dry-run <пакет>
```

### `--reinstall`

APT заново скачает пакет и установит его поверх текущей версии.

```bash
sudo apt install --reinstall curl
```
