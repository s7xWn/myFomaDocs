Kali Linux — это Debian-based дистрибутив Linux, специально предназначенный для специалистов по кибербезопасности.

<hr />

## Семейство

- Kali Linux относится к семейству Debian Linux.
- **Семейство:** Debian-based Linux.
- **Основа:** Debian GNU/Linux.
- **Разработчик:** Offensive Security.
- **Пакетный менеджер:** `APT` (`.deb`).
- **Основное назначение:** тестирование на проникновение, аудит безопасности, цифровая криминалистика и анализ защищённости систем.
