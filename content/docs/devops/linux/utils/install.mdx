title: install
---

— это командная утилита для установки файлов в нужные места файловой системы.

## Режим доступа/права (`-m`)

```bash
install -m <mode> [options] <source> <destination>
```

В `install` опция `-m` означает **mode** — режим доступа (права) создаваемого файла или каталога.

- `<mode>` -> abcd

```
a  b  c  d
│  │  │  │
│  │  │  └── остальные
│  │  └───── группа
│  └──────── владелец
└─────────── специальные права
```

Для обычных прав чаще всего используют только три последние цифры:

```
b  c  d
│  │  │
│  │  └── остальные
│  └───── группа
└──────── владелец
```

`abcd` могут быть: 0-7

Цифры складываются из:

- 4 = чтение (r)
- 2 = запись (w)
- 1 = выполнение/вход (x)

Поэтому возможные значения каждой цифры:

```
0 = ---
1 = --x
2 = -w-
3 = -wx
4 = r--
5 = r-x
6 = rw-
7 = rwx
```

## Создание каталогов (`-d`)

```bash
install -d <path>
```
