---
title: ls - Содержимое каталога
---

`ls` — это стандартная утилита Linux/Unix, которая показывает содержимое каталога.

```bash
ls
```

<hr />

## `-l` - подробный список

```bash
ls -l
```

Подробный список:

- права доступа;
- количество ссылок;
- владельца;
- группу;
- размер;
- дату изменения;
- имя файла.

### `-h` - удобные размеры файлов

```bash
ls -lh
```

`-h` = human-readable — делает размеры файлов более удобными для чтения (`1K`, `20M`, `2G`);

### `-r` - реверс фильтра

Например:

```bash
ls -lt # сначала недавно изменённые
ls -ltr # сначала старые

ls -S # Большие файлы сверху
ls -Sr # Большие файлы снизу

```

### `-t` - сортировка по дате изм.

```bash
ls -lt
```

### `-S` - сортировка по размеру

```bash
ls -lS
```

### `-X` - сортировка по расширению

```bash
ls -lX
```

<hr />

## `-a` - показывает скрытые

```bash
ls -a
```

— показывает также скрытые файлы и каталоги, имена которых начинаются с `.`

<hr />

## `-A` - показывает скрытые

```bash
ls -a
```

— тоже что и `-a`, но без `.` и `..`
