---
title: "ln - создание ссылок"
---

`ln` — это стандартная утилита Linux для создания [ссылок]() на файлы и каталоги.

<hr />

## Hark Link

```bash
ln <linkOnFile> <linkName>
```

<Callout title='' type='tip'>

Если в качестве назначения указать каталог, то `ln` автоматически возьмёт имя последнего элемента исходного пути.

</Callout>

Создаёт жёсткую ссылку ([hard link](../../hard-soft-link-inode.mdx#hard-link)) на файл `linkOnFile` с именем `linkName` в текущем каталоге.

<Callout title='Важный момент' type='warn'>

`ln` не копирует содержимое файла. Он создаёт дополнительное имя для уже существующего файла.

</Callout>

<details>
  <summary>Пример</summary>

```bash
ln /var/log/app.log app.log
```

</details>

<hr />

## Soft Link (`-s`)

```bash
ln -s <linkOnFile> <linkName>
```

<Callout title='' type='tip'>

Если в качестве назначения указать каталог, то `ln` автоматически возьмёт имя последнего элемента исходного пути.

</Callout>

Создаёт символическую ссылку ([soft link](../../hard-soft-link-inode.mdx#hard-link)) на файл `linkOnFile` с именем `linkName` в текущем каталоге.

<hr />

## Параметры

| Параметр | Назначение                                      |
| -------- | ----------------------------------------------- |
| `-s`     | Создать символическую ссылку                    |
| `-f`     | Перезаписать существующий файл назначения       |
| `-v`     | Показывать создаваемые ссылки                   |
| `-n`     | Не переходить по существующей ссылке на каталог |
| `-T`     | Считать назначение обычным файлом               |

<Callout title='' type='tip'>

Если в качестве назначения указать каталог, то `ln` автоматически возьмёт имя последнего элемента исходного пути.

</Callout>
