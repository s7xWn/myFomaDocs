---
title: grep - Поиск строки
---

`grep` — это стандартная утилита для поиска строк, соответствующих заданному шаблону, в файлах или в выводе других команд.

```bash
grep [options] <value> <file/dir>
```

`grep` пройдёт по `<file>` и оставит только строки, содержащие `<value>`

:::warning
По умолчанию `grep` учитывает регистр.
:::

## `-i` - игнорировать регистр

```bash
grep -i <value> <file>
```

Найдёт `<value>`, `<Value>`, `<VALUE>` и т. д.

<hr />

## `-n` - показать номера строк

```bash
grep -n <value> <file>
```

Результат:

```
15:Connection error
42:Database error
```

<hr />

## `-r` - искать рекурсивно в каталоге

```bash
grep -r <value> <dir>
```

Поищет `<value>` во всех файлах внутри `<dir>`.

<hr />

## `-w` - искать целое слово

```bash
grep -w <value> <file>
```

Найдёт `<value>`, но не `<value> + other words`.

<hr />

## `-v` - строки, которые НЕ соответствуют

```bash
grep -v <value> <file>
```

То есть исключить все строки с `<value>`.
