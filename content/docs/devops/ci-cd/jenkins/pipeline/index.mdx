## Triggers

### GitHub

Включаем триггер для webhook: `GitHub hook trigger for GITScm polling`
Создай Webhook в GitHub: Repository → Settings → Webhooks → Add webhook

- Payload URL: `https://"domain"/github-webhook/`
- Content type: `application/json`
- SSL verification: `Enable (https)` / `Disable (http)` || Зависит от Payload URL
- Which events would you like to trigger this webhook?: `Just the push event`
- `Active`
