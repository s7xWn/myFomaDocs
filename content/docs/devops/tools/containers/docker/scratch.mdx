Docker Scratch — это специальный минимальный базовый образ, который используется для создания максимально лёгких Docker-контейнеров.

В нём нет:

- Linux-дистрибутива;
- оболочки Bash или Shell;
- пакетного менеджера (apt, apk);
- стандартных системных утилит;
- библиотек, кроме тех, которые ты сам добавишь.

```dockerfile
FROM scratch

COPY app /app

CMD ["/app"]
```

## Зачем нужен Scratch

1. Маленький размер — минимальный размер образа.
2. Безопасность — меньше компонентов, меньше потенциальных уязвимостей.
3. Быстрая загрузка — меньше данных для скачивания.
4. Минимализм — в контейнере только то, что действительно нужно приложению.

<div className="hr-decor">✦</div>

## Используется

- Go-приложений;
- статически скомпилированных программ на C/C++;
- микросервисов;
- production-контейнеров.
