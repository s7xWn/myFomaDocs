Docker Registry — это хранилище Docker-образов (Docker Images), откуда их можно скачивать и куда можно загружать.

Проще говоря, это аналог GitHub, но для Docker-образов.

<div className="hr-decor">✦</div>

## Как это работает

1. Собрать Docker Image на компьютере.
2. Загрузить его в Docker Registry.
3. На другом сервере скачать этот образ.
4. Запустить контейнер из скачанного образа.

<div className="hr-decor">✦</div>

## Популярные Docker Registry

| Registry                             | Описание                                      |
| ------------------------------------ | --------------------------------------------- |
| [Docker Hub](https://hub.docker.com) | Публичный и приватный Registry от Docker      |
| GitHub Container Registry (GHCR)     | Хранение образов в GitHub                     |
| GitLab Container Registry            | Registry, встроенный в GitLab                 |
| Amazon ECR                           | Registry от AWS                               |
| Harbor                               | Self-hosted Registry для своей инфраструктуры |

### Настройки доступа к Gitlab Registry

Нужно создать персональный токен доступа (access token) в настройках своего профиля на Gitlab.

Переходим по ссылке: `https:/<namespace>/-/user_settings/personal_access_tokens`

Нажимаем кнопку `Add new token`
Token name: Registry

В **Select scopes** нужны права:

- api
- read_api
- read_user
- read_repository
- write_repository

Нажимаем кнопку `Create personal access token`.

Сохраняем сгенерированный токен для дальнейшего использования.
