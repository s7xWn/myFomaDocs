Docker — это платформа для запуска приложений в контейнерах. Контейнер упаковывает приложение вместе с его зависимостями и настройками, чтобы оно предсказуемо работало на разных машинах.

## Какие проблемы решает Docker

1. **Конфликты зависимостей**

   Допустим, проект A требует Node.js 18, а проект B — Node.js 22.

   Без Docker приходится переключать версии или настраивать разные окружения. С Docker каждый проект может жить в своём контейнере.

2. **Запуск на разных ОС**

   Docker позволяет не зависеть от установленного на хосте Python, Node.js, Java, библиотек и т. д.э <br/>
   Потому что контейнер содержит пользовательское окружение Linux, а Docker на Windows/macOS использует Linux VM/подсистему, чтобы запускать Linux-контейнеры.

   Поэтому корректнее говорить:

   > Docker обеспечивает переносимость окружения приложения между разными хостовыми ОС.

3. **Сложный onboarding разработчиков**

   Вместо инструкции:

   ```
   Установи PostgreSQL → создай пользователя → установи Redis → настрой Python → установи зависимости → выставь переменные окружения...
   ```

   часто достаточно:

   ```bash
   docker compose up
   ```

4. Изоляция приложений

   Каждый контейнер получает своё окружение. Они могут работать на одной машине, не мешая друг другу.

## Основные понятия Docker

| Термин             | Что означает                                                          |
| ------------------ | --------------------------------------------------------------------- |
| **Docker Engine**  | Движок Docker, который создаёт и запускает контейнеры и управляет ими |
| **Dockerfile**     | Инструкция, как собрать image                                         |
| **Image**          | Шаблон, из которого создаются контейнеры                              |
| **Container**      | Запущенный экземпляр image                                            |
| **Registry**       | Хранилище образов, например Docker Hub                                |
| **Volume**         | Постоянное хранилище данных                                           |
| **Network**        | Сеть между контейнерами                                               |
| **Docker Compose** | Инструмент для запуска нескольких контейнеров                         |

Docker Engine - клиент-серверное приложение, которое состоит из:

- сервер -> создаёт образы, контейнеры и тома, управляя ими
- API
- CLI

## Установка

### Windows

[Ссылка на скачивание](https://docs.docker.com/desktop/setup/install/windows-install/)

### Linux Ubuntu

Удаляем старые/конфликтующие пакеты

```bash
sudo apt remove -y docker.io docker-doc docker-compose podman-docker containerd runc
```

Обновляем систему

```bash
sudo apt update
sudo apt upgrade -y
```

Устанавливаем необходимые пакеты (`ca-certificates`, `curl`)

```bash
sudo apt install -y ca-certificates curl
```

Добавляем официальный GPG-ключ Docker

```bash
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg \
  -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
```
