## `login`

Логинимся под своим логином и созданным паролем.

```bash
docker login -u <GITLAB-LOGIN> -p <ACCESS-TOKEN> <IP/URI>:<PORT>
```

<details>
  <summary>Пример</summary>

```bash
docker login -u root -p glpat-TOKEN gitlab.s7xwn.ru:5050
```

Docker compose, без внешнего reverse proxy:

```
registry_external_url 'https://gitlab.s7xwn.ru:5050'
registry_nginx['enable'] = true
registry_nginx['listen_port'] = 5050
registry_nginx['listen_https'] = true
```

</details>

## Контейнеры

### `run` - запуск контейнера

`docker run` запускает контейнер из Docker-образа.

```bash
docker run <name>
```

```bash
docker run <name>:<version>
```

#### `-d` - в background

```bash
docker run -d <name>
```

```bash
docker run -d <name>:<version>
```

#### `--name` - указать новое имя

```bash
docker run --name <new_name> <name>
```

```bash
docker run --name <name>:<version>
```

#### `-p` - порты

```bash
docker run -p HOST_PORT:CONTAINER_PORT <name>:<version>
```

<hr />

### `ps` - запущенные контейнеры

Запущенные контейнеры

```bash
docker ps
```

<hr />

### `rm` - удалить контейнер

```bash
docker rm <CONTAINER_ID>
```

Удалить все контейнеры:

```bash
docker rm $(docker ps -aq) --force
```

<hr />

### `run` - запустить контейнер

```bash
docker run <options> <ports> <container>
```

<hr />

### `stop` - остановить контейнер

```bash
docker stop <CONTAINER_ID>
```

## Образы

### `build` - сборка

При `build` ищет `Dockerfile` в указанной директории

```bash
docker build .
```

#### `-t` - с именем (и тегом)

```bash
docker build -t <name> .
```

```bash
docker build -t <name>:<tag> .
```

Несколько тегов одного образа:

```bash
docker build -t <name>:<tag> -t <name>:latest .
```

#### `-f` - указать Dockerfile явно

```bash
docker build -f Dockerfile .
```

<div className="hr-decor">✦</div>

### `pull` - пулл образа

По умолчанию `docker pull` скачивает образы из Docker Hub — публичного реестра Docker.

```bash
docker pull <name>:<version>
```

<details>
  <summary>Пример</summary>

```bash
docker pull alpine:latest
```

</details>

#### GitLab Registry

```bash
docker pull <IP/URI>:<PORT>/.../<USERNAME>/my-app:v0.1.0
```

<hr />

### `images` - спулленые образы

```bash
docker images
```

<hr />

### `rmi` - удалить образ

Удалить все образы:

```bash
docker rmi $(docker images -q) --force
```

<hr />

### `tag` - метка

```bash
docker tag alpine:latest <IP/URI>:<PORT>/.../<USERNAME>/my-app:v0.1.0
```

<hr />

### `push` - пуш образа

```bash
docker push <IP/URI>:<PORT>/.../<USERNAME>/my-app:v0.1.0
```
