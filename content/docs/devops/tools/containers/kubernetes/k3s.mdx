title: "k3s"

K3s (Kubernetes) — это облегчённая версия Kubernetes, предназначенная для запуска и управления контейнерами на серверах с небольшими ресурсами.

<div className="hr-decor">✦</div>

## k8s vs k3s

| Характеристика          | Kubernetes | K3s              |
| ----------------------- | ---------- | ---------------- |
| Ресурсы                 | Больше     | Меньше           |
| Установка               | Сложнее    | Проще            |
| Архитектура             | Полная     | Облегчённая      |
| Совместимость с K8s API | Да         | Да               |
| Raspberry Pi            | Можно      | Отлично подходит |
| Production              | Да         | Да               |
