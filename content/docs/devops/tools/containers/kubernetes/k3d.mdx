---
title: "k3d"
---

k3d (K3s in Docker) - это лёгкий инструмент для запуска локальных Kubernetes-кластеров внутри Docker.

<div className="hr-decor">✦</div>

## k8s vs k3s vs k3d

| Критерий          | Kubernetes (K8s)        | k3s                    | k3d                          |
| ----------------- | ----------------------- | ---------------------- | ---------------------------- |
| Что это           | Платформа               | Облегчённый Kubernetes | Инструмент запуска кластеров |
| Назначение        | Управление контейнерами | Компактный Kubernetes  | Локальная разработка         |
| Использует Docker | Не обязательно          | Не обязательно         | Да                           |
| Production        | Да                      | Да                     | Обычно нет                   |
