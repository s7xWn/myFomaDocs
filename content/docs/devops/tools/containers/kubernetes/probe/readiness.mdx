---
title: "Readiness Probe"
---

Проверяет, готово ли приложение обрабатывать запросы.

Если проверка не проходит:

- Контейнер НЕ перезапускается.
- Pod исключается из списка endpoints соответствующего Service.
- Kubernetes перестаёт направлять на него новый трафик.

<details>
  <summary>Пример</summary>

Приложение запустилось, но ещё загружает данные из базы. Пока оно не готово, запросы к нему не поступают.

```yaml
readinessProbe:
  httpGet:
    path: /ready
    port: 8080
  initialDelaySeconds: 5
  periodSeconds: 5
```

</details>
