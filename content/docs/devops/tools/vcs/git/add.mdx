---
title: add | Добавление изменений
---

В Git команда `add` добавляет изменения в staging area (индекс) — то есть подготавливает их к следующему коммиту.

<hr />

## Добавить конкретный файл.

```bash
git add file.txt
```

### Добавить все файлы определённого типа

```bash
git add "*.js"
```

```bash
git add src/*.py
```

<hr />

## Добавить несколько файлов.

```bash
git add file1.txt file2.txt
```

<hr />

## Добавить изменения в текущей директории и ниже.

```bash
git add .
```

<hr />

## Добавить все изменения во всём репозитории, включая удалённые файлы.

```bash
git add -u
```
