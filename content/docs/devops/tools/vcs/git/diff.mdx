---
title: diff | Разница файлов
---

`git diff` — команда Git, которая показывает разницу между версиями файлов: что было добавлено, удалено или изменено.

```bash
git diff
```

<Callout>В выводе строки с `-` — удалённые, а с `+` — добавленные:</Callout>

<Callout type="success">
`git diff` может открыть пейджер — программу, которая показывает длинный вывод постранично. Это не редактор в смысле редактирования файлов.

Обычно Git использует `less`.

</Callout>

Например, ты изменил файл `app.js`, но ещё не сделал `git add` покажет твои текущие изменения относительно последнего состояния в staging area.

```bash
git diff                 # изменения, которые ещё не добавлены через git add
git diff --staged        # изменения, уже добавленные через git add
git diff HEAD            # все изменения относительно последнего коммита
git diff main..feature   # разница между двумя ветками
git diff commit1 commit2 # разница между двумя коммитами
```

<hr />

## Синтаксис

```
diff --git a/source.config.ts b/source.config.ts
index a08c699..78f7c37 100644
--- a/source.config.ts
+++ b/source.config.ts
@@ -1,7 +1,8 @@
```

- `diff --git a/source.config.ts b/source.config.ts` <br/>
  Git сравнивает две версии одного файла:
  - `a/source.config.ts` — старая версия
  - `b/source.config.ts` — новая версия
- `index a08c699..78f7c37 100644` <br/>
  Здесь Git показывает внутренние идентификаторы двух версий файла:
  - `a08c699` — состояние файла до изменений
  - `78f7c37` — состояние после изменений
  - `100644` — права файла в Git: обычный файл, не исполняемый
- `--- a/source.config.ts +++ b/source.config.ts` -> Это обозначение сторон сравнения старой и новой версии
- `@@ -1,7 +1,8 @@` <br/>
  Говорит, в каком месте файла находятся изменения.
  - `-1,7` -> В старой версии изменения относятся к строкам с 1-й, всего 7 строк.
  - `+1,8` -> В новой версии — начиная с 1-й строки, всего 8 строк.

    То есть Git обнаружил, что в этом участке файла было 7 строк → стало 8 строк.
