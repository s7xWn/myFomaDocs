---
title: Файловая структура
---

Типичная структура выглядит так:

```
.git/
├── HEAD
├── config
├── description
├── hooks/
│   ├── applypatch-msg.sample
│   ├── commit-msg.sample
│   ├── pre-commit.sample
│   └── ...
├── info/
│   └── exclude
├── objects/
│   ├── info/
│   └── pack/
├── refs/
│   ├── heads/
│   └── tags/
├── branches/          (может отсутствовать в новых версиях Git)
└── index              (появится после добавления файлов)
```

| Элемент         | Назначение                                                                                                         |
| --------------- | ------------------------------------------------------------------------------------------------------------------ |
| **HEAD**        | Указывает на текущую ветку (обычно `refs/heads/main` или `master`).                                                |
| **config**      | Локальные настройки репозитория.                                                                                   |
| **description** | Описание репозитория, используется в основном Git-серверами.                                                       |
| **hooks/**      | Каталог с Git-хуками (скриптами, выполняемыми при различных событиях). По умолчанию содержит примеры (`*.sample`). |
| **info/**       | Дополнительная информация, например файл `exclude` — локальный аналог `.gitignore`.                                |
| **objects/**    | Хранилище всех объектов Git: коммитов, деревьев, blob-объектов и тегов. Изначально почти пустое.                   |
| **refs/**       | Ссылки на ветки (`heads`) и теги (`tags`).                                                                         |
| **index**       | Индекс (staging area). Создается после первого `git add`.                                                          |
| **logs/**       | Журнал перемещения указателей (`HEAD`, веток). Появляется после первых коммитов.                                   |

<hr />

## `HEAD`

Это обычный текстовый файл, который указывает, какая ветка сейчас является текущей.

Содержит после `init`:

```
ref: refs/heads/main
```

Что это означает

- `ref`: говорит, что `HEAD` ссылается на другую ссылку (reference).
- `refs/heads/main` — файл, в котором хранится хеш последнего коммита ветки `main`.

<hr />

## `config`

Это локальная конфигурация конкретного репозитория.

Содержит после `init`:

```
[core]
	repositoryformatversion = 0
	filemode = true
	bare = false
	logallrefupdates = true
	ignorecase = true
	precomposeunicode = true
```

| Параметр                      | Назначение                                                                                                              |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `repositoryformatversion = 0` | Версия формата репозитория Git.                                                                                         |
| `filemode = true`             | Git отслеживает изменение прав на выполнение файлов (`chmod +x`).                                                       |
| `bare = false`                | Это обычный репозиторий с рабочей директорией. Если `true` — репозиторий без рабочей директории (например, на сервере). |
| `logallrefupdates = true`     | Вести журнал изменений ссылок (`git reflog`).                                                                           |
