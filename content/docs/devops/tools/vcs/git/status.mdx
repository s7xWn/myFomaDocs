---
title: status | Состояние репозитория
---

`git status` — это команда Git, которая показывает текущее состояние твоего репозитория.

```bash
git status
```

Git покажет, например:

- на какой ты сейчас ветке;
- есть ли изменения в файлах;
- какие файлы изменены;
- какие файлы подготовлены для коммита (staged);
- какие файлы ещё не отслеживаются (untracked).
