Commit в Git — это сохранённая версия изменений в проекте.

Ты изменил файлы → подготовил изменения → сделал commit → Git запомнил, что именно изменилось и кто это сделал.

```bash
git commit
```

Git попробует создать **commit**, но откроет редактор текста, чтобы ты написал сообщение для **commit**.

## `-m`

```bash
git commit -m "Добавил авторизацию"
```

Флаг `-m` позволяет сразу указать сообщение и не открывать редактор.

Обычно рекомендуют:

- до 50 символов — краткий заголовок commit;
- если нужно больше деталей — можно добавить описание на следующих строках;
- старайся писать кратко и по делу.

## `--amend` - изменяет последний коммит

<Callout type="warn">
  `amend` переписывает историю Git — фактически создаётся новый коммит вместо
  старого.

Поэтому если уже сделан:

```bash
git push
```

и другие люди работают с этой веткой, с amend нужно быть осторожным. Для уже отправленного коммита обычно потребуется:

```bash
git push --force-with-lease
```

<details>
  <summary>Пример</summary>

```bash
git commit
git push
git add forgotten-file.js
git commit --amend --no-edit
git push --force-with-lease
```

</details>

</Callout>

```bash
git commit --amend
```

— это команда Git, которая изменяет последний коммит, вместо создания нового.

### `--no-edit` - не менять сообщение

`--no-edit` означает: не менять сообщение коммита.
