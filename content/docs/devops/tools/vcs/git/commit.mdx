Commit в Git — это сохранённая версия изменений в проекте.

Ты изменил файлы → подготовил изменения → сделал commit → Git запомнил, что именно изменилось и кто это сделал.

```bash
git commit
```

Git попробует создать **commit**, но откроет редактор текста, чтобы ты написал сообщение для **commit**.

## `-m`

```bash
git commit -m "Добавил авторизацию"
```

Флаг `-m` позволяет сразу указать сообщение и не открывать редактор.

Обычно рекомендуют:

- до 50 символов — краткий заголовок commit;
- если нужно больше деталей — можно добавить описание на следующих строках;
- старайся писать кратко и по делу.
