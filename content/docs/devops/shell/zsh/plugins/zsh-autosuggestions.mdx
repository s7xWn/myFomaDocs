## Установка

### Oh My Zsh

[Oh My Zsh](./ohmyzsh.mdx)

```bash
git clone https://github.com/zsh-users/zsh-autosuggestions ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-autosuggestions
```

Открыть `~/.zshrc`, найти `plugins` и добавить

```
zsh-autosuggestions
```

```
plugins=(
    # other plugins...
    zsh-autosuggestions
)
```
