---
title: fzf-zsh-plugin
---

`fzf-zsh-plugin` — это плагин для оболочки Zsh, который добавляет интерактивный поиск с помощью fzf, инструмента нечёткого поиска (fuzzy finder).

Он позволяет находить команды, файлы и каталоги, выбирая нужный вариант из списка с помощью клавиатуры, вместо того чтобы вводить всё вручную.
