— это программа, которая позволяет пользователю взаимодействовать с операционной системой с помощью текстовых команд.

> Shell — это посредник между пользователем и операционной системой. Вы вводите команду, Shell передает ее операционной системе, а затем выводит результат.

<Callout>
Каждая оболочка (`sh`, `bash`, `zsh`) предоставляет собственный диалект языка **shell** со своими расширениями и особенностями синтаксиса.

Они частично используют синтаксис и концепции POSIX sh, но не все являются реализациями POSIX sh.

- `sh` — это оболочка, которая в POSIX-системах должна соответствовать стандарту POSIX Shell Command Language (хотя конкретная реализация может отличаться).
- `bash` — это отдельная оболочка, которая поддерживает POSIX sh-совместимый режим, но по умолчанию использует расширенный язык Bash.
- `zsh` — тоже имеет много совместимого с sh синтаксиса, но является отдельным shell-языком.

</Callout>

## Что можно делать с помощью Shell

- Просматривать файлы и папки.
- Создавать, копировать, перемещать и удалять файлы.
- Запускать программы.
- Устанавливать программное обеспечение.
- Автоматизировать задачи с помощью сценариев (скриптов).

## Список командых оболочек

| Shell                 | Операционная система | Особенности                                                                                                 | Пример запуска |
| --------------------- | -------------------- | ----------------------------------------------------------------------------------------------------------- | -------------- |
| **sh (Bourne Shell)** | Unix, Linux          | Первая широко распространенная Unix-оболочка. Простой синтаксис, поддержка скриптов, высокая переносимость. | `sh`           |

`sh` (Bourne Shell) — это одна из самых важных командных оболочек, с которой началась история большинства современных Unix-shell.

Несмотря на возраст, `sh` остается актуальной, потому что:

- многие системные скрипты пишутся в стандарте **POSIX sh**;
- практически в любой Unix-подобной системе есть команда `sh`;
- скрипты на `sh` обычно работают на разных системах без изменений.

| Shell                                 | Операционная система  | Особенности                                                                 | Пример запуска          |
| ------------------------------------- | --------------------- | --------------------------------------------------------------------------- | ----------------------- |
| **Bash (Bourne Again Shell)**         | Linux, macOS          | Самая популярная оболочка, поддерживает скрипты и автоматизацию             | `bash`                  |
| **Zsh (Z Shell)**                     | Linux, macOS          | Улучшенное автодополнение, удобная настройка, поддержка плагинов            | `zsh`                   |
| **Fish (Friendly Interactive Shell)** | Linux, macOS          | Дружелюбный интерфейс, подсказки и автодополнение «из коробки»              | `fish`                  |
| **PowerShell**                        | Windows, Linux, macOS | Работает с объектами, мощная автоматизация и администрирование              | `pwsh` или `powershell` |
| **Command Prompt (cmd.exe)**          | Windows               | Классическая командная строка Windows, поддерживает пакетные (`.bat`) файлы | `cmd`                   |
| **KornShell (ksh)**                   | Unix, Linux           | Используется в Unix-системах, сочетает возможности Bourne Shell и C Shell   | `ksh`                   |
| **Tcsh (TENEX C Shell)**              | Unix, Linux           | Улучшенная версия C Shell с историей команд и автодополнением               | `tcsh`                  |

## Чем Shell отличается от терминала?

- Терминал — это программа (окно), в котором вы работаете.
- Shell — это программа, которая принимает и выполняет команды внутри терминала.

Например, в Linux вы открываете приложение Терминал, а внутри него обычно запускается `Bash` или `Zsh`.

## Исполняемые команды

Отдельные исполняемые файлы: `cat`, `mkdir`, `ls` и др. Они являются частью набора Unix-утилит (часто GNU Coreutils в Linux) и никак не относятся к Shell.

Есть команды, которые принадлежат самой оболочке - `builtin commands`

| Команда   | Обычно builtin?                  |
| --------- | -------------------------------- |
| `cd`      | да                               |
| `export`  | да                               |
| `alias`   | да                               |
| `set`     | да                               |
| `unset`   | да                               |
| `history` | часто да                         |
| `echo`    | часто да (но есть и `/bin/echo`) |
| `pwd`     | часто да                         |
