— это одна из самых старых и базовых командных оболочек Unix/Linux. Она позволяет пользователю взаимодействовать с операционной системой через текстовые команды, а также писать сценарии (скрипты), которые автоматически выполняют последовательности действий.

## Scripting

Структура хорошего скрипта

```bash
#!/bin/sh

set -e

# Константы

# Функции

# Основной код

```

### Shebang

— это первая строка в скрипте, которая указывает операционной системе, каким интерпретатором нужно выполнять файл.

```bash
#!/bin/sh
```

```bash
#!/bin/bash
```

ОС читает первую строку и понимает: «этот файл нужно передать программе `/bin/sh`».

:::tip
Фактически запуск похож на:

```bash
/bin/sh ./script.sh
```

:::

#### Вариант через `env`

```bash
#!/usr/bin/env sh
```

Причина: `env` ищет программу через PATH, поэтому скрипт может быть более переносимым между системами.
