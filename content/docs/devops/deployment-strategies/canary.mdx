title: "Canary Deployment"
---

Канареечный Deploy (Canary Deployment) — это способ обновления программного обеспечения, при котором новая версия приложения постепенно запускается для небольшой части пользователей.

<Callout title='Главная идея' type='tip'>

Не обновлять приложение сразу для всех, а сначала проверить новую версию на небольшой группе пользователей.

</Callout>

<div className="hr-decor">✦</div>

## Функции Canary Deployment

- **Безопасность**: меньше пользователей затронуты, если новая версия сломается.
- **Тестирование в реальных условиях**: можно проверить приложение на настоящем трафике.
- **Быстрый откат**: при проблемах можно вернуть старую версию.
- **Минимизация простоев**: приложение продолжает работать во время обновления.

<div className="hr-decor">✦</div>

## Как это работает? (Пример)

Представим, что у тебя есть приложение и ты хочешь выпустить новую версию.

1. Старая версия работает для 100% пользователей.
2. Ты разворачиваешь новую версию для 5% пользователей.
3. Проверяешь, нет ли ошибок, сбоев и проблем с производительностью.
4. Если всё хорошо, увеличиваешь долю пользователей до 20%, 50%, а затем 100%.
5. Если обнаруживаются ошибки, переключаешь пользователей обратно на старую версию.
