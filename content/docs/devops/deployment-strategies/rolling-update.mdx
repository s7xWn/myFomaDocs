title: "Rolling Update"
---

Rolling Update (постепенное обновление) — это способ обновления приложения или сервиса, при котором новые версии запускаются постепенно, без одновременной остановки всех старых экземпляров.

<div className="hr-decor">✦</div>

## Преимущества Rolling Update

1. Минимальный downtime — приложение продолжает работать во время обновления.
2. Постепенное внедрение — можно проверить работу новой версии на части экземпляров.
3. Контроль обновления — при проблемах обновление можно остановить.
4. Экономия ресурсов — не требуется запускать отдельную полную инфраструктуру для новой версии.

<div className="hr-decor">✦</div>

## Как это работает? (Пример)

До обновления

```
[Pod 1 ] [Pod 2 ] [Pod 3 ] [Pod 4 ]
[  v1  ] [  v1  ] [  v1  ] [  v1  ]
```

В процессе обновления

```
{Pod 1 } [Pod 2 ] [Pod 3 ] [Pod 4 ]
{  v2  } [  v1  ] [  v1  ] [  v1  ]
```

После обновления

```
[Pod 1 ] [Pod 2 ] [Pod 3 ] [Pod 4 ]
[  v2  ] [  v2  ] [  v2  ] [  v2  ]
```
