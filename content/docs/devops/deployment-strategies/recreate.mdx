Recreate Deployment (стратегия пересоздания) — это стратегия деплоя, при которой старая версия приложения полностью останавливается и удаляется, а затем разворачивается новая версия.

<div className="hr-decor">✦</div>

## Преимущества и недостатки

### Преимущества

- Простая реализация.
- Не нужно поддерживать одновременно две версии приложения.
- Не требуется сложная инфраструктура.
- Нет проблем совместимости между версиями во время переключения.

### Недостатки:

- Возникает downtime (время простоя приложения).
- Если новая версия не запустилась, приложение останется недоступным.
- Откат на предыдущую версию требует повторного деплоя старой версии.

<div className="hr-decor">✦</div>

## Как это работает? (Пример)

1. Старая версия работает
2. Старая версия останавливается
3. Устанавливается новая версия
4. Новая версия работает
