## Cluster/Кластер

Кластер — это группа отдельных компьютеров (или серверов), которые работают вместе как одна система.

<details>
  <summary>Пример</summary>

Представим, есть одна большая задача, но один компьютер не справляется с ней самостоятельно. <br/>
Берём несколько компьютеров и объединяем их в команду. <br/>
Каждый компьютер выполняет свою часть работы, но вместе они решают общую задачу. <br/>
Вот такую группу компьютеров и называют кластером.

</details>

### Kubernetes-кластер

Kubernetes — это система, которая управляет группой серверов и распределяет между ними работу.

<details>
  <summary>Пример сайт, на который одновременно заходят 10 000 человек.</summary>

Вместо того чтобы запускать весь сайт на одном сервере, можно использовать несколько серверов:

- Сервер №1 обслуживает часть посетителей.
- Сервер №2 обслуживает другую часть.
- Сервер №3 обслуживает ещё одну часть.

А Kubernetes следит за тем, чтобы всё работало правильно:

- распределяет приложения между серверами;
- запускает приложения;
- перезапускает их, если что-то сломалось;
- добавляет дополнительные ресурсы при необходимости.

</details>

## Node

Node — отдельный элемент или узел какой-либо системы, который связан с другими элементами.

1.  Компьютерные сети <br/>
    Каждый компьютер, сервер, маршрутизатор или другое устройство в сети может называться Node.

2.  Kubernetes <br/>
    Node — это сервер (физический или виртуальный), на котором Kubernetes запускает приложения.
