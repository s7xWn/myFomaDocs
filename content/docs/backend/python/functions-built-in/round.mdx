— это встроенная функция для округления чисел.

```python
round(число, количество_знаков)
```

## Banker's rounding (округление .5)

Python использует "банковское округление" (округление к ближайшему чётному).

Поэтому `round(2.5)` будет `2`, а `round(3.5)` будет `4`. Это сделано для уменьшения ошибки при суммировании больших массивов данных.
