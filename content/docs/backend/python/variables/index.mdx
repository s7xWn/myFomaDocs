---
title: "Переменные"
---

— это имена (идентификаторы), которые ссылаются на объекты (значения) в памяти. Они позволяют хранить данные и использовать их в программе.

В Python переменная создается простым присваиванием значения с помощью оператора `=`.

```Python
имя_переменной = значение
```

> Особенность Python в том, что переменные не имеют фиксированного типа.
> Тип принадлежит объекту, а не переменной. Поэтому одной и той же переменной можно присвоить значение другого типа:
>
> ```Python
> x = 10      # int
> x = "Hello" # теперь x ссылается на строку
> ```

## Правила именования переменных

- Имя должно начинаться с буквы или символа `_`
- Можно использовать буквы, цифры и символ `_`

## Регистр символов

В Python регистр символов имеет значение. Это означает, что заглавные и строчные буквы считаются разными.

```Python
name = "Анна"
Name = "Иван"

print(name)  # Анна
print(Name)  # Иван
```
