— это способы обращаться к элементам последовательностей: получать один элемент или часть последовательности.

Они применимы к многим другим объектам: спискам, кортежам, диапазонам и некоторым пользовательским объектам.

| Тип                     | Индексы               | Срезы   |
| ----------------------- | --------------------- | ------- |

| `list`                  | ✅                    | ✅      |

| `range`                 | ✅                    | ✅      |
| `bytes`                 | ✅                    | ✅      |

| `set`                   | ❌                    | ❌      |

| пользовательские классы | зависит от реализации | зависит |

## Индексы (indexing)

— это номер позиции элемента

:::important
В Python индексация начинается с `0`.
:::

Пример:

```python
text = "Python"

print(text[0])
print(text[1])
print(text[5])
```

### Отрицательные индексы

Python позволяет считать с конца. <br/>
Отрицательные индексы позволяют обращаться к элементам с конца последовательности. Индекс -1 соответствует последнему элементу, -2 — предпоследнему и т.д.

Пример:

```python
text = "Python"

text[-1]  # 'n'
text[-2]  # 'o'
```

<hr />

## Срезы (slicing)

Срез позволяет **взять** часть последовательности.

```python
объект[начало:конец:шаг]
```

:::warning
Если начало не указано, Python автоматически считает, что оно равно `0`.
:::

:::danger[Важно]
Конец не включается.
:::

Пример

```python
text = "Python"

print(text[:3])    # берёт 3 символа с начала | Pyt
print(text[2:])    # берет с символа индекс = 2 до конца | thon
print(text[:])     # копия всей строки | Python
print(text[::2])   # срезает каждый второй символ | Pto
```

:::tip
Можно использовать отрицательные индексы!
:::
