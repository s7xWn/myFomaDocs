---
title: "Тернарный оператор"
---

— это сокращённая форма записи условного выражения `if...else`, которая позволяет выбрать одно из двух значений в зависимости от условия.<br/>
Он позволяет записать простое условие в одну строку.

```js
valueIfTrue if condition else valueIfFalse
```

Тернарный оператор хорошо читается, когда:

- условие короткое и очевидное;
- выбираются только две альтернативы;
- обе ветки возвращают простые значения (строку, число или короткое выражение).

Пример:

```python
age = 18

status = "Взрослый" if age >= 18 else "Несовершеннолетний"

print(status)
```

## Вложенные тернарные операторы

```python
значение1 if условие1 else значение2 if условие2 else значение3
```

```python
(значение1 if условие1 else значение2) if условие2 else значение3
```

Тернарный оператор можно вкладывать, но это быстро ухудшает читаемость. Вложенность допустима, если логика остается понятной.

```python
score = 85

grade = "A" if score >= 90 else "B" if score >= 75 else "C"

print(grade) # B
```
