# `if` .. `else`

Для сравнения используются [логические операторы](../operators/logical) и [операторы сравнения](../operators/compare).

## `if`

— это условный оператор. Он выполняет код только тогда, когда условие истинно (`true`).

```Python
if условие:
  блок команд 1
```

<hr />

## else

```Python
if условие:
  блок команд 1
else:
  блок команд 2
```

— позволяет выполнить другой код, если условие ложно (`false`).

<hr />

## `else if` - цепочка проверок

```Python
if условие:
    if условие:
       блок команд 1
    else:
       блок команд 2
else:
    if условие:
       блок команд 3
    else:
       блок команд 4
```

<hr />

## `elif` - множественный выбор

— когда нужно проверить несколько условий по очереди.

```Python
if условие_1:
    # выполняется, если условие_1 истинно
elif условие_2:
    # выполняется, если первое условие ложно, а второе истинно
elif условие_3:
    # выполняется, если первые два ложны, а третье истинно
else:
    # выполняется, если ни одно условие не подошло
```
