# Исключения

В Python есть много встроенных исключений. Они образуют иерархию, где почти все наследуются от `Exception`.

| Исключение            | Когда возникает                                   | Пример                               |
| --------------------- | ------------------------------------------------- | ------------------------------------ |
| `ValueError`          | Значение правильного типа, но некорректное        | `int("abc")`                         |
| `TypeError`           | Неподходящий тип данных                           | `"2" + 2`                            |
| `NameError`           | Переменная не определена                          | `print(x)`                           |
| `IndexError`          | Индекс выходит за границы списка/кортежа          | `[1, 2][5]`                          |
| `KeyError`            | Ключ отсутствует в словаре                        | `{"a": 1}["b"]`                      |
| `AttributeError`      | У объекта нет такого атрибута                     | `"hello".foo`                        |
| `ZeroDivisionError`   | Деление на ноль                                   | `10 / 0`                             |
| `FileNotFoundError`   | Файл не найден                                    | `open("abc.txt")`                    |
| `PermissionError`     | Нет прав на операцию                              | чтение защищённого файла             |
| `ImportError`         | Не удалось импортировать модуль/объект            | `from x import y`                    |
| `ModuleNotFoundError` | Модуль не найден                                  | `import nonexistent`                 |
| `SyntaxError`         | Синтаксическая ошибка в коде                      | `if True print("x")`                 |
| `IndentationError`    | Неправильные отступы                              | смешивание отступов                  |
| `UnboundLocalError`   | Локальная переменная используется до присваивания | особый случай `NameError`            |
| `RuntimeError`        | Общая ошибка времени выполнения                   | когда нет более подходящего типа     |
| `RecursionError`      | Слишком глубокая рекурсия                         | бесконечный рекурсивный вызов        |
| `TimeoutError`        | Операция превысила допустимое время               | сетевые/системные операции           |
| `OSError`             | Ошибка операционной системы                       | работа с файлами, процессами и т. п. |
