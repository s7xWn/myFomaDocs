это модуль (набор готового кода: функций, классов и переменных), который уже входит в стандартную поставку Python и доступен без установки дополнительных библиотек.

## Математика и числа

| Модуль       | Для чего нужен                                    |
| ------------ | ------------------------------------------------- |
| `math`       | математические функции (корни, синусы, логарифмы) |
| `random`     | случайные числа и случайный выбор                 |
| `statistics` | статистика (среднее, медиана и т.д.)              |
| `decimal`    | точные десятичные вычисления                      |
| `fractions`  | работа с дробями                                  |
