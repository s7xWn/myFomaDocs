---
title: "math"
---

— это встроенный модуль (библиотека) для математических вычислений. Он содержит готовые функции и константы: корни, степени, тригонометрию, логарифмы, округление и многое другое.

```python
import math
```

| Функция             | Что делает                                                |
| ------------------- | --------------------------------------------------------- |
| `math.ceil(x)`      | округление вверх                                          |
| `math.trunc(x)`     | отбрасывает дробную часть и возвращает int без округления |
| `math.floor(x)`     | округление вниз                                           |
| ------------------- | --------------------------------------------------------- |
| `math.sqrt(x)`      | квадратный корень                                         |
| `math.pow(x, y)`    | x в степени y                                             |
| `math.factorial(x)` | факториал                                                 |
| `math.sin(x)`       | синус                                                     |
| `math.cos(x)`       | косинус                                                   |
| `math.tan(x)`       | тангенс                                                   |
| `math.log(x)`       | логарифм                                                  |
| `math.fabs(x)`      | модуль числа (абсолютное значение)                        |

| Константа  | Значение            | Описание                                        |
| ---------- | ------------------- | ----------------------------------------------- |
| `math.pi`  | ≈ 3.141592653589793 | число π (отношение длины окружности к диаметру) |
| `math.e`   | ≈ 2.718281828459045 | число Эйлера (основание натурального логарифма) |
| `math.tau` | ≈ 6.283185307179586 | число τ = 2π                                    |
| `math.inf` | `∞`                 | положительная бесконечность                     |
| `math.nan` | `nan`               | "не число" (Not a Number)                       |
