## Устновка

```bash
pip install playwright
```

### Установка браузеров

Сам пакет не содержит браузеры, их нужно загрузить отдельно

Будут установлены Chromium, Firefox и WebKit.

```bash
playwright install
```

Если нужен только Chromium

```bash
playwright install chromium
```
