## Браузер

### Chromium

```python
browser = p.chromium.launch()
```

<hr />

### Firefox

```python
browser = p.firefox.launch()
```

<hr />

### WebKit

```python
browser = p.webkit.launch()
```

<hr />

## `headless` (Запуск с видимым окном)

По умолчанию Playwright работает в headless-режиме. Чтобы увидеть браузер:

```python
browser = p.chromium.launch(headless=False)
```

<hr />

<hr />

## `slow_mo` (Задержку между действиями)

Добавляет задержку между действиями в мс.

```python
browser = p.chromium.launch(
    headless=False,
    slow_mo=500
)
```
