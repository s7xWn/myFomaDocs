title: "parametrize"
---

`parametrize` — специальная возможность pytest, которая позволяет запустить один и тот же тест несколько раз с разными данными.

> «Возьми этот тест и запусти его несколько раз, подставляя разные значения».

```python
import pytest
@pytest.mark.parametrize("param1, param2", [
    (1, 2),
    (3,4),
])
def test_add(param1,param2):
    assert param1 + 1 == param2
```

```python
import pytest
@pytest.mark.parametrize(["param1","param2"], [
    (1, 2),
    (3,4),
])
def test_add(param1,param2):
    assert param1 + 1 == param2
```

:::tip
Каждый выполненый тест (`pytest -v`) каждый набор параметров считается отдельным тест-кейсом. Каждый набор параметров воспринимается как самостоятельный запуска теста.
:::

## **Запуск через консоль**

```bash
pytest test_file.py::test_func[10-11-12]
```

- 10 - первый параметр
- 11 - второй параметр
- 12 - третий параметр
