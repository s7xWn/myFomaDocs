# `xdist`

— это плагин для pytest, который позволяет запускать тесты параллельно на нескольких процессах.

Обычно имеется в виду пакет `pytest-xdist`.

Допустим, у тебя 1000 тестов, и обычный запуск: `pytest` идёт 10 минут. <br/>
С `xdist` можно запустить тесты на нескольких CPU: `pytest -n 4`. Тогда pytest создаст 4 worker-процесса и распределит между ними тесты. В удачном случае 10 минут могут превратиться примерно в 3 минуты.

При последовательном запуске всё может работать, а при `pytest -n 4` возникнет **race condition**: тесты выполняются одновременно и влияют друг на друга.

Поэтому при использовании xdist особенно важно следить за:

- общей БД;
- файлами и временными директориями;
- глобальным состоянием;
- портами;
- фикстурами с `scope="session"`;
- порядком выполнения тестов.

По умолчанию `xdist` использует стратегию, которая динамически раздаёт тесты worker'ам (`load`).

```
pytest
  │
  ├── worker 1 → test_a, test_e, test_i...
  ├── worker 2 → test_b, test_f, test_j...
  ├── worker 3 → test_c, test_g, test_k...
  └── worker 4 → test_d, test_h, test_l...
```

<hr />

## **Установка**

```bash
pip install pytest-xdist
```

<hr />

## **Использование**

### Фиксированное количество процессов

```bash
pytest -n 4
```

### Использовать доступные CPU автоматически

```bash
pytest -n auto
```

### Распределять тесты по файлам

```bash
pytest -n 4 --dist=loadfile
```

`xdist` старается держать тесты одного файла на одном worker'е

```
worker 1 → test_users.py
worker 2 → test_orders.py
worker 3 → test_products.py
worker 4 → test_payments.py
```

|                                       | `pytest -n 4` | `pytest -n 4 --dist=loadfile` |
| ------------------------------------- | ------------- | ----------------------------- |
| Несколько процессов                   | ✅            | ✅                            |
| Параллельное выполнение               | ✅            | ✅                            |
| Возможны race conditions              | ✅            | ✅                            |
| Тесты одного файла держатся вместе    | ❌            | ✅                            |
| Устраняет проблемы с общей БД/файлами | ❌            | ❌                            |
