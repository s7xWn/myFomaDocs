## Установка

Перейти на офф. сайт во кладку [Downloads](https://www.python.org/downloads/)

### Python install manager

### Standalone installer

Запускаем установщие:

1. Поставить галочку _**'Add python.exe to Path'**_
   - она позволит вам сразу в командной строке после установки запускать интерпретатор Python без прописывания полного пути к исполняемому файлу

2. Выбрать _**customize installation**_
3. Выбрать нужные пункты (по двефолту все)
4. Выбрать нужные пункты и путь к папке (`C:\Python314`, вместо `314` можно указать свою версию)
   - associtate files with Python
   - create shortcuts for installed applications
   - add Python to environment variables
