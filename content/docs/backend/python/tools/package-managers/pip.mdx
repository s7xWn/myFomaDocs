---
title: "pip"
---

— это стандартный менеджер пакетов для Python.
Он позволяет устанавливать, обновлять, удалять и управлять сторонними библиотеками (пакетами), которые не входят в стандартную библиотеку Python.

<hr />

## Обновить `pip`

Обновляет `pip` именно для того Python, который запущен командой `python`:

```bash
python -m pip install --upgrade pip
```

Обновляет `pip`, который вызывается командой `pip`:

```bash
pip install --upgrade pip
```

<hr />

## Commands

### `install`

Установка пакета

:::important
Если **не используется виртуальное окружение** и не указан флаг `--user`, пакет устанавливается в глобальный каталог `site-packages`.
:::

```bash
pip install package_name
```

#### `-r`

Установка зависимости из файла

```bash
pip install -r requirements.txt
```

#### `--upgrage`

Обновление пакета

```bash
pip install --upgrade package_name
```

#### `--user`

Установка только для текущего пользователя (пакеты попадут в пользовательскую директорию).

```bash
pip install --user requests
```

<hr />

### `uninstall`

Удаление пакета

```bash
pip uninstall package_name
```

<hr />

### `show`

Информация о пакете

```bash
pip show package_name
```

<hr />

### `list`

Показывает все установленные пакеты в текущем Python-окружении в удобном для человека виде.

```bash
pip list
```

<hr />

### `freeze`

Выводит установленные пакеты в формате, который понимает `pip install -r`.

```bash
pip freeze > requirements.txt
```
