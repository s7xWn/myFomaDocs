# Package managers

| Инструмент | Для чего подходит                              | Особенности                                                              |
| ---------- | ---------------------------------------------- | ------------------------------------------------------------------------ |
| **pip**    | Стандартная установка пакетов                  | Входит в большинство установок Python                                    |
| **uv**     | Очень быстрый менеджер пакетов и окружений     | Написан на Rust, значительно быстрее pip                                 |
| **Poetry** | Управление зависимостями и публикация проектов | Автоматически создаёт виртуальные окружения, использует `pyproject.toml` |
| **PDM**    | Современное управление проектами               | Следует стандартам PEP, может работать без виртуальных окружений         |
| **Hatch**  | Управление проектами, окружениями и сборкой    | Гибкая система плагинов                                                  |
| **Conda**  | Научные вычисления и Data Science              | Устанавливает не только Python-пакеты, но и системные библиотеки         |
| **Pipenv** | Упрощённая работа с виртуальными окружениями   | Объединяет `pip` и `venv`, но сейчас менее популярен                     |
