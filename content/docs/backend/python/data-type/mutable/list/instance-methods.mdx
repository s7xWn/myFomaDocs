# Методы экземпляра

## Добавление элементов

| Метод              | Описание                                             |
| ------------------ | ---------------------------------------------------- |
| `append(x)`        | Добавляет элемент в конец списка.                    |
| `extend(iterable)` | Добавляет все элементы другого итерируемого объекта. |
| `insert(i, x)`     | Вставляет элемент по индексу `i`.                    |

<hr />

## Удаление элементов

| Метод       | Описание                                                                    |
| ----------- | --------------------------------------------------------------------------- |
| `pop([i])`  | Удаляет и возвращает элемент по индексу. Если индекс не указан — последний. |
| `remove(x)` | Удаляет первое вхождение элемента.                                          |
| `clear()`   | Удаляет все элементы списка.                                                |

<hr />

## Поиск элементов

| Метод                      | Описание                                       |
| -------------------------- | ---------------------------------------------- |
| `index(x[, start[, end]])` | Возвращает индекс первого найденного элемента. |
| `count(x)`                 | Считает количество вхождений элемента.         |

<hr />

## Сортировка и изменение порядка

| Метод       | Описание                   |
| ----------- | -------------------------- |
| `sort()`    | Сортирует список на месте. |
| `reverse()` | Разворачивает список.      |

<hr />

## Копирование

| Метод    | Описание                            |
| -------- | ----------------------------------- |
| `copy()` | Создает поверхностную копию списка. |
