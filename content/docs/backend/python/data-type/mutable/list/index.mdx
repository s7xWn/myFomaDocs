---
title: "List"
---

— это упорядоченная коллекция элементов, которая позволяет хранить в одном месте сразу несколько значений. Могут содержать любые объекты Python.

```Python
mixed = [10, "Python", True, 3.14]
```

> `list` в Python похож на массив, но это не совсем массив в классическом смысле.
