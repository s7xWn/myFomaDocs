# Методы экземпляра

## Изменение регистра

| Функция        | Описание                                                               |
| -------------- | ---------------------------------------------------------------------- |
| `lower()`      | в нижний регистр.                                                      |
| `upper()`      | в верхний регистр.                                                     |
| `capitalize()` | первая буква заглавная, а все остальные в нижнем                       |
| `title()`      | каждое слово с заглавной буквы.                                        |
| `swapcase()`   | поменять регистр букв.                                                 |
| `casefold()`   | более агрессивное приведение к нижнему регистру (для сравнения строк). |

<hr />

## Удаление и добавление символов

| Функция                | Описание                                                                                                            |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `strip([chars])`       | Удаляет указанные символы с начала и конца строки. Если аргумент не указан — удаляет пробелы и управляющие символы. |
| `lstrip([chars])`      | Удаляет указанные символы только с начала строки (слева).                                                           |
| `rstrip([chars])`      | Удаляет указанные символы только с конца строки (справа).                                                           |
| `removeprefix(prefix)` | Удаляет указанную начальную часть строки (префикс), если она есть.                                                  |
| `removesuffix(prefix)` | Удаляет указанную конечную часть строки (суффикс), если она есть.                                                   |

<hr />

## Поиск

| Функция                      | Описание                                                                                                                                                                                                          |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `find(sub[, start[, end]])`  | Возвращает индекс первого вхождения подстроки. Если подстрока не найдена — возвращает `-1`.                                                                                                                       |
|                              | `sub` Подстрока, которую нужно найти (обязательный параметр)<br/> `start` Индекс, с которого начинать поиск (необязательно)<br/>`end` Индекс, до которого выполнять поиск не включая этот индекс (необязательно ) |
| `rfind()`                    | Возвращает индекс последнего вхождения подстроки (поиск справа налево). Если подстрока не найдена — возвращает `-1`.                                                                                              |
| `index()`                    | Возвращает индекс первого вхождения подстроки. Если подстрока не найдена — вызывает исключение `ValueError`.                                                                                                      |
| `rindex()`                   | Возвращает индекс последнего вхождения подстроки. Если подстрока не найдена — вызывает исключение `ValueError`.                                                                                                   |
| `count(sub[, start[, end]])` | Возвращает количество вхождений указанной подстроки в строку.                                                                                                                                                     |

## Проверка начала/конца

| Функция                              | Описание                                                                                |
| ------------------------------------ | --------------------------------------------------------------------------------------- |
| `startswith(prefix[, start[, end]])` | Проверяет, начинается ли строка с указанной подстроки. Возвращает `True` или `False`.   |
| `endswith(suffix[, start[, end]])`   | Проверяет, заканчивается ли строка указанной подстрокой. Возвращает `True` или `False`. |

## Проверка свойств строки

| Функция          | Описание                                                                                                                      |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `isalnum()`      | Проверяет, состоит ли строка только из букв и цифр. Возвращает `True`, если строка не пустая и все символы — буквы или цифры. |
| `isalpha()`      | Проверяет, состоит ли строка только из букв.                                                                                  |
| `isascii()`      | Проверяет, содержат ли все символы строки только ASCII-символы (коды от 0 до 127).                                            |
| `isdecimal()`    | Проверяет, состоит ли строка только из десятичных цифр (`0`–`9`).                                                             |
| `isdigit()`      | Проверяет, состоит ли строка только из цифр, включая некоторые специальные числовые символы (например, верхние индексы).      |
| `isnumeric()`    | Проверяет, состоит ли строка только из числовых символов, включая дроби, римские цифры и другие числовые символы Unicode.     |
| `isidentifier()` | Проверяет, может ли строка быть допустимым идентификатором Python (например, именем переменной).                              |
| `islower()`      | Проверяет, есть ли в строке буквы и все они находятся в нижнем регистре.                                                      |
| `isupper()`      | Проверяет, есть ли в строке буквы и все они находятся в верхнем регистре.                                                     |
| `istitle()`      | Проверяет, находится ли строка в формате заголовка (каждое слово начинается с заглавной буквы).                               |
| `isspace()`      | Проверяет, состоит ли строка только из пробельных символов (пробелы, табуляции, переносы строк).                              |
| `isprintable()`  | Проверяет, являются ли все символы строки печатаемыми (не управляющими).                                                      |

## Замена и преобразование

| Функция                      | Описание                                                                                          |
| ---------------------------- | ------------------------------------------------------------------------------------------------- |
| `replace(old, new[, count])` | Заменяет указанную подстроку на другую. Можно указать количество замен.                           |
| `translate(sub)`             | Заменяет символы в строке согласно таблице преобразований, созданной с помощью `maketrans()`.     |
| `str.maketrans()`            | Статический метод класса `str`. Создаёт таблицу преобразований для использования в `translate()`. |
| `expandtabs()`               | Заменяет символы табуляции `\t` на пробелы. Можно указать ширину табуляции.                       |

<hr />

## Разделение

| Функция                         | Описание                                                                                                                 |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `split(sep=None, maxsplit=-1)`  | Разделяет строку на [список](../../mutable/list) подстрок по указанному разделителю. По умолчанию разделяет по пробелам. |
| `rsplit(sep=None, maxsplit=-1)` | Разделяет строку на [список](../../mutable/list) подстрок, начиная поиск разделителя справа налево.                      |
| `splitlines(keepends=False)`    | Разделяет строку по символам конца строки (`\n`, `\r\n`, `\r`) и возвращает [список](../../mutable/list) строк.          |
| `partition(sep)`                | Делит строку на три части по первому вхождению разделителя: до разделителя, сам разделитель и после него.                |
| `rpartition(sep)`               | Делит строку на три части по последнему вхождению разделителя.                                                           |

<hr />

## Объединение

| Функция          | Описание                                                                                                                         |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `join(iterable)` | Объединяет элементы итерируемого объекта (например, списка или кортежа) в одну строку, используя текущую строку как разделитель. |

| Пример                                    | Результат          |
| ----------------------------------------- | ------------------ |
| `" ".join(["Python", "is", "easy"])`      | `"Python is easy"` |
| `",".join(["a", "b", "c"])`               | `"a,b,c"`          |
| `"-".join(("2025", "06", "15"))`          | `"2025-06-15"`     |
| `"".join(["P", "y", "t", "h", "o", "n"])` | `"Python"`         |

## Выравнивание

| Функция                     | Описание                                                                                   |
| --------------------------- | ------------------------------------------------------------------------------------------ |
| `ljust(width[, fillchar])`  | Выравнивает строку по левому краю, добавляя указанные символы справа до заданной длины.    |
| `rjust(width[, fillchar])`  | Выравнивает строку по правому краю, добавляя указанные символы слева до заданной длины.    |
| `center(width[, fillchar])` | Выравнивает строку по центру, добавляя указанные символы с обеих сторон до заданной длины. |
| `zfill(width)`              | Дополняет строку слева нулями (`0`) до указанной длины. Используется часто для чисел.      |

## Форматирование

| Функция                   | Описание                                                                                                                                                                                                                                  |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `format(*args, **kwargs)` | Подставляет значения в строку по указанным заполнителям `{}` и возвращает новую строку. <br/> Позиционные аргументы (`*args`) для подстановки в `{0}`, `{1}` или `{}` <br/> Именованные аргументы (`**kwargs`) для подстановки в `{name}` |

| Пример                                         | Результат        |
| ---------------------------------------------- | ---------------- |
| `"Привет, {}!".format("Мир")`                  | `"Привет, Мир!"` |
| `"{} + {} = {}".format(2, 3, 5)`               | `"2 + 3 = 5"`    |
| `"{name} — {age}".format(name="Анна", age=20)` | `"Анна — 20"`    |
| `"{:.2f}".format(3.14159)`                     | `"3.14"`         |
| `"{:>10}".format("cat")`                       | `"       cat"`   |
