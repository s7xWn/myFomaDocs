# Интернирование строк

Интернирование строк (String Interning) — это механизм оптимизации, при котором Python хранит одну копию неизменяемой строки и повторно использует её вместо создания новых одинаковых объектов.

> Если в программе встречаются одинаковые строки, Python может сохранить один объект строки и дать несколько ссылок на него.

## Вручную интернирование строки

`sys.intern()`

```Python
import sys

a = sys.intern("hello world")
b = sys.intern("hello world")

print(a is b) # True
```

## Обычно интернируются автоматически

Важно: нет строгого списка "все эти строки всегда интернируются", потому что это зависит от версии Python, реализации (например, CPython), места создания строки и оптимизаций компилятора. Но можно привести типичные случаи для CPython.

1. Короткие строки без пробелов и спецсимволов

   ```Python
   a = "hello"
   b = "hello"

   print(a is b)  # True
   ```

2. Строки, похожие на идентификаторы Python
   состоят из:
   - букв;
   - цифр;
   - `_`;

   и не начинаются с цифры.

   ```Python
   a = "user_id"
   b = "user_id"

   print(a is b)  # True
   ```

3. Строковые литералы в одном выражении

   ```Python
    a = "hello" "world"
    b = "helloworld"

    print(a is b)  # True
   ```

4. Ключи словарей (часто выгодно интернировать)

   ```Python
    {
        "name": "Alex",
        "age": 25,
        "email": "a@test.com"
    }
   ```

<hr />

## Обычно НЕ интернируются автоматически

1. Строки с пробелами
2. Строки с пробелами и пунктуацией
3. Длинные строки
4. Строки, созданные во время выполнения

   ```Python
   a = "hello"

   b = "".join(["he", "llo"])

   print(a == b)  # True
   print(a is b)  # False
   ```

5. Строки через форматирование

   ```Python
    a = "hello"

    b = f"{'he'}{'llo'}"

    print(a == b)  # True
    print(a is b)  # False (часто)
   ```

6. Строки с не-ASCII символами
7. Строки с символами, запрещёнными в идентификаторах
