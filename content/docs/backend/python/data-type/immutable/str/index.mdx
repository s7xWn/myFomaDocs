— это тип данных для строк (последовательность символов). Название происходит от английского string — «строка».

Любая операция (замена символа, изменение регистра) создает новую строку в памяти. Это сделано для безопасности и возможности использования строк в качестве ключей в словарях.

```python
my_string = "Строка"
text = 'Привет, мир!'
```

## Многострочные строки (`"""`, `'''`)

В Python тройные кавычки `('''` или `""")` используются для создания многострочных строк. Они позволяют записывать текст на нескольких строках без специальных символов `\n`.

```python
text1 = '''Это строка
из нескольких
строк'''

text2 = """Это тоже строка
из нескольких
строк"""
```

## Специальные символы

| Последовательность | Что означает                          | Пример                    |
| ------------------ | ------------------------------------- | ------------------------- |
| `\n`               | новая строка                          | `"Привет\nМир"`           |
| `\t`               | табуляция                             | `"Имя:\tИван"`            |
| `\\`               | обратный слеш                         | `"C:\\Users"`             |
| `\'`               | одинарная кавычка                     | `'It\'s OK'`              |
| `\"`               | двойная кавычка                       | `"Он сказал: \"Привет\""` |
| `\r`               | возврат каретки                       | `"abc\rX"`                |
| `\b`               | backspace (стереть символ слева)      | `"abc\b"`                 |
| `\a`               | звуковой сигнал (если поддерживается) | `"\a"`                    |
| `\0`               | нулевой символ                        | `"\0"`                    |

## Экранирование `\`

Для вывода символа `\`, надо экранировать: `\\`

<hr />

## `repr()`

Возвращает строковое представление с экранированными символами

## r-строки (Сырые строки)

Иногда нужно, чтобы `\` не воспринимался как специальный символ. Тогда используют r перед строкой:

```python
path = r"C:\Users\Admin\file.txt"

print(path)
```

<hr />

## f-строки (форматированные строки, formatted string literals)

— это способ форматирования строк в Python, который позволяет вставлять значения переменных и выражения прямо внутрь текста.

```python
name = "Иван"
age = 25

text = f"Меня зовут {name}, мне {age} лет"
```

### Дополнительное форматирование `int`

#### Разделение больших чисел

Можно добавить разделители тысяч

```python
number = 1000000

print(f"{number:,}") # 1,000,000
```

<hr />

### Дополнительное форматирование `float`

#### Форматирование чисел после запятой

Количество знаков после запятой

`.nf` - где `n` количество знаков

```python
x = 3.1415926

print(f"{x:.3f}") # 3.142
```

<hr />

### Дополнительное форматирование `str`

#### Выравнивание текста

Используются символы:

- `<` — по левому краю
- `>` — по правому краю
- `^` — по центру

#### Заполнение символами

Можно указать символ заполнения

```python
name = "Python"

print(f"{name:*^10}")
```

<hr />

## Явное приведение типа

### `str()`

```python
str(3.14)      # '3.14'
str(True)      # 'True'
str([1, 2, 3]) # '[1, 2, 3]'
```

<hr />

## Разворот строки в обратном порядке (Reverse)

Самый эффективный способ — через слайс

```python
s[::-1]
```
