# Как компьютер хранит Float и почему `0.1 + 0.2 != 0.3?`

Компьютеры используют стандарт IEEE 754 (двоичное представление чисел с плавающей точкой). Числа вроде 0.1 не могут быть точно представлены в двоичной системе (это бесконечная дробь), поэтому возникают мизерные ошибки округления. В тестах это лечится через `pytest.approx()` или `round()`.
