# int

— тип данных используется для хранения **целых чисел без дробной части**.

:::warning
Тип `int` в Python хранит целые числа в диапазоне от −∞ до +∞.
:::

## "Кэширование малых целых чисел" (Integer Caching)

Python заранее создает объекты для целых чисел в диапазоне от -5 до 256.

Пример:

Если ты создашь две переменные с числом 10, они будут указывать на одну и ту же область в памяти.<br/>
`a = 256; b = 256; a is b` -> `True`<br/>
`a = 257; b = 257; a is b` -> `False` (но `a == b` будет `True`).
