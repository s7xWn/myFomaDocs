## `and` (логическое И)

Возвращает `True`, если оба условия истинны.

```python
x = 10

print(x > 5 and x < 20)   # True
print(x > 5 and x > 20)   # False
```

<hr />

## `or` (логическое ИЛИ)

Возвращает `True`, если хотя бы одно условие истинно.

```python
x = 10

print(x < 5 or x < 20)    # True
print(x < 5 or x > 20)    # False
```

<hr />

## `not` (логическое НЕ)

Инвертирует логическое значение.

```python
x = 10

print(not x > 5)   # False
print(not x < 5)   # True
```
