---
title: "Операторы принадлежности"
---

Membership operators используются для проверки, находится ли элемент внутри другой структуры данных (строки, списка, кортежа, множества, словаря и т. д.).

## `in`

Возвращает `True`, если элемент найден.

## `not in`

Возвращает `True`, если элемента нет.

## Использование в условиях

```Python
password = "python123"

if "123" in password:
    print("Пароль содержит цифры 123")
```
