# Операторы присваивания

| Оператор | Пример    | Эквивалент   |
| -------- | --------- | ------------ |
| `=`      | `x = 5`   | присвоить    |
| `+=`     | `x += 2`  | `x = x + 2`  |
| `-=`     | `x -= 2`  | `x = x - 2`  |
| `*=`     | `x *= 2`  | `x = x * 2`  |
| `/=`     | `x /= 2`  | `x = x / 2`  |
| `//=`    | `x //= 2` | `x = x // 2` |
| `%=`     | `x %= 2`  | `x = x % 2`  |
| `**=`    | `x **= 2` | `x = x ** 2` |
