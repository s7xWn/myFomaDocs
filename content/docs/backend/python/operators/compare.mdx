# Операторы сравнения

Операторы сравнения возвращают логическое значение `True` или `False`. Они используются в условиях (`if` / `elif` / `else`), циклах, фильтрации данных и в любой логике, где нужно сравнить значения.

| Оператор | Название         | Пример     | Результат |
| -------- | ---------------- | ---------- | --------- |
| `==`     | Равно            | `5 == 5`   | `True`    |
| `!=`     | Не равно         | `5 != 3`   | `True`    |
| `>`      | Больше           | `7 > 4`    | `True`    |
| `<`      | Меньше           | `2 < 8`    | `True`    |
| `>=`     | Больше или равно | `10 >= 10` | `True`    |
| `<=`     | Меньше или равно | `3 <= 5`   | `True`    |
