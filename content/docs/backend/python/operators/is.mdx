title: "is"

В Python оператор `is` используется для проверки, являются ли две переменные одним и тем же объектом в памяти.

Возвращает `True` или `False`.

```python
a is b
```

## Пример

```python
a = [1, 2, 3]
b = [1, 2, 3]

print(a is b)
print(a == b)
```

<hr />

## "Кэширование малых целых чисел" (Integer Caching)

Python заранее создает объекты для целых чисел в диапазоне от -5 до 256.

Пример:

Если ты создашь две переменные с числом 10, они будут указывать на одну и ту же область в памяти.<br/>
`a = 256; b = 256; a is b` -> `True`<br/>
`a = 257; b = 257; a is b` -> `False` (но `a == b` будет `True`).

<hr />

## `is` vs `==`

| Оператор | Что проверяет               |
| -------- | --------------------------- |
| `is`     | один ли это объект в памяти |
| `==`     | равны ли значения объектов  |
