# Моржовый оператор

:::warning
В Python появился начиная с версии 3.8
:::

Walrus operator — это оператор присваивания выражению в Python, который записывается как:

```Python
:=
```

Его официальное английское название — **assignment expression operator**, но из-за внешнего сходства `:=` с глазами и бивнями моржа его почти всегда называют **walrus operator**.

Пример (без и с ним):

```Python
name = input("Введите имя: ")

if name:
    print(f"Привет, {name}!")
```

```Python
if (name := input("Введите имя: ")):
    print(f"Привет, {name}!")
```
