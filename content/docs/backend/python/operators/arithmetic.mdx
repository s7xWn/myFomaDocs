# Арифметические операторы

Используются для математических вычислений

| Оператор | Назначение            | Аналог через `math`                | Пример                   | Результат      |
| -------- | --------------------- | ---------------------------------- | ------------------------ | -------------- |
| `+`      | Сложение              |                                    | `5 + 3`                  | `8`            |
| `-`      | Вычитание             |                                    | `5 - 3`                  | `2`            |
| `*`      | Умножение             |                                    | `5 * 3`                  | `15`           |
| `/`      | Деление               |                                    | `5 / 2`                  | `2.5` float    |
| `//`     | Целочисленное деление | math.floor(`a`/`b`)                | `5 // 2` <br/> `5 // -2` | `2` <br/> `-3` |
| `%`      | Остаток от деления    | `a` - math.floor(`a` / `b`) \* `b` | `5 % 2` <br/> `5 % -2`   | `1`<br/> `-1`  |
| `**`     | Возведение в степень  |                                    | `5 ** 2`                 | `25`           |
