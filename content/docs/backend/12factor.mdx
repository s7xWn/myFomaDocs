12Factor (12-factor app) — это методология разработки современных приложений, особенно веб-сервисов и облачных приложений (Cloud Native).

Она описывает 12 принципов, которые помогают создавать приложения, удобные для масштабирования, развёртывания и сопровождения.

|   № | Принцип             | Что означает                                              |
| --: | ------------------- | --------------------------------------------------------- |
|   1 | Codebase            | Одна кодовая база — разные окружения                      |
|   2 | Dependencies        | Зависимости явно объявлены                                |
|   3 | Config              | Конфигурация хранится отдельно от кода                    |
|   4 | Backing Services    | Базы данных и другие сервисы подключаются как ресурсы     |
|   5 | Build, Release, Run | Сборка, релиз и запуск разделены                          |
|   6 | Processes           | Приложение работает как stateless-процессы                |
|   7 | Port Binding        | Приложение самостоятельно предоставляет сервис через порт |
|   8 | Concurrency         | Масштабирование через увеличение числа процессов          |
|   9 | Disposability       | Быстрый запуск и корректное завершение                    |
|  10 | Dev/Prod Parity     | Минимальная разница между Dev и Prod                      |
|  11 | Logs                | Логи — это поток событий                                  |
|  12 | Admin Processes     | Административные задачи выполняются отдельно              |
