---
title: Изменение данных (DML)
---

DML (Data Manipulation Language) — это часть SQL, которая отвечает за изменение данных в таблицах.

Основные DML-команды:

- `INSERT` — добавить строки
- `UPDATE` — изменить существующие строки
- `DELETE` — удалить строки
- `MERGE` — выполнить вставку/обновление в зависимости от условия
