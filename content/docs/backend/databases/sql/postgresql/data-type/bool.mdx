---
title: "`BOOLEAN`"
---

— это логический тип данных, который хранит одно из трёх значений:

- `TRUE` — истина
- `FALSE` — ложь
- `NULL` — значение неизвестно/отсутствует

Помимо `TRUE`/`FALSE`, PostgreSQL умеет распознавать некоторые варианты:

```sql
TRUE
FALSE
'true'
'false'
't'
'f'
'yes'
'no'
'1'
'0'
```
