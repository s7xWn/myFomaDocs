---
title: "`REAL`"
---

Число с плавающей точкой одинарной точности, занимающее 4 байта.

```sql
-3.4 × 10^38  ...  3.4 × 10^38
```

```sql
-3.4028235E+38 ... 3.4028235E+38
```

:::important[Важно]
У `REAL` диапазон очень большой, но точность ограничена примерно 6 десятичными цифрами.
:::

`REAL` может давать небольшие ошибки округления:

```sql
SELECT 0.1::REAL + 0.2::REAL;
```

Результат может отличаться от математического `0.3`. <br/>
Внутри `REAL` это не точное десятичное `0.3`, а ближайшее представимое двоичное число. PostgreSQL может показать `0.3` из-за форматирования результата, хотя фактическое значение немного отличается от `0.3`.
Для денег и точных десятичных вычислений лучше использовать `NUMERIC`, а для более высокой точности плавающей точки — `DOUBLE PRECISION`.

<hr />

## Где использовать

`REAL` подходит для значений, где не требуется абсолютная точность, например:

- температура;
- координаты;
- результаты измерений;
- научные расчёты;
- приблизительные значения.
