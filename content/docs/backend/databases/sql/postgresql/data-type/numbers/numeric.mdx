---
title: "`NUMERIC`"
---

— это тип для точных чисел, особенно когда важна точность: деньги, проценты, измерения и т. п.

Главное отличие от `REAL` и `DOUBLE PRECISION`: `NUMERIC` хранит числа точно, поэтому для финансовых расчётов обычно выбирают именно его.

```sql
NUMERIC(p, s)
```

- **p** — общее количество цифр.
- **s** — количество цифр после десятичной точки.

Если точность и масштаб не указаны:

```sql
NUMERIC
```

PostgreSQL позволяет хранить число с очень высокой точностью, ограниченной возможностями типа NUMERIC.

<hr />

## Пример

```
NUMERIC(10, 2)
         ↑   ↑
         |   └── 2 цифры после точки
         └────── 10 цифр всего
```

Максимальное значение примерно:

```
99999999.99
```
