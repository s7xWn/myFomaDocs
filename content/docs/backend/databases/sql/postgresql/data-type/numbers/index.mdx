---
title: Числовые типы
---

| Тип                | Описание                                          | Где можно использовать                                                  |
| ------------------ | ------------------------------------------------- | ----------------------------------------------------------------------- |
| `SMALLINT`         | Целое число, 2 байта                              | Возраст, количество товаров, рейтинг от 1 до 100                        |
| `INTEGER` / `INT`  | Целое число, 4 байта                              | ID, количество пользователей, количество заказов                        |
| `BIGINT`           | Целое число, 8 байт                               | Большие ID, количество просмотров, счётчики с очень большими значениями |
| `REAL`             | Число с плавающей точкой, 4 байта                 | Научные расчёты, приблизительные измерения, координаты                  |
| `DOUBLE PRECISION` | Число с плавающей точкой двойной точности, 8 байт | Научные и инженерные расчёты, статистика, математические вычисления     |
| `NUMERIC(P,S)`     | Точное десятичное число                           | Цена товара, зарплата, сумма платежа, финансовые расчёты                |
