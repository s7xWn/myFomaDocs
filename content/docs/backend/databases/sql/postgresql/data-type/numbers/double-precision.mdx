---
title: "`DOUBLE PRECISION`"
---

Число с плавающей точкой двойной точности, занимает 8 байт.

```sql
−1.8 × 10^308 ... 1.8 × 10^308
```

```sql
-1.7976931348623157E+308 ... 1.7976931348623157E+308
```

`DOUBLE PRECISION`, как и `REAL`, использует приближённое представление чисел с плавающей точкой.
