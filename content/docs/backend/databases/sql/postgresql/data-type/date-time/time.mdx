---
title: "`TIME`"
---

— это тип данных для хранения времени суток без даты. <br/>
PostgreSQL для `TIME` поддерживает точность до 6 знаков после секунды (микросекунды). <br/>
Внутри PostgreSQL `TIME` хранится как числовое внутреннее представление времени.

```
HH:MI:SS.ffffff
```

TIME хранит:

- часы
- минуты
- секунды
- дробную часть секунды
