---
title: "`CHAR(n)`"
---

— это тип данных для хранения строки фиксированной длины.

`CHAR(n)` дополняет короткие строки пробелами до указанной длины.

:::danger
В PostgreSQL `CHAR` можно использовать без `n`, но тогда это означает `CHAR(1)`.
:::

<hr />

## CHAR(n) vs VARCHAR(n)

```
CHAR(5)     → 'ABC  '
VARCHAR(5)  → 'ABC'
```
