| Тип                   | Пример                     | Для чего используют                          |
| --------------------- | -------------------------- | -------------------------------------------- |
| **String**            | `"hello"`                  | Строки, числа, JSON, токены, счётчики        |
| **List**              | `["a", "b", "c"]`          | Очереди, ленты, списки                       |
| **Set**               | `{"a", "b", "c"}`          | Уникальные значения, множества               |
| **Sorted Set (ZSet)** | `{alice: 100, bob: 250}`   | Рейтинги, leaderboard, сортировка по score   |
| **Hash**              | `{name: "Alex", age: 25}`  | Объекты/структуры                            |
| **Stream**            | последовательность событий | Event log, очереди, обработка событий        |
| **Bitmap**            | набор битов                | Флаги, статистика, tracking                  |
| **HyperLogLog**       | вероятностное множество    | Приблизительный подсчёт уникальных элементов |
| **Geospatial**        | координаты                 | Поиск объектов рядом                         |
| **JSON**              | JSON-документы             | Работа со структурированным JSON             |

- Redis JSON предоставляется через Redis Stack/модуль RedisJSON, а не является базовым типом классического Redis.

<Callout>
  В Redis нет отдельного типа `number`. Для чисел обычно используется тип
  `String`, но Redis умеет атомарно интерпретировать его как целое число и
  выполнять операции над ним.
</Callout>

## Команды

### KEYS

```bash
KEYS pattern
```

| Шаблон   | Значение                                      |
| -------- | --------------------------------------------- |
| `*`      | любое количество любых символов               |
| `user:*` | Получить только ключи, начинающиеся с `user:` |
| `?`      | один любой символ                             |
| `[ae]`   | один символ `a` или `e`                       |
| `[^e]`   | любой символ, кроме `e`                       |
| `[a-z]`  | символ из диапазона                           |

<Callout title="KEYS vs SCAN" type="warn">
Главное, что стоит запомнить:

```bash
KEYS *
```

— простой способ посмотреть ключи, но потенциально опасный на большом production Redis, потому что команда выполняет полный поиск.

Вместо него обычно:

```bash
SCAN 0 MATCH user:*
```

`SCAN` возвращает ключи порциями, поэтому его обычно используют для обхода большого набора ключей.

</Callout>
