title: List

List в Redis — это упорядоченная коллекция строковых значений, где элементы могут повторяться. По сути, это структура данных, похожая на обычный список/очередь.

<hr />

## Основные операции

### LPUSH / RPUSH - добавить слева/справа

### LPOP / RPOP - удалить слева/справа

### LRANGE - получить диапазон

Получает срез списка от и до

```bash
LRANGE key i j
```

- `i` -> начало среза
- `j` -> конец среза

Вывести весь список:

```bash
LRANGE key 0 -1
```

### LLEN - узнать размер

```bash
LLEN key
```

### LMOVE - атомарное перем. одного ел. в другой

```bash
LMOVE source destination LEFT|RIGHT LEFT|RIGHT
```

- удаляет элемент из `source`;
- добавляет его в `destination`.
- `LEFT|RIGHT` с какого края из `source`
- `LEFT|RIGHT` в какой край в `destination`
