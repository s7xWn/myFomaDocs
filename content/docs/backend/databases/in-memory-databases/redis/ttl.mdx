---
title: TTL - Время жизни ключа
---

TTL (Time To Live) в Redis — это время, в течение которого ключ будет существовать, прежде чем Redis автоматически его удалит.

```bash
TTL key
```

**Время выводится в секундах.**

<Callout type="success">

Время жизни ключей по дефолту `-1`

</Callout>

<hr />

## Основные операции

### EXPIRE - устанавливает TTL

**Время указывается в секундах.**

```bash
EXPIRE key 60
```

### PERSIST - убирает TTL

Убирает TTL, сделает ключ постоянным

```bash
PERSIST key
```
