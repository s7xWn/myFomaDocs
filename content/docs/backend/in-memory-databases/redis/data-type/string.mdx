title: String
---

В Redis String — это базовый тип данных, который хранит последовательность байтов: текст, число, JSON, бинарные данные и т. д.

<Callout>
  В Redis нет отдельного типа `number`. Для чисел обычно используется тип
  `String`, но Redis умеет атомарно интерпретировать его как целое число и
  выполнять операции над ним.
</Callout>

<hr />

## Команды

### SET - Записывает значение

```bash
SET keyName "Value"
```

#### SET ... EX - Создаёт ключ с TTL

```bash
SET key value EX 60
```

### GET - Получает значение

Вернёт значение или `nil`

```bash
GET keyName
```

### DEL - Удаляет ключ

```bash
DEL keyName
```

<hr />

## Основные числовые операции

### INCR - увеличить на 1

```bash
INCR key
```

### DECR - уменьшить на 1

```bash
DECR key
```

### INCRBY - увеличить на число

```bash
INCRBY key 5
```

### DECRBY - уменьшить на число

```bash
DECRBY key 5
```

### INCRBYFLOAT - изменить число с плавающей точкой

```bash
INCRBYFLOAT key 0.5
```
