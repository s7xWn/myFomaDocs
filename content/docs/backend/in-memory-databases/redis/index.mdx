Redis — это очень быстрое хранилище данных, которое в основном работает в **оперативной памяти (RAM)**. Его часто используют рядом с основной базой данных, чтобы ускорить приложение.

> Название исторически расшифровывается как REmote DIctionary Server.

По сути, Redis хранит данные в формате «ключ → значение»:

```
"user:123:name" → "Alex"
"cart:123"      → ["apple", "milk"]
"visits"        → 15240
```

<hr />

## Используется

Redis используется в качестве:

- Базы данных
- Кэша
- Брокер сообщений

и др.

## Установка

<Callout>Вместе с `redis-server` установится `redis-cli`</Callout>

### Linux

```bash
sudo apt install redis-server
```

```bash
sudo systemctl start redis-server
```

### Windows

<Tabs groupId="windows" items={["WSL2", "Docker"]}>

  <Tab value="WSL2">
  
  ```bash
  sudo apt install redis-server
  ```

  </Tab>
  
  <Tab value="Docker">
  
  ```bash
    docker run -d \
    --name redis \

  ```
  
  </Tab>
</Tabs>

### MacOS (brew)

```bash
brew install redis
```

Проверить Redis в списке сервисов:

```bash
brew services list
```

Запустить Redis:

```bash
brew services start redis
```

## Подключение

### Docker

```bash
docker exec -it redis redis-cli
```

```bash
docker exec -it redis redis-cli -a mypassword
```

```
docker exec     → выполнить команду внутри запущенного контейнера
-it             → подключить интерактивный терминал
redis            → имя контейнера
redis-cli        → программа-клиент Redis
-a mypassword   → передать пароль для авторизации
```

### Авторизация

Если Redis быд запущен с паролем `command: redis-server --requirepass ${REDIS_PASSWORD}`

```bash
AUTH mypassword
```
