title: NodeJS (JS / TS)
---

Node.js — это среда выполнения JavaScript, которая позволяет запускать JavaScript не только в браузере, но и на сервере, компьютере или в командной строке.

<Callout title="Node.js ≠ JavaScript" type="warn">
  **JavaScript** — язык программирования. <br />
  **Node.js** — среда, в которой JavaScript может выполняться вне браузера.
</Callout>

Например, с Node.js можно создавать:

- веб-серверы и API;
- серверы для чатов и онлайн-приложений;
- системы авторизации;
- приложения, работающие с базами данных;
- консольные программы и автоматизацию;
- инструменты для разработки — например, npm-пакеты.

### Браузер

| Браузер                                        | NodeJS                   |
| ---------------------------------------------- | ------------------------ |
| Интерактивные веб приложения                   | Серверный приожения      |
| [Browser API (WebAPI)](/docs/frontend/web-api) | Node API                 |
| Фрагментация версий                            | Единая версия на сервере |

### Deno

| Deno                  | NodeJS          |
| --------------------- | --------------- |
| ts / js модули        | NPM             |
| Контроль безопасности | Нет ограничений |
| Совместим с браузером | Node API        |

## Простейший сервер на NodeJS

```js
const http = require("http");

const server = http.createServer((req, res) => {
  res.end("Привет из Node.js!");
});

server.listen(3000);
```

После запуска программа начинает слушать порт 3000, и при обращении к серверу возвращает текст.
