---
title: "Глобальные переменные"
---

- `global` — глобальный объект Node.js
- `performance` - объект `Performance` внутри `global`
- `globalThis` — универсальный глобальный объект
- `process` — информация и управление текущим процессом
- `console` — вывод в консоль
- `Buffer` — работа с бинарными данными
