`@nestjs/config` — это официальный пакет для NestJS, который помогает управлять конфигурацией приложения:
читать переменные окружения, хранить настройки в `.env` и получать их в разных частях приложения.

## Подключение - `ConfigModule`

В `app.module.ts` подключить `ConfigModule`:

```ts
import { Module } from "@nestjs/common";
import { ConfigModule } from "@nestjs/config";

@Module({
  imports: [
    ConfigModule.forRoot({
      isGlobal: true,
    }),
  ],
})
export class AppModule {}
```

- `ConfigModule.forRoot()` загружает конфигурацию, в том числе переменные из `.env`.
- `isGlobal: true` позволяет использовать `ConfigService` в других модулях без повторного импорта `ConfigModule`.

<hr />

## Использование - `ConfigService`

`ConfigService` — это специальный сервис NestJS, который помогает получать настройки приложения: переменные окружения, значения из `.env`, конфигурацию базы данных, JWT и т. д.

```ts
import { ConfigService } from "@nestjs/config";
```

### В `main.ts`

```ts
const config = app.get(ConfigService);
```

```ts
const port = config.getOrThrow<Type>("KEY", defValue);
```

### В классах

```ts
constructor(private configService: ConfigService) {}
```

```ts
this.configService.getOrThrow<Type>("KEY", defValue);
```

<Callout type='warn'>

Важный момент: `.getOrThrow<Type>()` не преобразует тип автоматически.

</Callout>

<details>
  <summary>Пример</summary>

```ts
@Injectable()
export class AppService {
  constructor(private configService: ConfigService) {}

  getPort(): number {
    return this.configService.get<number>("PORT", 3000);
  }
}
```

</details>
