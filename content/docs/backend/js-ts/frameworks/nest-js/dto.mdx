DTO (Data Transfer Object) в NestJS — это объект, который описывает формат данных, которые приходят в приложение или уходят из него.

Проще говоря, DTO отвечает на вопрос: «Какие данные и в каком виде мы ожидаем получить?»

<Callout>
  Часто используют [class-validator](../../packages/class-validator.mdx)
</Callout>

```ts
import { IsEmail, IsString, MinLength } from "class-validator";

export class CreateUserDto {
  @IsString()
  name: string;

  @IsEmail()
  email: string;

  @MinLength(6)
  password: string;
}
```

И использовать его в контроллере:

```ts
@Post()
create(@Body() dto: CreateUserDto) {
  return this.usersService.create(dto);
}
```

Теперь `dto` должен соответствовать описанной структуре.

<hr />

## Зачем DTO нужен?

1. Описывает структуру данных
2. Позволяет валидировать входные данные
3. Отделяет API от базы данных

<hr />

## Расположение и название файла

- Создать папку `dto/` внутри модуля
- Назвать `[[Operation]Entity].dto.ts`
  - `login.dto.ts`
  - `create-habit.dto.ts`
