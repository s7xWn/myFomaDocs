— это современный фреймворк для разработки серверных приложений на Node.js, построенный поверх Express (по умолчанию) или Fastify. Он написан на TypeScript и вдохновлен архитектурой Angular: использует модули, внедрение зависимостей (Dependency Injection) и декораторы.

## Создание приложения

Установить `Nest CLI`

```bash
npm install -g @nestjs/cli
```

Создай новый проект

```bash
nest new my-app
```

Во время создания CLI предложит выбрать пакетный менеджер:

- `npm` / `yarn` / `pnpm`

После выбора будут автоматически установлены зависимости.

### Запуск

```bash
npm run start:dev
```
