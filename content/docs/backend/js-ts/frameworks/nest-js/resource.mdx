---
title: Resource
---

— это логически отдельная часть приложения, которая работает с определённым типом данных или сущностью.

В NestJS такой ресурс обычно состоит из нескольких частей:

```
Users Resource
│
├── UsersController → HTTP-запросы
├── UsersService → бизнес-логика
├── UsersModule → объединяет всё
├── DTO → структура входных данных
└── Entity → структура сущности/данных
```

```bash
nest g resource name
```

→ controller + service + module + DTO + entity + CRUD-заготовка.

> Создай мне каркас для работы с ресурсом `name`, включая CRUD.
