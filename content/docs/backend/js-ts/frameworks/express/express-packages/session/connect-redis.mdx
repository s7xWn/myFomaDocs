`connect-redis` — это middleware/адаптер для Node.js, который позволяет хранить сессии Express-приложения в Redis вместо памяти самого Node.js процесса.

Обычно он используется вместе с `express-session`.

## Использование

Тебе не нужно самостоятельно обращаться к Redis при каждом запросе: `express-session` загружает данные сессии из хранилища и сохраняет изменения автоматически. В браузере хранится идентификатор сессии в cookie, а сами данные находятся на сервере, в твоём случае — в Redis.

```ts
import { RedisStore } from "connect-redis";
```

```ts
const redisStore = new RedisStore({
  client: redisClient,
  prefix: "prefix:",
});
```

В `app.use` `session`, в параметр `store`:

```ts
app.use(
  session({
    ...
    store: redisStore,
  }),
);
```
