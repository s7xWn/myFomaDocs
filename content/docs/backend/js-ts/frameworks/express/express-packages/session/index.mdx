## Создание и использование

### Создание

```ts
import session from "express-session";
```

```ts
app.use(
  session({
    secret: "my-secret",
    name: "my-name",
    resave: true,
    saveUninitialized: false,
  }),
);
```

<hr />

### Использование

<Callout title='' type='tip'>

Вручную проверять подпись `cookie` обычно не требуется. `express-session` делает это автоматически

</Callout>

```ts
app.get("/set-session", (req, res) => {
  req.session.username = "Alex";
  req.session.visits = 1;

  res.json({ message: "Сессия создана" });
});

app.get("/get-session", (req, res) => {
  res.json({
    username: req.session.username,
    visits: req.session.visits,
  });
});
```

<hr />

### Использование через Promise

```ts
return new Promise((resolve, reject) => {
  req.session.userId = user.id;
  req.session.save((err) => {
    if (err) {
      return reject(
        new InternalServerErrorException("Не удалось сохранить сессию."),
      );
    }
    resolve({ user });
  });
});
```

<hr />

### Вывод данных

```ts
app.get("/debug-session", (req, res) => {
  console.log("Session ID:", req.sessionID);
  console.log("Session data:", req.session);

  res.json(req.session);
});
```

## Удаление - `req.session.destroy()`

Для удаления сессии в `express-session` используй `req.session.destroy()`.

> Этот метод удалит текущую сессию из Redis через твой `redisStore`.

<details>
  <summary>Пример NestJS</summary>

```ts
@Post('logout')
async logout(@Req() req: Request, @Res() res: Response) {
  await new Promise<void>((resolve, reject) => {
    req.session.destroy((err) => {
      if (err) {
        return reject(
          new InternalServerErrorException(
            'Не удалось удалить сессию.',
          ),
        );
      }

      resolve();
    });
  });

  res.clearCookie(config.getOrThrow<string>('SESSION_NAME'));

  return res.json({ message: 'Вы вышли из системы' });
}
```

или

```ts
public async logout(req: Request, res: Response): Promise<void> {
  await new Promise<void>((resolve, reject) => {
    req.session.destroy((err) => {
      if (err) {
        return reject(
          new InternalServerErrorException('Не удалось удалить сессию.'),
        );
      }

      resolve();
    });
  });

  res.clearCookie(this.config.getOrThrow<string>('SESSION_NAME'));
  res.status(200).json({ message: 'Вы вышли из системы' });
}
```

</details>

## `express-session.d.ts`

`express-session.d.ts` обычно нужен для TypeScript, чтобы описать или расширить типы, связанные с `express-session`.

<Callout>
  `.d.ts` — это файл деклараций типов. Он не содержит выполняемого
  JavaScript-кода. Он нужен компилятору TypeScript, чтобы знать, какие типы
  существуют.
</Callout>

<details>
  <summary>Пример</summary>

Например, если ты хочешь добавить свои поля в `req.session`:

```ts
req.session.userId = 123;
req.session.isAdmin = true;
```

TypeScript по умолчанию не знает о `userId` и `isAdmin`. В `express-session.d.ts` можно сделать module augmentation:

```ts
import "express-session";

declare module "express-session" {
  interface SessionData {
    userId: number;
    isAdmin: boolean;
  }
}
```

После этого TypeScript понимает:

```ts
req.session.userId; // number
req.session.isAdmin; // boolean
```

</details>
