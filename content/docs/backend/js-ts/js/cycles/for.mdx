---
title: for
---

— это цикл, который позволяет выполнить блок кода несколько раз.

```js
for ([инициализация счетчика]; [условие]; [изменение счетчика]){

    // действия
}
```

1. **Инициализация** — выполняется один раз перед началом цикла.
2. **Условие** — проверяется перед каждой итерацией. Если `true`, цикл продолжается.
3. **Изменение** — выполняется после каждой итерации.

При этом можно опускать различные части объявления цикла

```js
let i = 0;
for (; i < 60; ) {
  console.log(i);
  i = i + 10;
}
```
