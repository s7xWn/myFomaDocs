— это цикл, который используется для перебора **значений** итерируемых объектов (массивов, строк, `Map`, `Set`, и т.д.).

```js
for (const element of iterable) {
  // тело цикла
}
```

<details>
<summary> Производительность </summary>

Теоретически:

- `for` чуть быстрее
- `for...of` чуть медленнее

Причина:

- `for` — прямой доступ по индексу `arr[i]`
- `for...of` — использует итератор (**iterator protocol**)

Но в реальности:

- современные движки (V8 в Chrome / Node.js) сильно оптимизируют оба варианта
- разница часто микроскопическая или нулевая
- `console.log()` внутри цикла намного медленнее самого цикл

</details>

## Отличие от `for...in`

| Цикл       | Что перебирает       |
| ---------- | -------------------- |
| `for...of` | значения (values)    |
| `for...in` | ключи/индексы (keys) |

```js
const arr = [10, 20, 30];

for (const i in arr) {
  console.log(i); // 0, 1, 2 (индексы)
}

for (const v of arr) {
  console.log(v); // 10, 20, 30 (значения)
}
```
