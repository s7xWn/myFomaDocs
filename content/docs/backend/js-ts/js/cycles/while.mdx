---
title: while
---

— это цикл, который выполняет код до тех пор, пока условие истинно (true).

```js
while (condition) {
  // код, который повторяется
}
```

`while` удобно применять, когда заранее неизвестно, сколько раз должен выполниться цикл. Например:

- ждать корректный ввод пользователя;
- обрабатывать данные до определенного условия;
- выполнять повторяющиеся действия, пока не достигнута нужная цель.

Если же количество повторений известно заранее (например, нужно выполнить код 10 раз), чаще используют цикл for.

:::important
Всегда используйте альтернативы циклу while, которые лучше подходят под задачу.

Например, у массивов есть много удобных методов: `forEach()`, `filter()`, `map()`. Они лучше читаются и содержат меньше кода.
:::

## Бесконечный цикл

```js
while (true) {
  // код, который повторяется
}
```
