---
title: Управление циклами (`continue`, `break`)
---

Под «управлением циклами» обычно понимают способы влиять на ход выполнения цикла. Два основных оператора для этого — `break` и `continue`. <br/>
`break` и `continue` работают только для ближайшего (внутреннего) цикла. <br/>
Чтобы выйти из всех циклов используют метку (label) или выносят логику в функцию и делают `return` или исполоьзуют флаг.

## continue

— пропустить текущую итерацию

Когда выполняется `continue`, текущая итерация завершается, а цикл переходит к следующей. <br/>
Пример цикла вывода чисел от 1 до 5, но на 3 должен сработать `continue`:

```js
for (let i = 1; i <= 10; i++) {
  if (i === 3) {
    continue;
  }

  console.log(i);
}

// 1 2 4 5
```

## break

— полностью прервать цикл

Когда выполняется `break`, цикл немедленно завершается, и выполнение программы продолжается после него. <br/>
Пример цикла вывода чисел от 1 до 10, но на 5 должен сработать `break`:

```js
for (let i = 1; i <= 10; i++) {
  if (i === 5) {
    break;
  }

  console.log(i);
}

// 1 2 3 4
```

## Выходы из циклов

### Метка (labeled statements)

Метка (label) в JavaScript создаётся очень просто: идентификатор + двоеточие перед циклом или блоком кода. <br/>
Метку можно использовать как с `break`, так и с `continue`. Для обычного блока `{}` доступен только `break`.

```js
labelName: statement;
```

```js
labelName:
for (...) {
    ...
}
```

Пример:

```js
outer: for (let i = 0; i < 3; i++) {
  console.log("i:" + i);
  for (let j = 0; j < 3; j++) {
    console.log("j:" + j);
    if (j === 1) {
      break outer;
    }
  }
}

console.log("После циклов");
// i:0 j:0 j:1 После циклов
```

### Флаг

```js
let found = false;

for (let i = 0; i < 3 && !found; i++) {
  for (let j = 0; j < 3 && !found; j++) {
    for (let k = 0; k < 3; k++) {
      if (условие) {
        found = true;
        break;
      }
    }
  }
}
```
