---
title: Арифметические операторы
---

Используются для математических вычислений

| Оператор | Описание             | Пример       |
| -------- | -------------------- | ------------ |
| `+`      | сложение             | `2 + 3 = 5`  |
| `-`      | вычитание            | `5 - 2 = 3`  |
| `*`      | умножение            | `2 * 3 = 6`  |
| `/`      | деление              | `6 / 2 = 3`  |
| `%`      | остаток от деления   | `7 % 3 = 1`  |
| `**`     | возведение в степень | `2 ** 3 = 8` |
