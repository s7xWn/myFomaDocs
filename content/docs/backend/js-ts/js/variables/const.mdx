---
title: const
---

:::warning
Появился в версии EcmaScript 2015 года (ES6)
:::

`const` — ключевое слово языка для объявления констант. Константа — переменная, значение которой нельзя переназначить.

:::tip
Если **константа** хранит _массив_ или _объект_, то сам массив/объект изменять можно! Нельзя заменить один объект на другой. Это происходит из-за того, что константа хранит **_ссылку на сложное значение_**, а не само значение.
:::

:::tip
Используйте **ALL_CAPS** формат именования, если нужно объявить константу, которая хранит важное значение для программы.
:::

<hr />

## Область видимости (Scope)

Обладает **блочной областью видимости**. <br/>
Переменные, объявленные с помощью `const`, доступны только **внутри блока**, в котором они объявлены.

```js
function scopeEx() {
  if (true) {
    var funScope = "var";
    let blockScope = "let";
    const blockConst = "const";
  }
  console.log(funScope); // var
  console.log(blockScope); // RefError
  console.log(blockConst); // RefError
}
```

### Всплытие (Hoisting)

Все переменные в JavaScript **“поднимаются”** к верхушке своей области видимости. `const` попадет в так называемую **"временную мертвую зону" (TDZ)** до тех пор, пока не будут инициализированы явно в коде.

```js
console.log(z); // referr, cannot access before init
const z = 15;
```

### Переопределение и объявление

`const` - Не позволяет повторное объявление переменной и требует инициализации при объявлении.

```js
const c = 1;
const c = 2; // error
```

`const` - не позволяет изменять значение переменной после инициализации (хотя свойства объектов, объявленных через `const`, могут изменяться).

```js
const f = 1;
f = 2; //error

const g = { value: 42 };
g.value = 50; // ok
```
