---
title: Тернарный оператор `? :`
---

:::warning
Появился в версии ECMAScript 1 (ES1), опубликованной в 1997 году.
:::

— это сокращённая форма записи условного выражения `if...else`, которая позволяет выбрать одно из двух значений в зависимости от условия.<br/>
В отличие от `if/else`, тернарный оператор является выражением, то есть возвращает значение.
Это удобно, когда нужно именно “вычислить результат”, а не выполнить набор команд.

```js
condition ? valueIfTrue : valueIfFalse;
```

Тернарный оператор хорошо читается, когда:

- условие короткое и очевидное;
- выбираются две альтернативы;
- обе ветки возвращают простые значения (строка, число, короткое выражение).

Пример:

```js
let age = 20;
let status = age >= 18 ? "Взрослый" : "Ребёнок";
```

## Вложенные тернарные операторы

Тернарный оператор можно вкладывать, но это быстро ухудшает читаемость. Вложенность допустима, если логика остается понятной.

```js
const temp = 18;

const state = temp >= 25 ? "hot" : temp >= 15 ? "warm" : "cold";

console.log(state); // "warm"
```
