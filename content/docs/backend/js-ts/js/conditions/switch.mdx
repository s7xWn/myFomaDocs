---
title: switch
---

— это оператор выбора, который позволяет выполнять разный код в зависимости от значения переменной или выражения.
Он часто используется вместо длинной цепочки `if...else if...else`.

В круглых скобках указывается переменная, значение которой сравнивается. <br/>
В фигурных скобках с помощью ключевого слова `case` указываются возможные значения и код, который нужно выполнить.

:::important
Сравнение в `switch` происходит через строгое равенство (`===`)
:::

```js
switch (var) {
  case 1:
    //
    break;

  case 2:
    //
    break;

  default:
    //
}
```

Если внутри кейса нужно создать переменную, то придётся добавить фигурные скобки, иначе JavaScript упадёт с ошибкой:

```js
switch (variable) {
  case 5: {
    const myVar = "Hello";
  }
}
```

:::tip
Если в вашем свитче меньше трёх кейсов, то `if...else` будет читаться проще.
:::

## `break`

— это оператор, который немедленно прекращает выполнение текущей конструкции.

Если вы забыли поставить `break`, то будут выполнены все команды, начиная со сработавшего кейса и до тех пор, пока либо не встретится `break`, либо не закончится `switch`.

## `default`

— это блок в операторе `switch`, который выполняется, если ни один case не подошел. Его можно сравнить с `else` в конструкции `if...else`.

Располагается `default` чаще всего — в конце, хотя JavaScript позволяет разместить его и в другом месте. Для читаемости кода рекомендуется писать его последним.
