Работает автоматически, нет возможности запустить самому <br/>
Алгоритм работы - Mark and Sweep

## Mark and Sweep

- **Отметка (Marking)** - сначала сборщик мусора проходит по всем объектам, к которым есть доступ от корневых объектов (например, глобальные переменные и текущий стек вызовов), и помечает их как "достижимые".
- **Удаление (Sweeping)** - затем сборщик мусора проходит по всей памяти и освобождает память для объектов, которые не были помечены как "достижимые".
