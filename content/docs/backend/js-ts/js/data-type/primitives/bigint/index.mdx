---
title: bigint
---

— это примитивный тип для работы с очень большими целыми числами, которые выходят за пределы `number`. <br/>
**Только целые числа. Нельзя смешивать с number.**

```js
let big = 12345678901234567890n;
let big2 = BigInt("12345678901234567890");
```

:::danger
`BigInt` нельзя смешивать с `Number` без явного приведения:

```js
10n + 5; // ❌ TypeError
```

:::

В JavaScript тип number безопасно хранит числа только до `2^53 - 1`

```js
Number.MAX_SAFE_INTEGER;
// 9007199254740991
```

Где используется:

- Криптография
- Работа с блокчейном
- Финансовые системы
- Большие идентификаторы
- Математические вычисления

## Явное приведение типа

### `BigInt()`

Строка должна быть целым числом, дроби нельзя!

```js
BigInt(123); // 123n
BigInt("123"); // 123n
```

### Суффикс `n`

```js
123n - 456n;
```
