---
title: "null"
---

— это примитивное значение и тип, которое означает: **"Значение намеренно отсутствует"**
То есть мы специально указали, что здесь нет данных.

> Это примитив (но есть исторический нюанс)
>
> `typeof null;` -> `"object"`
>
> Это старый баг JavaScript, который нельзя исправить. Несмотря на это — `null` является примитивом, а не объектом.
