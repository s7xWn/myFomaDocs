**Promise** — это объект, который представляет результат асинхронной операции: он появится позже (успех) или операция завершится ошибкой.
У Promise есть три основных состояния:

- pending — операция ещё не завершена
- fulfilled — всё прошло успешно
- rejected — произошла ошибка

На `promise` можно навешивать колбэки двух типов:

- `onFulfilled` – срабатывают, когда `promise` в состоянии «выполнен успешно».
- `onRejected` – срабатывают, когда `promise` в состоянии «выполнен с ошибкой».

```js
var promise = new Promise(function (resolve, reject) {
  // Эта функция будет вызвана автоматически
  // В ней можно делать любые асинхронные операции,
  // А когда они завершатся — нужно вызвать одно из:
  // resolve(результат) при успешном выполнении
  // reject(ошибка) при ошибке
});
```

После вызова `resolve`/`reject` промис уже не может «передумать».

```js
let promise = new Promise((resolve, reject) => {
  // через 1 секунду готов результат: result
  setTimeout(() => resolve("result"), 1000);

  // через 2 секунды — reject с ошибкой, он будет проигнорирован
  setTimeout(() => reject(new Error("ignored")), 2000);
});

promise.then(
  (result) => alert("Fulfilled: " + result), // сработает
  (error) => alert("Rejected: " + error), // не сработает
);
```

## Методы экземпляра

### then

`.then()` принимает функцию, которая получит результат, когда Promise выполнится успешно. <br/>
Каждый `.then()` возвращает новый `Promise`, он станет результатом следующего `.then()`.

```js
promise.then(onFulfilled, onRejected);

// onFulfilled сработает при успешном выполнении
promise.then(onFulfilled);
// onRejected сработает при ошибке
promise.then(null, onRejected);
```

### catch

`.then(null, onRejected)` или `.catch(onRejected)` – срабатывает, если Promise завершился с ошибкой.<br/>
Ловит: `reject` и ошибки внутри `.then()`

```js
fetch("/api")
  .then((res) => res.json())
  .catch((err) => {
    console.error(err);
  });
```

`.catch(onRejected)` тоже возвращает `Promise`. Если из `catch` вернуть значение, цепочка продолжится как успешная.

```js
Promise.reject(new Error("Fail"))
  .catch(() => {
    return 0;
  })
  .then((value) => {
    console.log(value); // 0
  });
```

#### throw

Если в функции промиса происходит синхронный `throw` (или иная ошибка), то вызывается `reject`

```js
let p = new Promise((resolve, reject) => {
  // то же что reject(new Error("o_O"))
  throw new Error("o_O");
});

p.catch(alert); // Error: o_O
```

- все последующие `.then()` с обычными обработчиками (`onFulfilled`) пропускаются
- управление передаётся ближайшему `.catch()` (или `.then(null, onRejected)`)

### finally

`.finally()` выполняется всегда — и при успехе, и при ошибке.

```js
fetch("/api")
  .then((res) => res.json())
  .catch((err) => console.log(err))
  .finally(() => {
    console.log("Завершено");
  });
```

## Синтаксический сахар `async` / `await`

— это синтаксический сахар над `Promise`, который позволяет писать асинхронный код так, будто он синхронный и более читаемый.

### `async`

Функция, объявленная как async, всегда возвращает Promise:

```js
async function foo() {
  return 42;
}

foo().then(console.log); // 42
```

Фактически это то же самое, что:

```js
function foo() {
  return Promise.resolve(42);
}
```

:::warning
Обратите внимание на `foo()`, который вызывается как `Promise` <br/>
`Promise` вызывался без `()`
:::

### `await`

`await` можно использовать только внутри `async` функции. <br/>
Он останавливает выполнение функции до тех пор, пока `Promise` не выполнится:
:::important
`await` не блокирует весь JS (только текущую `async`-функцию)
:::

```js
function delay(ms) {
  return new Promise((resolve) => setTimeout(resolve, ms));
}

async function run() {
  console.log("Start");

  await delay(2000); // ждём 2 секунды

  console.log("After 2 seconds");
}

run();
```

Дургой пример с `fetch()` <br/>
Без `async`/`await`:

```js
fetch("/api/data")
  .then((res) => res.json())
  .then((data) => {
    console.log(data);
  });
```

С `async`/`await`:

```js
async function getData() {
  const res = await fetch("/api/data");
  const data = await res.json();
  console.log(data);
}
```

Обработка ошибок `try`...`catch`:

```js
async function getData() {
  try {
    const res = await fetch("/api/data");
    const data = await res.json();
    console.log(data);
  } catch (err) {
    console.error("Ошибка:", err);
  }
}
```
