— это встроенная коллекция для хранения пар ключ - значение, похожая на объект (`Object`), но с несколькими важными преимуществами.

```js
const user = new Map();
```

```js
user.set("name", "Alex");
user.set("age", 25);

console.log(user.get("name")); // Alex
```

## Свойства

### map.size

`Map.prototype.size` <br/>
Возвращает количество элементов.

`size` у `Map` — это getter (аксессор) в прототипе. Он каждый раз возвращает текущее внутреннее состояние `Map`

```js
const user = new Map([
  ["name", "Alex"],
  ["age", 25],
]);

user.size; //2
```
