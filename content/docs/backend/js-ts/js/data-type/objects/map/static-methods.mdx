## Map.groupBy(items, callbackFn)

Он группирует элементы массива в Map

```js
const arr = [1, 2, 3, 4, 5, 6];

const grouped = Map.groupBy(arr, (n) => (n % 2 === 0 ? "even" : "odd"));

console.log(grouped);
// Map {
//   "odd" => [1, 3, 5],
//   "even" => [2, 4, 6]
// }
```
