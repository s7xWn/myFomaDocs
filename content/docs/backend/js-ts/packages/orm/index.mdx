---
title: ORM
---

ORM (Object-Relational Mapping) — это технология, которая позволяет работать с базой данных через объекты и классы языка программирования, вместо написания SQL вручную.

| ORM             | Особенности                                                                 |
| --------------- | --------------------------------------------------------------------------- |
| **Prisma**      | Очень популярный, удобный API, отличная типизация                           |
| **TypeORM**     | Классический ORM, похож на Hibernate/JPA                                    |
| **Sequelize**   | Старый и зрелый ORM для Node.js                                             |
| **Drizzle ORM** | Легковесный, SQL-подобный подход, сильная типизация                         |
| **MikroORM**    | Полноценный ORM, хорошо работает с Entity и отношениями                     |
| **Kysely**      | Type-safe SQL query builder; это скорее query builder, чем классический ORM |
