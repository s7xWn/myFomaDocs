`class-validator` — это библиотека для валидации объектов в Node.js/TypeScript с помощью декораторов.

Особенно часто её используют вместе с NestJS.

<Callout>
  Важно: `class-validator` занимается именно валидацией, а не типизацией
  TypeScript. TypeScript проверяет типы во время разработки/компиляции, а
  `class-validator` позволяет проверять данные, пришедшие во время выполнения —
  например, из HTTP-запроса.
</Callout>

## Декораторы

| Декоратор           | Проверяет                 |
| ------------------- | ------------------------- |
| `@IsString()`       | строка                    |
| `@IsInt()`          | целое число               |
| `@IsNumber()`       | число                     |
| `@IsBoolean()`      | boolean                   |
| `@IsEmail()`        | email                     |
| `@IsNotEmpty()`     | не пустое                 |
| `@IsOptional()`     | поле необязательное       |
| `@Min(18)`          | число ≥ 18                |
| `@Max(100)`         | число ≤ 100               |
| `@MinLength(8)`     | строка минимум 8 символов |
| `@IsUUID()`         | UUID                      |
| `@IsDate()`         | Date                      |
| `@IsArray()`        | массив                    |
| `@ValidateNested()` | вложенный объект          |

## `ValidationOptions`

— это общие настройки поведения конкретного валидатора. Они не определяют что проверять, а определяют, как вести себя, если проверка не прошла и в каких случаях её применять.

У большинства декораторов есть возможность передать:

```ts
{
  message?: string;
  groups?: string[];
  always?: boolean;
  each?: boolean;
  context?: any;
}
```

<hr />

### `message`

Сообщение об ошибке.

```ts
@IsString({
  message: 'Имя должно быть строкой',
})
name: string;
```

Если передать функцию:

```ts
@MinLength(8, {
  message: (args) => {
    return `${args.property} должен содержать минимум ${args.constraints[0]} символов`;
  },
})
password: string;
```

`args` — это `ValidationArguments`

В нём можно получить:

```ts
args.value; // значение свойства
args.property; // имя свойства
args.target; // класс
args.object; // объект
args.constraints; // параметры валидатора
```

<hr />

### `groups`

Позволяет объединять валидаторы в группы.

<hr />

### `always`

Обычно валидатор с `groups` выполняется только тогда, когда совпадает группа.

`always: true` говорит:

> выполнять этот валидатор независимо от выбранной группы.
