## Методы

| Метод                    | Что возвращает                          |
| ------------------------ | --------------------------------------- |
| `os.platform()`          | Платформу (`linux`, `win32`, `darwin`)  |
| `os.arch()`              | Архитектуру процессора                  |
| `os.cpus()`              | Массив, каждый элем - информациа о ядре |
| `os.totalmem()`          | Объём оперативной памяти                |
| `os.freemem()`           | Свободную оперативную память            |
| `os.hostname()`          | Имя компьютера                          |
| `os.homedir()`           | Домашнюю директорию пользователя        |
| `os.tmpdir()`            | Путь к временной папке                  |
| `os.userInfo()`          | Информацию о текущем пользователе       |
| `os.networkInterfaces()` | Сетевые интерфейсы                      |
