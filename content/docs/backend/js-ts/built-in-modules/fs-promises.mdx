— это API в Node.js для работы с файловой системой через Promise.

Позволяет читать, создавать, изменять и удалять файлы и папки с `async`/`await`.

С его помощью можно:

- читать файлы;
- создавать и изменять файлы;
- создавать, удалять и переименовывать папки;
- удалять файлы;
- получать информацию о файлах.

## `mkdir()` - Создание папки

— это метод, который создаёт папку (директорию).

<Tabs groupId="modules" items={["ESM", "CommonJS"]}>
  <Tab value="ESM">

    ```js
    await mkdir("folderName");
    ```

  </Tab>
  <Tab value="CommonJS">

    ```js
    ```

  </Tab>
</Tabs>

`folderName` будет относительным путём — он будет интерпретироваться относительно текущей рабочей директории (`process.cwd()`), а не обязательно относительно файла с кодом.

```js
path.resolve(__dirname, "folderName");
```

привяжет путь к расположению относительно расположения текущего JS-файла.
