— это встроенный модуль File System, который позволяет работать с файловой системой компьютера.

<Callout type="tip">
  **Лучше использовать [fs/promise](./fs-promises.mdx)**
</Callout>

С его помощью можно:

- читать файлы;
- создавать и изменять файлы;
- создавать, удалять и переименовывать папки;
- удалять файлы;
- получать информацию о файлах.

```js
const fs = require("fs");
```

```js
import fs from "node:fs";
```

<hr />

## `mkdir()` - Создание папки

— это метод, который создаёт папку (директорию).

```js
fs.mkdir("folderName", (err) => {
  if (err) throw err;

  console.log("Папка создана!");
});
```

`folderName` будет относительным путём — он будет интерпретироваться относительно текущей рабочей директории (`process.cwd()`), а не обязательно относительно файла с кодом.

```js
path.resolve(__dirname, "folderName");
```

привяжет путь к расположению относительно расположения текущего JS-файла.

## `rmdir()` - Удаление папки | Устарел (deprecated)

— это метод модуля `fs`, который удаляет директорию (папку).

```js
fs.rmdir("folderName", (err) => {
  if (err) throw err;

  console.log("Папка удалена");
});
```

<hr />

## `writeFile()` - Создание/перезапись файла

— это метод Node.js, который записывает данные в файл.

<Callout title="Важный момент" type="warn">
  Метод перезаписывает файл
</Callout>

```js
fs.writeFile("file.txt", "Text to write", (err) => {
  if (err) throw err;

  console.log("Файл записан!");
});
```

Если `file.txt` не существует — Node.js создаст его.

## `appendFile()` - Добавление в конец файла

```js
fs.appendFile("file.txt", " ещё текст", (err) => {
  if (err) throw err;

  console.log("Файл дописан!");
});
```
