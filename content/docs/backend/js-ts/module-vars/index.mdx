---
title: "Модульные переменные"
---

| Переменная       | Что означает                              |
| ---------------- | ----------------------------------------- |
| `module`         | текущий модуль                            |
| `module.exports` | то, что модуль экспортирует               |
| `exports`        | сокращённая ссылка на `module.exports`    |
| `require`        | загружает другой модуль                   |
| `__filename`     | путь к текущему файлу(`__dirname`) + файл |
| `__dirname`      | путь к директории текущего файла          |
