</Callout>

## `if`

— это условный оператор. Он выполняет код только тогда, когда условие истинно (`true`).

```go
if condition {
  //code
}
```

## `else`

```go
if condition {
  //code
} else {
  // code
}
```

— позволяет выполнить другой код, если условие ложно (`false`).

## `else if` - цепочка проверок

Если вариантов больше двух, добавляют else if. Проверки идут сверху вниз, выполняется первый подходящий блок.

Пример:

```go
score := 75

if score >= 90 {
    fmt.Println("Отлично")
} else if score >= 70 {
    fmt.Println("Хорошо")
} else if score >= 50 {
    fmt.Println("Удовлетворительно")
} else {
    fmt.Println("Не сдал")
}
```

## Примеры (файл)

```go
package main

import "fmt"

// Условные конструкции
func main() {
	const zero = 0

	// Условие if
	if zero == 0 {
		// true
		fmt.Println("zero is zero")
	}

	// Условие if с блоком else
	if zero == 1 {
		// false
	} else {
		// true
	}

	// Много условий
	if zero == 1 {
		// false
	} else if zero == 2 {
		// false
	} else if zero == 3 {
		// false
	} else {
		// true
	}

	// Тоже самое через Switch
	switch {
	case zero == 1:
		// false
	case zero == 2:
		// false
	case zero == 3:
		// false
	default:
		// true

	}

	//	If с выражением внутри
	if ok := isZero(zero); !ok {
		fmt.Println("Alarm!")
	}
}

func isZero(i int) bool {
	return i == 0
}

```
