Для сравнения используются [логические операторы](../operators/logical.mdx) и [операторы сравнения](../operators/compare.mdx).

<Callout title='' type='warn'>

В Go вокруг условия(condition) нет `()`! <br/>
`{}` обязательны!

</Callout>

## `if`

— это условный оператор. Он выполняет код только тогда, когда условие истинно (`true`).

```go
if condition {
  //code
}
```

## `else`

```go
if condition {
  //code
} else {
  // code
}
```

— позволяет выполнить другой код, если условие ложно (`false`).

## `else if` - цепочка проверок

Если вариантов больше двух, добавляют else if. Проверки идут сверху вниз, выполняется первый подходящий блок.

Пример:

```go
score := 75

if score >= 90 {
    fmt.Println("Отлично")
} else if score >= 70 {
    fmt.Println("Хорошо")
} else if score >= 50 {
    fmt.Println("Удовлетворительно")
} else {
    fmt.Println("Не сдал")
}
```
