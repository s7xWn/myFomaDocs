— это оператор выбора, который позволяет выполнять разный код в зависимости от значения переменной или выражения.
Он часто используется вместо длинной цепочки `if...else if...else`.

В фигурных скобках с помощью ключевого слова `case` указываются возможные значения и код, который нужно выполнить.

```go
switch var {
  case 1:
    //
  case 2:
    //
  default:
    //
}
```

В Go не нужно писать `break` после каждого `case:` он выполняется автоматически.

Можно использовать `switch` вместо большого кол-ва `if else`:

```go
switch {
  case condition1:
    //
  case condition2:
    //
  default:
    //
}
```

<hr />

### `default`

— это блок в операторе `switch`, который выполняется, если ни один case не подошел. Его можно сравнить с `else` в конструкции `if...else`.

Располагается `default` чаще всего — в конце.

<hr />

### `fallthrough`

`fallthrough` — это специальное ключевое слово внутри `switch`, которое позволяет выполнить следующий `case`, даже если его условие не совпадает.

```go
switch var {
  case 1:
    //
    fallthrough
  case 2:
    //
  default:
    //
}
```

Результат: при выполнении `case 1` Go принудительно выполняет следующий `case 2`.

<hr />

## Type Switch

`switch val := v.(type)` называется Type Switch (переключатель типов).

Она позволяет определить, какой конкретный тип данных хранится внутри интерфейса (`interface{}` или `any`), и выполнить соответствующий код.

```go
func checkType(v interface{}) {
    switch val := v.(type) {
    case int:
        fmt.Println("Это int:", val)
    case string:
        fmt.Println("Это string:", val)
    case bool:
        fmt.Println("Это bool:", val)
    default:
        fmt.Println("Неизвестный тип")
    }
}
```

- `v` — переменная типа interface{} или any.
- `.(type)` — специальная конструкция для определения типа значения внутри интерфейса.
- `val` — переменная, которая получает значение с конкретным типом внутри соответствующего case.
