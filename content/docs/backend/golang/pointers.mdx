---
title: "Указатели"
---

Указатель (pointer) — это переменная, которая хранит адрес другой переменной в памяти, а не само значение.

Указатели позволяют работать с данными напрямую через их адрес, изменять значения переменных внутри функций и избегать ненужного копирования данных.

В Go используются два основных оператора:

- `&` — получить адрес переменной.
- `*` — получить значение по адресу (разыменование указателя).

<Callout title='Разница между new() и &' type='tip'>

`new(type)` самостоятельно создаёт переменную, а `&varName` получает адрес уже существующей переменной.

</Callout>

```go
x := 10

p := &x

fmt.Println(x)  // 10
fmt.Println(p)  // адрес переменной x
fmt.Println(*p) // 10
```

- `x` хранит значение `10`.
- `&x` возвращает адрес переменной `x`.
- `p` хранит этот адрес.
- `*p` позволяет получить значение, лежащее по этому адресу.

<hr />

## Изменение значения через указатель

```go
x := 10
p := &x
*p = 50

fmt.Println(x) // 50
```

<hr />

## Указатели в функциях

### Передача параметра

```go
func funcName(varName *type) {
    *varName = value
}

...

func main() {
    funcName(&a)
    fmt.Println(a) // value
}
```

<hr />

### Возврат указателя

```go
func funcName(varName *type) {
    *varName = value
}

...

func main() {
    funcName(&a)
    fmt.Println(a) // value
}
```

## Nil-указатель

В Go указатель может не указывать ни на какую переменную. Такое значение называется `nil`.

В Go `nil` означает отсутствие значения (отсутствие ссылки на объект).

```go
var p *int

fmt.Println(p) // <nil>
```

Если попробовать разыменовать nil: `fmt.Println(*p)` <br/>
Программа завершится с panic.

Поэтому перед использованием указателя часто проверяют его:

```go
if p != nil {
    fmt.Println(*p)
}
```

## Указатели и структуры

Указатели особенно полезны при работе со структурами.

<Callout title="Обрати внимание" type="tip">
  Go позволяет обращаться к полям структуры через указатель без явного `*`.
</Callout>

```go
package main

import "fmt"

type User struct {
    Name string
    Age  int
}

func changeAge(u *User) {
    u.Age = 25
}

func main() {
    user := User{
        Name: "Alex",
        Age:  20,
    }

    changeAge(&user)

    fmt.Println(user.Age) // 25
}
```

## `new()`

`new()` — это встроенная функция Go, которая выделяет память для переменной указанного типа и возвращает указатель на неё.

Проще говоря, `new()` создаёт переменную со значением по умолчанию и возвращает её адрес.

```go
varName := new(type)
```

Что происходит:

1. Выделяется память для переменной типа `type`.
2. Переменная получает нулевое значение.
3. Возвращается указатель `*type`.

<Callout title='Разница между new() и &' type='tip'>

`new(type)` самостоятельно создаёт переменную, а `&varName` получает адрес уже существующей переменной.

</Callout>

<details>
  <summary>Пример</summary>

```go
package main

import "fmt"

func main() {
    p := new(int)

    fmt.Println(p)  // адрес
    fmt.Println(*p) // 0

    *p = 100

    fmt.Println(*p) // 100
}
```

</details>

<hr />

### `new()` с разными типами

```go
a := new(int)    // *int, значение 0
b := new(string) // *string, значение ""
c := new(bool)   // *bool, значение false
```

Со структурами:

```go
type User struct {
    Name string
    Age  int
}

func main() {
    user := new(User)

    user.Name = "Alex"
    user.Age = 25

    fmt.Println(user) // &{Alex 25}
}
```
