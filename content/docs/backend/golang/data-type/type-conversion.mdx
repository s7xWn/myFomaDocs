---
title: "Преобразование типов"
---

В Go преобразование типов — это явное изменение значения одного типа данных в другой.

В отличие от некоторых языков (например, JavaScript или Python), Go не выполняет автоматическое преобразование типов между различными числовыми типами.

Выражение преобразует значение `v` в тип `T`:

```
T(v)
```

<details>
  <summary>Пример</summary>

Здесь `int` преобразуется в `float64`:

```go
package main

import "fmt"

func main() {
    var a int = 10

    var b float64 = float64(a)

    fmt.Println(b) // 10
}
```

</details>

<hr />

## Преобразование числовых типов

<Callout title="" type="warn">
  Важно: при преобразовании `float64` в `int` дробная часть отбрасывается, а не
  округляется.
</Callout>

<hr />

## Преобразование строк и чисел

Для преобразования строк в числа и обратно используется пакет `strconv`.
