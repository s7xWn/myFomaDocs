В языке программирования Go (Golang) `map` — это структура данных, которая хранит пары «ключ — значение» (key-value).

Её можно представить как словарь, где каждому ключу соответствует определённое значение.

```go
var varName map[typeKey]type // Nil map, опасно

// Empty slice
varName := map[typeKey]type{}
varName := make(map[typeKey]type)
```

- `typeKey` — тип ключа.
- `type` — тип значения.

<hr />

## Основные операции

### Инициализация через `make()`

```go
varName := make(map[typeKey]type)
```

<hr />

### Инициализация через литерал

```go
varName := map[typeKey]type{}
```

<hr />

### Получение значения

```go
fmt.Println(varName[typeKeyValue]) // value
```

<hr />

### Добавление нового элемента

```go
varName[typeKeyValue] = value
```

<hr />

### Изменение значения

```go
varName[typeKeyValue] = value
```

<hr />

### Удаление элемента

```go
delete(varName, typeKeyValue)
```

<hr />

### Проверка существования ключа

```go
value, ok := varName[typeKeyValue]

if ok {
    fmt.Println(value)
} else {
    fmt.Println("typeKeyValue не найден")
}
```

<hr />

### Перебор `map` через `for`

Порядок элементов при переборе map в Go не гарантирован.

```go
for typeKeyValue, value := range varName {
    fmt.Println(typeKeyValue, value)
}
```

<hr />

### Получить кол-во элементов `len()`

```go
len(varName)
```

## Старая реализация `map` (до Go 1.24)

В Go старая реализация `map` (до Go 1.24) была построена на основе хеш-таблицы (Hash Table) с использованием бакетов (buckets). <br/>
Главная идея: когда ты добавляешь элемент в map, Go вычисляет хеш его ключа, определяет бакет, в который нужно положить элемент, и сохраняет там пару key-value.

Упрощённо старая реализация выглядела так:

hmap — основная структура

- count — количество элементов
- B — степень двойки, определяющая число бакетов
- hash0 — seed для хеширования
- buckets — массив бакетов
- oldbuckets — старые бакеты при росте
- nevacuate — прогресс переноса элементов

Массив buckets<br/>
Bucket 0<br/>
_До 8 элементов_<br/>
Keys-Values

overflow → следующий

- Один бакет вмещает до 8 пар ключ-значение.
- Если места не хватает, создаётся дополнительный overflow bucket.
- Количество основных бакетов всегда равно \(2^B\).

### Как устроен один bucket

Внутри бакета находятся:

- `tophash` — массив из 8 коротких хешей.
- `keys` — массив из 8 ключей.
- `values` — массив из 8 значений.
- `overflow` — указатель на следующий бакет, если текущий заполнен.

## Новая реализация `map` (Go 1.24+) - Swiss Tables

Начиная с Go 1.24, внутренняя реализация `map` изменилась: вместо старой хеш-таблицы с бакетами и overflow-бакетами используется подход на основе Swiss Tables.

В новой реализации используется другая концепция:

- Map разделяется на группы (groups).
- Каждая группа содержит 8 слотов.
- Для каждого слота хранится короткий фрагмент хеша — H2.
- Отдельно хранится управляющая информация — control bytes.
- При поиске можно проверять сразу несколько слотов одной группы.

## `Nil map`

В Go `nil map` — это map, которая не была инициализирована. Её значение равно `nil`.

Главная особенность: из nil map можно читать данные, но нельзя добавлять или изменять элементы.

```go
var m map[string]int

fmt.Println(m == nil) // true
```

Читать можно:

```go
var m1 map[string]int
var m2 map[string]string
var m3 map[string]bool

fmt.Println(m1["key"]) // 0
fmt.Println(m2["key"]) // ""
fmt.Println(m3["key"]) // false
```
