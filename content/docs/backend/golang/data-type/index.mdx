## Значимые типы (Value Types)

Типы, которые при присваивании копируют своё значение.

| Тип          | Пример                  | Описание                                 |
| ------------ | ----------------------- | ---------------------------------------- |
| `int`        | `var x int`             | Целое число                              |
| `int8`       | `var x int8`            | 8-битное целое число                     |
| `int16`      | `var x int16`           | 16-битное целое число                    |
| `int32`      | `var x int32`           | 32-битное целое число                    |
| `int64`      | `var x int64`           | 64-битное целое число                    |
| `uint`       | `var x uint`            | Беззнаковое целое число                  |
| `uint8`      | `var x uint8`           | 8-битное беззнаковое число               |
| `uint16`     | `var x uint16`          | 16-битное беззнаковое число              |
| `uint32`     | `var x uint32`          | 32-битное беззнаковое число              |
| `uint64`     | `var x uint64`          | 64-битное беззнаковое число              |
| `uintptr`    | `var x uintptr`         | Целое число для хранения адреса          |
| `float32`    | `var x float32`         | Число с плавающей точкой                 |
| `float64`    | `var x float64`         | Число с плавающей точкой                 |
| `complex64`  | `var x complex64`       | Комплексное число                        |
| `complex128` | `var x complex128`      | Комплексное число                        |
| `bool`       | `var x bool`            | Логическое значение                      |
| `string`     | `var x string`          | Строка                                   |
| `array`      | `var x [3]int`          | Массив фиксированной длины               |
| `struct`     | `var x struct{ A int }` | Структура с набором полей                |
| `rune`       | `var x rune`            | Псевдоним `int32`, Unicode-кодовая точка |
| `byte`       | `var x byte`            | Псевдоним `uint8`                        |

## Ссылочные типы и типы с внутренними ссылками

<Callout title='Важно' type='tip'>

В Go нет официальной категории `Reference Types`, как в Java или C#. Таблицы выше описывают поведение типов, а не официальную классификацию языка.

</Callout>

| Тип         | Пример                 | Описание                                              |
| ----------- | ---------------------- | ----------------------------------------------------- |
| `slice`     | `var x []int`          | Дескриптор массива: указатель, длина и capacity       |
| `map`       | `var x map[string]int` | Ссылка на внутреннюю структуру хеш-таблицы            |
| `channel`   | `var x chan int`       | Ссылка на структуру канала                            |
| `function`  | `var x func()`         | Значение функции, может содержать окружение замыкания |
| `pointer`   | `var x *int`           | Указатель на адрес значения                           |
| `interface` | `var x any`            | Хранит динамический тип и значение                    |

## Важные особенности

- В Go все аргументы и присваивания передаются по значению (by value).
- `array` при копировании копирует все свои элементы.
- `slice` при копировании разделяет общий underlying array, если не создана отдельная копия.
- `map` и `channel` при копировании позволяют обращаться к одной внутренней структуре.
- `string` является значимым типом, несмотря на внутреннее представление через указатель и длину.
- `struct` копируется целиком, но его поля могут содержать указатели, slices, maps и другие ссылочные значения.
