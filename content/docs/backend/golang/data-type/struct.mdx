Структура (struct) в Go (Golang) — это пользовательский тип данных, который позволяет объединить несколько переменных (полей) разных типов в одну логическую сущность.

Структура — это способ описать объект, у которого есть несколько характеристик.

```go
type StructName struct {
    field1 string
    field2  int
    field3 string
}
```

## Padding (выравнивание)

Padding (выравнивание) в структурах Go — это дополнительные пустые байты,
которые компилятор добавляет между полями структуры или в её конце,
чтобы правильно выровнять данные в памяти.

<Callout title='' type='tip'>

Компилятор не меняет порядок полей в структуре и не может оптимизировать padding

</Callout>

<details>
  <summary>Пример</summary>

Представим структуру:

```go
type Example struct {
    a bool
    b int64
    c bool
}
```

Размеры типов:

- bool — 1 байт.
- int64 — 8 байт.
- bool — 1 байт.

На первый взгляд, структура должна занимать: 1 + 8 + 1 = 10 байт

Но фактически на распространённых 64-битных платформах она занимает 24 байта.

Go выравнивает `int64` по границе 8 байт.

Поэтому память будет распределена примерно так:

```
bool (1байт) + Padding(7байт)
int64 (8байт)
bool (1байт) + Padding(7байт)
```

Можно изменить порядок полей структуры:

```go
type Example struct {
    a bool
    c bool
    b int64
}
```

Теперь расположение будет следующим:

- `a` - 1 байт.
- `c` - 1 байт.
- Padding - 6 байт.
- `b` - 8 байт.

16 байт вместо 24

</details>

## Основные операции

### Создания структуры

#### С указанием имён полей

```go
varName := StructName{
    field1: "Alex",
    field2:  25,
    field3: "Riga",
}
fmt.Println(varName) // {Alex 25 Riga}
```

#### Без указания имён (важен порядок полей)

```go
varName := StructName{"Alex", 25, "Riga"}
fmt.Println(varName) // {Alex 25 Riga}
```

#### Через указатель

```go
varName := new(StructName) // Устаревшее
varName := &StructName{}

varName.field1 = "Alex"
varName.field2 = 25
```

#### Zero value

Zero value структура — это структура, у которой все поля имеют свои нулевые значения(zero value).

```go
var varName StructName
```

<hr />

### Обращение к полю структуры

Для доступа к полям используется точка `.`

```go
fmt.Println(person.Name) // Alex
fmt.Println(person.Age)  // 25
```

## Конструктор

В языке программирования Go (Golang) конструктор — это функция, которая создаёт и инициализирует структуру (`struct`).

В Go нет специального ключевого слова `constructor`, как, например, в Java или C++. Вместо него обычно используют обычную функцию с именем `New...`.

```go
type StructName struct {
	...
}
```

```go
func NewStructName(name string, ...params) *StructName {
    return &Person{
		Name: name,
		...
    }
}
```

Использование:

```go
varName := NewStructName("Ivan", ...)
```

<hr />

### Конструктор с проверкой данных

Конструктор может возвращать ошибку, если переданные параметры некорректны.

```go
func NewStructName(name string, ...) (*StructName, error) {
    if name == "" {
        return nil, errors.New("name cannot be empty")
    }

    if ... {
        return nil, errors.New("...")
    }

    return &Person{
        Name: name,
        ...
    }, nil
}
```

## Функции (методы)

```go
func (s StructName) MethodName() {
    fmt.Println(s.field1)
}
```

- `s StructName` — получатель метода (receiver). Благодаря ему метод связан со структурой `StructName`.
- `s` - похож на `this` в других языках. Обычно называют одной буквой (первой буквой названии структуры).

В данном случае результат может быть одинаковым, но это не совсем одно и то же:

```go
func MethodName(s StructName) {
    fmt.Println(s.field1)
}
```

<details>
  <summary>Пример</summary>

```go
type Person struct {
    Name string
    Age  int
}

func (p Person) SayHello() {
    fmt.Println("Привет, меня зовут", p.Name)
}

func main() {
    p := Person{Name: "Alex", Age: 25}

    p.SayHello()
}
```

</details>

## Композиция (Composition)

Композиция (Composition) в Go — это принцип, при котором одна структура включает в себя другую структуру, чтобы использовать её поля и методы.

Проще говоря, вместо того чтобы наследовать поведение другого типа (как в некоторых ООП-языках), Go позволяет объединять типы между собой.

```go
type Engine struct {
    Power int
}

type Car struct {
    Brand  string
    Engine Engine
}
```

### Создание

```go
car := Car{
    Brand: "BMW",
    Engine: Engine{
        Power: 300,
    },
}
```

### Исопьзование

```go
fmt.Println(car.Brand)        // BMW
fmt.Println(car.Engine.Power)  // 300
```

## Встраивание структур (Embedding)

<Callout title='' type='tip'>

Больше похоже на наследование

</Callout>

```go
type Engine struct {
    Power int
}

type Car struct {
    Brand string
    Engine
}
```

### Создание

```go
car := Car{
    Brand: "BMW",
    Engine: Engine{
        Power: 300,
    },
}
```

### Исопьзование

```go
fmt.Println(car.Brand)        // BMW
fmt.Println(car.Power)  // 300
```

### Field Shadowing - Перекрытие полей

Перекрытие полей (Field Shadowing) в Embedding Go — это ситуация, когда внешняя структура объявляет поле с таким же именем, как у встроенной структуры.

```go
type User struct {
    Name string         // = "User"
    Age  int
}

type Admin struct {
    User
    Name string         // = "Admin"
}
```

```go
fmt.Println(admin.Name)      // "Admin"
fmt.Println(admin.User.Name)      // "User"
```

## Передача структуры в функцию

### Изменение полей структуры внутри функции

```go
package main

import "fmt"



type Car struct {
    name string
    cost  int
    power int
}

func main() {
    s := Car {"Royal",1_000_000,240}

    change(s)

    fmt.Println(s) // {"Royal",1_000_000,240}
}

func change(s Car) {
    s.name = "Royal J"
}
```

Структура в Go передаётся в функцию по значению, то есть функция получает его копию.

Поэтому изменения элементов структуры внутри функции не затрагивают оригинальную структуру.

Чтобы изменить оригинальный массив, нужно передать в функцию указатель на него или вернуть новый.

```go
package main

import "fmt"

type Car struct {
    name  string
    cost  int
    power int
}

func main() {
    s := Car{"Royal", 1_000_000, 240}

    // change(&s)
	// s = change(s)

    fmt.Println(s) // {Royal J 1000000 240}
}

func change(s *Car) {
    s.name = "Royal J"
}


// func change(s Car) Car {
//     s.name = "Royal J"
//     return s
// }
```

## Примеры (файл)

```go
package main

import (
	"fmt"
	"unsafe"
)

type user struct {
	ID   int
	Name string
	Age  int
}

func (u user) GetName() string {
	return u.Name
}

func (u user) GetAge() int {
	return u.Age
}

func main() {
	u := user{
		ID:   42,
		Name: "Alice",
		Age:  25,
	}

	name := u.GetName()
	age := u.GetAge()

	fmt.Println(name, age)

	// Паддинг (выравнивание) в структурах
	// Размер структуры зависит от порядка полей и их типов
	// Поля выравниваются по 4 или 8 байт
	type user1 struct {
		ID   int32  // 4 байта, но займёт 8
		Name string // 16 байт
		Age  int32  // 4 байта, но займёт 8
	}

	fmt.Println("Размер структуры user1:", unsafe.Sizeof(user1{})) // 32 байта

	type user2 struct {
		Name string // 16 байт
		ID   int32  // 4 байта и займёт 4 байта
		Age  int32  // 4 байта и займёт 4 байта
	}

	fmt.Println("Размер структуры user2:", unsafe.Sizeof(user2{})) // 24 байта

	type user3 struct {
		ID    int  // 8 байт
		Valid bool // 1 байт, но займёт 8 байт
	}

	fmt.Println("Размер структуры user3:", unsafe.Sizeof(user3{})) // 16 байт

	type user4 struct {
		ID    int32 // 4 байта
		Valid bool  // 1 байт, но займёт 4 байта
	}

	fmt.Println("Размер структуры user4:", unsafe.Sizeof(user4{})) // 8 байт
}
```
