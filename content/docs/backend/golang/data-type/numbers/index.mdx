---
title: "Числовые типы"
---

| Тип     | Описание                              |
| ------- | ------------------------------------- |
| `int`   | 32 или 64 бита                        |
| `int8`  | 8 бит (1 байт) : -128 ... 127         |
| `int16` | 16 бит (2 байта) : -32 768 ... 32 767 |
| `int32` | 32 бита (4 байта) : -2³¹ ... 2³¹-1    |
| `int64` | 64 бита (8 байт) -2⁶³ ... 2⁶³-1       |

| Тип      | Описание                        |
| -------- | ------------------------------- |
| `uint`   | 32 или 64 бита                  |
| `uint8`  | 8 бит (1 байт) : 0 ... 255      |
| `uint16` | 16 бит (2 байта) : 0 ... 65 535 |
| `uint32` | 32 бита (4 байта) : 0 ... 2³²-1 |
| `uint64` | 64 бита (8 байт) : 0 ... 2⁶⁴-1  |

- `int` и `uint` имеют размер 32 бита на 32-битной архитектуре и 64 бита на 64-битной.

| Тип                        | Описание                                                                   |
| -------------------------- | -------------------------------------------------------------------------- |
| `float32`                  | 32 бита (4 байта) ~6–7 десятичных цифр : ±1.18 × 10⁻³⁸ ... ±3.4 × 10³⁸     |
| `float64`                  | 64 бита (8 байт) ~15–16 десятичных цифр : ±2.23 × 10⁻³⁰⁸ ... ±1.79 × 10³⁰⁸ |
| `complex64` , `complex128` | Комплексные числа                                                          |

| Тип    | Описание                                                                             |
| ------ | ------------------------------------------------------------------------------------ |
| `byte` | 8 бит (алиас `uint8`), используется для доступа к отдельным байтам строки            |
| `rune` | 32 бита (алиас `int32`), используется для представления Unicode-кодовых точек строки |

<Callout title='' type='success'>

По дефолту Go присваивает переменной значение `0`.

```go
var isActive int // 0
```

</Callout>

<Callout title='' type='success'>

Go игнорирует `_`.

```go
var myInt int = 1_500_000 // 1500000
```

</Callout>
