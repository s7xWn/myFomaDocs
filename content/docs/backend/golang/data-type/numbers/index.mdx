---
title: "Числовые типы"
---

| Тип                        | Описание                                  |
| -------------------------- | ----------------------------------------- |
| `int`                      | Целое число                               |
| `int8` , `int16`           | Целые числа фиксированной разрядности     |
| `int32`                    | 32-битное целое                           |
| `int64`                    | 64-битное целое                           |
| `uint` , `uint8` ...       | Беззнаковые целые                         |
| `float32`                  | Число с плавающей точкой                  |
| `float64`                  | Число с плавающей точкой двойной точности |
| `complex64` , `complex128` | Комплексные числа                         |

| Тип    | Описание                                                    |
| ------ | ----------------------------------------------------------- |
| `byte` | используется для доступа к отдельным байтам строки          |
| `rune` | используется для представления Unicode-кодовых точек строки |

<Callout title='' type='success'>

По дефолту Go присваивает переменной значение `0`.

```go
var isActive int // 0
```

</Callout>
