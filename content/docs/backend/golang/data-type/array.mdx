Массив — это последовательность элементов одного типа с заранее определённым размером.

<Callout title='' type='tip'>

Массив != указатель

</Callout>

```go
var varName [n]type
```

- `varName` - название переменной
- `n` - количество элементов
- `type` - тип данных, хранящихся в массиве

Можно сразу заполнить массив:

```go
numbers := [5]int{10, 20, 30, 40, 50}
```

Можно не указывать размер явно:

```go
numbers := [...]int{10, 20, 30}
```

Можно инициализировать массив указав индексы. Индексы в массиве выступают в качестве ключей:

```go
	days = [7]string{
		0: "Пн",
		1: "Вт",
		2: "Ср",
		3: "Чт",
		4: "Пт",
		5: "Сб",
		6: "Вс",
	}
```

Или только некоторые индексы:

```go
days = [7]string{3: "Четверг", 1: "Вторник", 6: "Воскресенье"} // ["" "Вторник" "" "Четверг" "" "" "Воскресенье"]
```

<details>
  <summary>Пример красивых синтаксических индексов</summary>

Можно сделать красивые синтаксические индексы:

```go
	const (
		Monday = iota
		Tuesday
		Wednesday
		Thursday
		Friday
		Saturday
		Sunday
	)
```

Инициализация массива:

```go
	days = [...]string{
		Monday:    "Пн",
		Tuesday:   "Вт",
		Wednesday: "Ср",
		Thursday:  "Чт",
		Friday:    "Пт",
		Saturday:  "Сб",
		Sunday:    "Вс",
	}
```

```go
	// Обращение
	monday = days[Monday] // "Пн"

	// Изменение
	days[Monday] = "Пн"
```

</details>

<Callout title='Важно' type='error'>

Массивы разного размера в Go — это разные типы.

```go
var a [3]int
var b [5]int

// a = b // Ошибка компиляции!
```

```go
	a := [3]int{1,2,3}
	b := [3]int{1,2,4}
    c := [3]int{1,2,3}

	fmt.Print(a == b) // false
    fmt.Print(a == c) // true
}
```

</Callout>

## Массив не имеет постоянного расположения в памяти на все время жизни программы.<br/>(Может переезжать, когда растет стек горутины)

Это утверждение про массивы в Go и стек горутины (goroutine stack).

Оно означает, что массив не обязательно находится по одному и тому же адресу памяти на протяжении всей работы программы.

Почему массив может перемещаться?<br/>
В Go у каждой горутины есть собственный стек.

- Стек изначально небольшой.
- Когда ему не хватает места, Go увеличивает его размер.
- При увеличении стек может быть выделен в другом участке памяти.
- Содержимое старого стека копируется в новый.
- Соответственно, массивы и другие локальные переменные, находящиеся в стеке, тоже могут оказаться по новым адресам.

<details>
  <summary>Пример программы</summary>

```go
package main

import "fmt"

func growStack(depth int) {
    // Локальный массив
    var arr [1024]int

    arr[0] = depth

    if depth == 0 {
        fmt.Printf("Адрес массива до роста стека: %p\n", &arr[0])
        return
    }

    growStack(depth - 1)

    // Используем массив, чтобы он оставался необходимым
    // во время выполнения функции.
    arr[1] = depth

    if depth == 10000 {
        fmt.Printf("Адрес массива после роста стека: %p\n", &arr[0])
    }
}

func main() {
    growStack(10000)
}
```

</details>

## Основные операции

### Создание массива

```go
const myConst1 := 5
myVar := 5

arr1 := [myConst]int{10, 20, 30, 40, 50}
arr2 := [myVar]int{10, 20, 30, 40, 50} // ошибка
```

Создать массив можно явно указав размер или через константу.

<hr />

### Обращение к элементу по индексу

```go
arr[idx]
```

```go
arr[idx] = *(array + idx * elem_size)
```

<details>
  <summary>Пример</summary>

```go
func main() {
	cosnt elemSize = unsafe.Sizeof(int32(0))
	array = [...]int32{1,2,3}
	pointer = unsafe.Pointer{&array}

	first := *(*int32)(unsafe.Add(pointer, 0*elemSize)) // => array[0]
	second := *(*int32)(unsafe.Add(pointer, 1*elemSize)) // => array[0]
	third := *(*int32)(unsafe.Add(pointer, 2*elemSize)) // => array[0]
}
```

</details>

<hr />

### Получить длину `len()`

```go
length := len(arrayVar) // 7
```

<Callout title='' type='tip'>

В Go функция `len()` может вычисляться как на этапе компиляции, так и во время выполнения. Это зависит от того, над каким типом вызывается `len()` и известен ли компилятору размер.

</Callout>

<hr />

### Получить ёмкость `cap()`

Емкость (емкость массива соответствует его длине)

```go
capacity := cap(arrayVar) // 7
```

<hr />

### Итерация по массиву

```go
	for i := 0; i < len(days); i++ {
		day := days[i]
		fmt.Println("Индекс:", i, "День:", day)
	}
```

Итерация с помощью `range`:

```go
	for i, day := range days {
		fmt.Println("Индекс:", i, "День:", day)
	}
```

- `i` - индекс
- `day` - значение массива по индексу `i`

```go
	for _, _ := range days {
		...
	}
// тоже самое, что :
	for range days {
		...
	}
```

#### Изменение значения

```go
package main

import "fmt"

func main() {
    numbers := [5]int{10, 20, 30, 40, 50}
	for _, v := range numbers {
		v += 10
	}
	fmt.Println(numbers) // 10, 20, 30, 40, 50
}
```

При переборе массива через цикл, `for range` коипрует значение массива в переменную `v`.<br/>
Для того чтоб изменить значение, надо братиться к элементу массива через индекс:

```go
package main

import "fmt"

func main() {
    numbers := [5]int{10, 20, 30, 40, 50}
	for i, _ := range numbers {
		numbers[i] += 10
	}
	fmt.Println(numbers) // 20, 30, 40, 50, 60
}
```

### Сравнение массивов

```go
arr1 == arr2
arr1 != arr2
```

`>`, `<`, `>=`, `<=` - нельзя использовать

## Передача массива в функцию

- Массив в Go имеет фиксированную длину, которую нельзя изменить ни внутри функции, ни за её пределами.

### Изменение элементов массива внутри функции

```go
func change(arr [3]int) {
    arr[0] = 100
}

func main() {
    arr := [...]int{1, 2, 3}

    change(arr)

    fmt.Println(arr) // [1 2 3]
}
```

Массив в Go передаётся в функцию по значению, то есть функция получает его копию.

Поэтому изменения элементов массива внутри функции не затрагивают оригинальный массив.

Чтобы изменить оригинальный массив, нужно передать в функцию указатель на него.

```go
func change(arr *[3]int) {
    arr[0] = 100
}

func main() {
    arr := [...]int{1, 2, 3}

    change(&arr)

    fmt.Println(arr) // [100 2 3]
}
```

В отличие от слайсов, массивы не разделяют общий базовый массив при копировании.
Каждый массив — самостоятельное значение со своей копией элементов.

## Примеры (файл)

```go
package main

import (
	"fmt"
	"unsafe"
)

func main() {
	// Массивы хранятся в памяти последовательно

	// Массивы в Go - это набор из элементов одного типа с фиксированным размером
	var days [7]string
	days[0] = "Пн"
	days[1] = "Вт"
	days[2] = "Ср"
	days[3] = "Чт"
	days[4] = "Пт"
	days[5] = "Сб"
	days[6] = "Вс"

	// Инициализация массива с помощью литерала
	days = [7]string{"Пн", "Вт", "Ср", "Чт", "Пт", "Сб", "Вс"}

	// Размер массива - часть его типа: [7]string и [3]string - это разные типы

	// Автовыведение типа массива
	two := [...]int{1, 2}      // [2]int
	three := [...]int{1, 2, 3} // [3]int

	fmt.Println("Размер массива из 2 int:", unsafe.Sizeof(two))   // 16 байт (int = 8 байт * 2 элемента)
	fmt.Println("Размер массива из 3 int:", unsafe.Sizeof(three)) // 24 байта (int = 8 байт * 3 элемента)

	// Длина массива
	length := len(days) // 7

	// Емкость (емкость массива соответствует его длине)
	capacity := cap(days) // 7

	// Получение значения
	monday := days[0] // "Пн"

	// Изменение значения
	days[0] = "Monday"
	monday = days[0] // "Monday"

	// Последний элемент массива
	last := len(days) - 1
	sunday := days[last] // "Вс"

	// Можно инициализировать массив указав индексы. Индексы в массиве выступают в качестве ключей
	days = [7]string{
		0: "Пн",
		1: "Вт",
		2: "Ср",
		3: "Чт",
		4: "Пт",
		5: "Сб",
		6: "Вс",
	}

	// Или только некоторые индексы
	days = [7]string{3: "Четверг", 1: "Вторник", 6: "Воскресенье"}
	fmt.Println(days) // ["" "Вторник" "" "Четверг" "" "" "Воскресенье"]

	// Можно сделать красивые синтаксические индексы
	const (
		Monday = iota
		Tuesday
		Wednesday
		Thursday
		Friday
		Saturday
		Sunday
	)

	// Инициализация массива
	days = [...]string{
		Monday:    "Пн",
		Tuesday:   "Вт",
		Wednesday: "Ср",
		Thursday:  "Чт",
		Friday:    "Пт",
		Saturday:  "Сб",
		Sunday:    "Вс",
	}

	// Обращение
	monday = days[Monday] // "Пн"

	// Изменение
	days[Monday] = "Пн"

	// Итерация по массиву
	for i := 0; i < len(days); i++ {
		day := days[i]
		fmt.Println("Индекс:", i, "День:", day)
	}

	// Итерация с помощью range
	for i, day := range days {
		fmt.Println("Индекс:", i, "День:", day)
	}

	_, _, _, _ = length, capacity, monday, sunday
}
```
