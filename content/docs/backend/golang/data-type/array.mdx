---
title: "Массив"
---

Массив — это последовательность элементов одного типа с заранее определённым размером.

```go
var varName [n]type
```

- `varName` - название переменной
- `n` - количество элементов
- `type` - тип данных, хранящихся в массиве

Можно сразу заполнить массив:

```go
numbers := [5]int{10, 20, 30, 40, 50}
```

Можно не указывать размер явно:

```go
numbers := [...]int{10, 20, 30}
```

<Callout title='Важно' type='error'>

Массивы разного размера в Go — это разные типы.

```go
var a [3]int
var b [5]int

// a = b // Ошибка компиляции!
```

```go
	a := [3]int{1,2,3}
	b := [3]int{1,2,4}
    c := [3]int{1,2,3}

	fmt.Print(a == b) // false
    fmt.Print(a == c) // true
}
```
