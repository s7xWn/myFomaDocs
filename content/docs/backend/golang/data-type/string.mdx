В Go строковый тип данных всего один — `string`.

Он используется для хранения последовательностей байтов, которые обычно представляют текст в кодировке UTF-8.

```go
var name string = "Alex"

// Краткая запись
city := "Riga"

// Пустая строка
var empty string

fmt.Println(name)  // Alex
fmt.Println(city)  // Riga
fmt.Println(empty) // ""
```

<Callout title='' type='success'>

По дефолту Go присваивает переменной значение пустой строки `""`.

```go
var isActive bool // false
```

<Callout title='Важно' type='warn'>

**Строки** в Go неизменяемые (**immutable**). Нельзя изменить отдельный символ строки напрямую.

```go
name := "Alex"

// name[0] = 'B' // Ошибка компиляции
```

## Подробнее как устроена строка

Строка — это не слайс байтов (`[]byte`), хотя они имеют некоторые общие черты.

Внутри строка содержит две вещи:

1. Pointer — указатель на область памяти, в которой хранятся байты строки.
2. Length (len) — количество байтов в строке.

Упрощённо внутреннее устройство строки можно представить так:

```go
type stringStruct struct {
    data unsafe.Pointer
    len  int
}
```

В отличие от слайса, у строки нет `capacity` (`cap`), потому что строка не предназначена для изменения своего содержимого или добавления новых элементов.

| Характеристика              | `string` | `[]byte` / `[]int` |
| --------------------------- | -------- | ------------------ |
| Pointer                     | Да       | Да                 |
| Length (`len`)              | Да       | Да                 |
| Capacity (`cap`)            | Нет      | Да                 |
| Можно изменять элементы     | Нет      | Да                 |
| Можно использовать `[:]`    | Да       | Да                 |
| Можно использовать `append` | Нет      | Да                 |

### Строки неизменяемы (immutable)

После создания строки нельзя изменить отдельный байт или символ внутри неё.

```go
package main

import "fmt"

func main() {
    text := "hello"

    // text[0] = 'H' // Ошибка компиляции!

    fmt.Println(text) // hello
}
```

Чтобы изменить строку, нужно создать новую:

```go
package main

import "fmt"

func main() {
    text := "hello"

    text = "H" + text[1:]

    fmt.Println(text) // Hello
}
```

<hr />

### Строка может ссылаться на часть другой строки

Как и при работе со слайсами, с помощью операции среза (`[:]`) можно получить часть строки.

```go
package main

import "fmt"

func main() {
    text := "Hello, World!"

    part := text[7:12]

    fmt.Println(part) // World
}
```

При этом исходная строка не изменяется.

Важно: операция `text[7:12]` работает с байтами, а не с символами. Это особенно важно при работе с UTF-8.

## Способы записи строк

В Go есть два основных способа.

### Двойные кавычки `" "`

```go
text := "Hello\nWorld"

fmt.Println(text)
```

Поддерживают escape-последовательности.

### Обратные кавычки (Raw String)

```go
text := `Hello
World`

fmt.Println(text)
```

Особенности:

- Сохраняют переносы строк.
- Не обрабатывают escape-последовательности.
- Удобны для HTML, SQL, JSON и многострочного текста.

<div className="hr-decor">✦</div>

## Escape-последовательности

| Символ | Значение        |
| ------ | --------------- |
| `\n`   | Новая строка    |
| `\t`   | Табуляция       |
| `\\`   | Обратный слеш   |
| `\"`   | Двойная кавычка |
| `\r`   | Возврат каретки |

## Работа с символами строки

В Go есть два важных типа:

- `byte` — алиас для `uint8`, представляет один байт.
- `rune` — алиас для `int32`, представляет Unicode-кодовую точку.

<details>
  <summary>Пример</summary>

```go
text := "Hello"

fmt.Println(text[0])   // 72 (код байта)
fmt.Printf("%c\n", text[0]) // H
```

Для Unicode лучше использовать `rune`:

```go
text := "Привет"

runes := []rune(text)

fmt.Println(runes[0]) // 1055
fmt.Printf("%c\n", runes[0]) // П
```

</details>

## Сравнение строк

Строки можно сравнивать операторами:

- `==` — равенство.
- `!=` — неравенство.
- `<` — меньше.
- `>` — больше.
- `<=` — меньше или равно.
- `>=` — больше или равно.

Сравнение выполняется лексикографически по байтам.

```go
a := "apple"
b := "banana"

fmt.Println(a == b) // false
fmt.Println(a < b)  // true
```

## Полезные функции для работы со строками (`strings`)

Пакет `strings` содержит множество готовых функций.

```go
import "strings"

text := "Hello World"

strings.Contains(text, "World") // true
strings.ToUpper(text)           // HELLO WORLD
strings.ToLower(text)           // hello world
strings.ReplaceAll(text, "World", "Go")
strings.Split(text, " ")        // ["Hello", "World"]
strings.TrimSpace("  Hello  ")  // "Hello"
strings.HasPrefix(text, "Hello") // true
strings.HasSuffix(text, "World") // true
```
