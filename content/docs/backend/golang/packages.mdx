---
title: Packages / Пакеты
---

Package — это набор исходных файлов Go, которые компилируются как единая логическая единица и совместно используют пространство имён.

Packages в Go — это один из основных механизмов организации кода и реализации модульности приложения. Но есть нюанс: package — это не просто папка с файлами и не совсем аналог модуля в других языках.

<details>
  <summary>Пример</summary>

Например, у нас есть приложение для управления пользователями:

```
myapp/
    - cmd/server/
        - main.go — точка входа
    - user/
        - user.go — работа с пользователями
        - repository.go — хранение пользователей
    - config/
        - config.go — конфигурация приложения
go.mod — описание модуля
```

Здесь `user` и `config` — разные пакеты, а `main` — пакет приложения, запускающий сервер.

<Callout>
  Важное правило: обычно все `.go`-файлы в одной директории должны принадлежать
  одному пакету.
</Callout>

Например, `user/user.go`:

```go
package user

type User struct {
    ID   int
    Name string
}

func NewUser(id int, name string) User {
    return User{
        ID:   id,
        Name: name,
    }
}
```

`user/repository.go`:

```go
package user

func Validate(u User) bool {
    return u.ID > 0 && u.Name != ""
}
```

Оба файла принадлежат одному пакету `user`, поэтому `repository.go` может использовать тип `User` без дополнительных импортов.

</details>
