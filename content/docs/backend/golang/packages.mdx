| Критерий                | Package               | Module                             |
| ----------------------- | --------------------- | ---------------------------------- |
| Что это?                | Набор Go-файлов       | Набор пакетов                      |
| Как создаётся?          | Через `package name`  | Через `go mod init`                |
| Где определяется?       | В `.go` файлах        | В `go.mod`                         |
| За что отвечает?        | Организация кода      | Организация проекта и зависимостей |
| Может содержать другие? | Нет вложенных пакетов | Может содержать много пакетов      |

## Package

Package — это набор исходных файлов Go, которые компилируются как единая логическая единица и совместно используют пространство имён.

В Go пакет объединяет `.go`-файлы, находящиеся в одной директории и объявленные через одинаковое имя `package`.

Обычный пакет, виден другим пакетам. <br/>
Тестовый пакет (добавляется `_test` к имени пакета), виден только внутри пакета (нельзя обратиться из другого пакета)

<details>
  <summary>Пример</summary>

```
myapp/
    - cmd/
        server/
            - main.go — точка входа
    - user/
        - user.go — работа с пользователями
        - repository.go — хранение пользователей
    - config/
        - config.go — конфигурация приложения
go.mod — описание модуля
```

Здесь три пакета:

- `user`
- `config`
- `main`

Каждый пакет отвечает за определённую часть приложения.

<Callout>
  Важное правило: обычно все `.go`-файлы в одной директории должны принадлежать
  одному пакету.
</Callout>

Например, `user/user.go`:

```go
package user

type User struct {
    ID   int
    Name string
}

func NewUser(id int, name string) User {
    return User{
        ID:   id,
        Name: name,
    }
}
```

`user/repository.go`:

```go
package user

func Validate(u User) bool {
    return u.ID > 0 && u.Name != ""
}
```

Оба файла принадлежат одному пакету `user`, поэтому `repository.go` может использовать тип `User` без дополнительных импортов.

</details>

### `package main`

`package main` — это специальное обозначение пакета в языке программирования Go (Golang). Он используется для обозначения исполняемой программы (приложения).

- `package main` — обозначает пакет, который является точкой входа исполняемой программы.
- `func main()` — непосредственно функция, с которой начинается выполнение программы.

Корневой пакет, не виден другим пакетам

<hr />

### Импорт. Взаимодействие пакетов друг с другом

```go
import "packageName"
```

или

```go
import (
    "packageName"
    "packageName"
)
```

<details>
  <summary>Пример</summary>

Допустим, в `user/user.go` у нас есть:

```go
package user

type User struct {
    ID   int
    Name string
}
```

А в `cmd/server/main.go`:

```go
package main

import (
    "fmt"
    "github.com/username/myapp/user"
)

func main() {
    u := user.User{
        ID:   1,
        Name: "Alex",
    }

    fmt.Println(u)
}
```

Обрати внимание на импорт: `"github.com/username/myapp/user"`

Он состоит из двух частей:

- `github.com/username/myapp` — путь модуля из go.mod.
- `/user` — путь к пакету внутри модуля.

Именно благодаря этому Go понимает, где искать нужный пакет.

</details>

#### Псевдоним пакета

```go
import alias "packageName"
```

```go
alias.Func()
...
```

- `alias` - новое название пакета, чтобы не использовать `packageName`

<details>
  <summary>Пример</summary>

```go
package main

import printlib "fmt"

func main() {
	printlib.Println("Hello, 世界")
}
```

</details>

## Module

Модуль объединяет несколько пакетов в один проект.

Именно для его создания используется:

```bash
go mod init <NAME/URL>
```

То есть один Module может содержать множество Packages.

<hr />

### Приватный репозиторий для модулей в Gitlab

Версионируем libs через semver теги: v0.1.0, далее v0.2.0 и т.д.

Создаём токен на чтение в Gitlab

Добавляем токен в файл ~/.netrc:

```
machine gitlab.golang-school.ru login <GITLAB_LOGIN> password <TOKEN>
```

Добавляем репозиторий в go env:

```sh
go env -w GOPRIVATE="gitlab.golang-school.ru"
```

Проверяем, что всё работает:

```sh
go get gitlab.golang-school.ru/potok-2/mnepryakhin/libs
```
