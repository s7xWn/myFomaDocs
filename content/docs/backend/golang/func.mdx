title: "Функции"
---

Функция (function) в Go (Golang) — это именованный блок кода, который выполняет определённую задачу. Функции позволяют не повторять один и тот же код несколько раз, а вызывать его по необходимости.

<hr />

## Объявление функции `func`

```go
func funcName() {

}
```

```go
func main(){
    funcName()
}
```

<Callout title='' type='error'>

В Go открывающая фигурная скобка функции должна находиться на той же строке, где объявляется функция.

```go
func funcName() {
```

В Go действует правило: если поставить перенос строки после `)`, компилятор автоматически вставляет точку с запятой `;`. Поэтому второй вариант вызовет ошибку.

</Callout>

- `func` — ключевое слово для создания функции.
- `funcName` — название функции.
- `()` — место для параметров.
- `{}` — тело функции, то есть код, который она выполняет.
- sayHello() — вызов функции.

<hr />

### Параметры

Функция может принимать данные.

```go
func funcName(param1 int, param2 string) {

}
```

```go
func main(){
    funcName(0, "text")
}
```

Здесь:

- `param1`,`param2` — параметры.
- `int`, `string` — тип данных параметра.
- "Алексей" и "Иван" — аргументы, которые мы передаём функции.

<hr />

### Возвращаемое значение

Функция может возвращать результат.

```go
func add(a int, b int) int {
    return a + b
}
```

Здесь:

- `) int {` -> `int` — тип возвращаемого значения..
- `return` — возвращает результат функции.

```go
func main() {
    result := add(5, 3)
    fmt.Println(result)
}
```

#### Несколько возвращаемых значений

В Go функция может возвращать сразу несколько значений.

```go
func calculate(a int, b int) (int, int) {
    sum := a + b
    difference := a - b

    return sum, difference
}
```

```go
sum, difference := calculate(10, 5)

fmt.Println(sum)        // 15
fmt.Println(difference) // 5
```
