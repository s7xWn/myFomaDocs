Функция (function) в Go (Golang) — это именованный блок кода, который выполняет определённую задачу. Функции позволяют не повторять один и тот же код несколько раз, а вызывать его по необходимости.

<Callout title='' type='tip'>

Function в Go — объект первого класса.

</Callout>

```go
func funcName() {

}
```

```go
func main(){
    funcName()
}
```

<Callout title='' type='error'>

В Go открывающая фигурная скобка функции должна находиться на той же строке, где объявляется функция.

```go
func funcName() {
```

В Go действует правило: если поставить перенос строки после `)`, компилятор автоматически вставляет точку с запятой `;`. Поэтому второй вариант вызовет ошибку.

</Callout>

- `func` — ключевое слово для создания функции.
- `funcName` — название функции.
- `()` — место для параметров.
- `{}` — тело функции, то есть код, который она выполняет.
- sayHello() — вызов функции.

## Публичная/приватная фунцкия

Публичная функция в Go (Public Function) — это функция, которая доступна для использования из других пакетов (packages).

В Go публичность определяется первой буквой имени:

- С большой буквы (Exported) — публичная функция.

  ```go
  func funcName() {

  }
  ```

- С маленькой буквы (unexported) — приватная функция, доступная только внутри своего пакета.

  ```go
  func FuncName() {

  }
  ```

## Параметры

Функция может принимать данные.

```go
func funcName(param1 type, param2 type) {

}
```

Или если параметры имеют одинаковые типы:

```go
func funcName(param1, param2 type) {

}
```

```go
func main(){
    funcName(0, "text")
}
```

Здесь:

- `param1`,`param2` — параметры.
- `int`, `string` — тип данных параметра.
- "Алексей" и "Иван" — аргументы, которые мы передаём функции.

<div className="hr-decor">✦</div>

## Возвращаемое значение

Функция может возвращать результат.

```go
func add(a int, b int) int {
    return a + b
}
```

Здесь:

- `) int {` -> `int` — тип возвращаемого значения..
- `return` — возвращает результат функции.

```go
func main() {
    result := add(5, 3)
    fmt.Println(result)
}
```

<Callout title='' type='error'>

На практике использование голого `return` считается нежелательным,

</Callout>

<hr />

### Несколько возвращаемых значений

В Go функция может возвращать сразу несколько значений.

```go
func calculate(a int, b int) (int, int) {
    sum := a + b
    difference := a - b

    return sum, difference
}
```

```go
sum, difference := calculate(10, 5)

fmt.Println(sum)        // 15
fmt.Println(difference) // 5
```

<hr />

### Несколько возвращаемых инициализированных значений

```go
func calculate(a int, b int) (sum int, difference int) {
    sum = a + b
    difference = a - b

    return sum, difference
}
```

<Callout title='' type='tip'>

На практике использование голого `return` считается нежелательным,
однако при наличии нескольких именованных возвращаемых значений,
инициализированных заранее, всё же существует риск случайно использовать его.

</Callout>

## Чистая функция

Чистая функция (pure function) — это функция, которая:

1. **Детерминированность (Determinism)** — для одинаковых входных данных функция всегда возвращает одинаковый результат.
2. **Отсутствие побочных эффектов (No Side Effects)** — функция не изменяет внешнее состояние программы и не взаимодействует с внешним миром (например, не изменяет глобальные переменные, не записывает данные в БД или файлы, не отправляет HTTP-запросы).

<div className="hr-decor">✦</div>

## Анонимная функция

Анонимная функция в Go (Anonymous Function) — это функция, у которой нет имени. Её можно объявить прямо в том месте, где она нужна, и сразу выполнить или сохранить в переменную.

```go
func main() {
    func() {
        fmt.Println("Hello!")
    }()

	greet := func() {
        fmt.Println("Привет!")
    }

    greet()
}
```

- `func() { ... }` — анонимная функция.
- `()` в конце — означают, что функция вызывается сразу после объявления.
- `greet` — переменная, хранящая функцию.
- `greet()` — вызов этой функции.

<hr />

### Анонимная функция с параметрами

```go
func main() {
    func(a int, b int) {
        fmt.Println(a + b) // 8
    }(5,3)

    sum := func(a int, b int) int {
        return a + b
    }

    result := sum(5, 3) // 8
	fmt.Println(result) // 8
}
```

<hr />

### Замыкание (Closure)

Замыкание (Closure) — это функция, которая не только выполняет определённый код, но и имеет доступ к переменным из внешней области видимости, в которой она была создана.

```go
package main

import "fmt"

func main() {
    counter := 0

    increment := func() {
        counter++
        fmt.Println(counter)
    }

    increment() // 1
    increment() // 2
    increment() // 3
}
```

<hr />

### Анонимная асинхронная функция

В Go анонимную функцию можно запустить асинхронно с помощью ключевого слова `go`. Такая функция выполняется в отдельной горутине (goroutine), независимо от основного потока выполнения программы.

```go
package main

import (
    "fmt"
    "time"
)

func main() {
    go func() {
        fmt.Println("Асинхронная функция")
    }()
}
```

## First-Class Functions

Функции как объекты первого класса (First-Class Functions) в Go — это свойство языка, которое означает, что функции можно использовать практически так же, как обычные значения: числа, строки или переменные.

То есть функцию можно:

1. Присвоить переменной.
2. Передать в другую функцию как аргумент.
3. Вернуть из другой функции.
4. Хранить в структурах или коллекциях.

```go
var f FuncType = funcName
```

`f` — это переменная функционального типа, но в Go её не следует считать обычным указателем (`pointer`).

<hr />

### Zero Value

В Go zero value (нулевое значение) функции — это `nil`.

При вызове `nil`-функции произойдёт `panic`, потому что вызвать `nil` как функцию нельзя.

```go
package main

import "fmt"

func main() {
    var f func()

    fmt.Println(f == nil) // true

	 f() // panic: call of nil function
}
```

<hr />

### Присваивание функции переменной

```go
package main

import "fmt"

func sum(a, b int) int {
    return a + b
}

func main() {
    operation := sum

    result := operation(10, 20)

    fmt.Println(result) // 30
}
```

- `sum` — функция.
- `operation := sum` — мы присвоили функцию переменной.
- `operation(10, 20)` — вызываем функцию через переменную.

<hr />

### Передача функции в качестве аргумента

```go
package main

import "fmt"

func sum(a, b int) int {
    return a + b
}

func calculate(a, b int, operation func(int, int) int) int {
    return operation(a, b)
}

func main() {
    result := calculate(10, 20, sum)

    fmt.Println(result) // 30
}
```

## Примеры (файлы)

```go
package main

import "fmt"

// Не видна за пределами пакета
func private() {
	fmt.Println("первая буква определяет доступность. маленькая первая буква - private")
}

// Public видна за пределами пакета
func Public() {
	fmt.Println("Большая первая буква - public")
}

func main() {
	private()
	Public()

	err := MaybeError("Alice", 25, false)
	if err != nil {
		fmt.Println(err)
	}

	user, err := GetUser(42)
	if err != nil {
		fmt.Println(err)
	}

	user, err = getUser(42)
	if err != nil {
		fmt.Println(err)
	}

	user, err = neverDoThat(42)
	if err != nil {
		fmt.Println(err)
	}

	_ = user
}

var (
	ErrEmptyName   = fmt.Errorf("name is empty")
	ErrNegativeAge = fmt.Errorf("age is negative")
	ErrBlockedUser = fmt.Errorf("user is blocked")
)

// MaybeError возвращает nil или ошибку
func MaybeError(name string, age int, isBlocked bool) error {
	if name == "" {
		return ErrEmptyName
	}

	if age < 0 {
		return ErrNegativeAge
	}

	if isBlocked {
		return ErrBlockedUser
	}

	return nil
}

var ErrNotFound = fmt.Errorf("user not found")

type User struct {
	ID   int
	Name string
	Age  int
}

// GetUser возвращает структуру или ошибку
func GetUser(id int) (User, error) {
	var user User

	if id == 0 {
		return user, ErrBlockedUser
	}

	if id == 42 {
		return User{
			ID:   42,
			Name: "Alice",
			Age:  25,
		}, nil
	}

	return user, ErrNotFound
}

// Инициализация переменных в блоке с возвращаемыми значениеми
func getUser(id int) (user User, err error) {
	if id == 0 {
		return user, ErrBlockedUser
	}

	if id == 42 {
		return User{
			ID:   42,
			Name: "Alice",
			Age:  25,
		}, nil
	}

	return user, ErrNotFound
}

// Голый return никогда не используется. Если вы так сделате, вас сожгут)
func neverDoThat(id int) (user User, err error) {
	if id == 0 {
		err = ErrBlockedUser

		return
	}

	if id == 42 {
		return User{
			ID:   42,
			Name: "Alice",
			Age:  25,
		}, nil
	}

	err = ErrNotFound

	return
}
```
