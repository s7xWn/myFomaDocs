ООП (объектно-ориентированное программирование) в Go реализовано не так, как в Java, C++ или C#. В Go нет классического наследования и классов, но есть структуры, методы, интерфейсы и композиция.

Основные концепции ООП в Go:

1. Инкапсуляция
2. Абстракция
3. Полиморфизм
4. Композиция (вместо наследования)

<hr />

## Структуры (Structs) — вместо классов

В Go нет классов. Вместо них используются структуры (`struct`).
