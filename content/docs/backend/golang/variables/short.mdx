---
title: ":="
---

<Callout title='' type='warn'>

**Используется только внутри функций.**

</Callout>

Самый распространённый способ:

```go
name := "Alex"
age := 25
isStudent := true
```

- `:=` одновременно объявляет переменную и присваивает ей значение.
- Нельзя использовать `:=` для повторного объявления уже существующей переменной в той же области видимости без объявления хотя бы одной новой.
