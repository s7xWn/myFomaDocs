<Callout title='' type='tip'>

Go — это типизированный компилируемый язык.

</Callout>

**Переменные** — это именованные контейнеры для хранения данных.

Для имени переменной можно использовать следующие символы:

- буквы латинского алфавита;
- цифры;
- символ `_`.

<Callout title='' type='warn'>

**Первый символ не должен быть цифрой!**

**Регистр важен!**

</Callout>

## Zero value

Нулевые значения для переменных в Go

| Тип       | Нулоевое значение       |
| --------- | ----------------------- |
| Чсиловые  | `0`                     |
| Строка    | `""` (пустая строка)    |
| Булеан    | `false`                 |
| Указатель | `nil`                   |
| Slice     | `nil`                   |
| Map       | `nil`                   |
| Channel   | `nil`                   |
| Function  | `nil`                   |
| Interface | `nil`                   |
| Struct    | Все поля zero value     |
| Array     | Все элементы zero value |

## Область видимости переменных (Scope)

В Go существует несколько основных видов областей видимости.

### Локальная область видимости

Переменная, объявленная внутри функции, доступна только внутри этой функции и вложенных блоков.

<details>
  <summary>Пример</summary>

Переменная `x` существует только в области видимости функции `main`.

```go
package main

import "fmt"

func main() {
    x := 10

    fmt.Println(x) // 10
}

func another() {
    // fmt.Println(x) // Ошибка: x не объявлена здесь
}
```

</details>

<hr />

### Область видимости блока (Block Scope)

В Go фигурные скобки `{}` создают блоки кода, которые могут иметь собственную область видимости.

К блокам также относятся:

- `if`;
- `for`;
- `switch`;
- `select`;
- обычные блоки `{}`.

<details>
  <summary>Пример</summary>

Здесь:

- `x` доступна во всей функции main.
- `y` доступна только внутри блока if.

```go
func main() {
    x := 10

    if true {
        y := 20

        fmt.Println(x) // 10
        fmt.Println(y) // 20
    }

    fmt.Println(x) // 10
    // fmt.Println(y) // Ошибка
}
```

</details>

<hr />

### Область видимости на уровне пакета

Переменные, объявленные вне функций, доступны всем функциям того же пакета.

Если имя переменной начинается с заглавной буквы,
она может быть экспортирована и доступна из других пакетов
(при условии, что переменная объявлена на уровне пакета).

<details>
  <summary>Пример</summary>

```go
package main

import "fmt"

var globalVar = 100

func main() {
    fmt.Println(globalVar)
}

func another() {
    fmt.Println(globalVar)
}
```

</details>

## Затенение переменных (Variable Shadowing)

Затенение — ситуация, когда внутри вложенной области видимости объявляется переменная с таким же именем, как во внешней области.

<details>
  <summary>Пример</summary>

Что происходит?

1. Сначала создаётся `x` = 10.
2. Внутри `if` создаётся новая переменная `x` = 20.
3. Внутренняя переменная затеняет внешнюю.
4. После выхода из `if` снова доступна внешняя `x`.

Обрати внимание: `:=` создаёт новую переменную, если в текущем блоке нет подходящей переменной с таким именем.

```go
package main

import "fmt"

func main() {
    x := 10

    if true {
        x := 20
        fmt.Println(x) // 20
    }

    fmt.Println(x) // 10
}
```

</details>

## Всплытие переменных (Hoisting)

В Go нет всплытия переменных. <br/>
Go требует, чтобы переменная была объявлена до использования.
