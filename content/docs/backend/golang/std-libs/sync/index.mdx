---
title: "sync"
---

Пакет `sync` — это стандартная библиотека Go для синхронизации горутин (goroutines) при параллельном выполнении кода.

Её главная задача — помогать безопасно работать с общими данными из нескольких горутин, предотвращать гонки данных (data races) и координировать доступ к ресурсам.

```go
import (
	"sync"
)
```
