`os` в Go (Golang) - это стандартный пакет для взаимодействия с операционной системой.

Он позволяет программе работать с файлами, папками, переменными окружения, аргументами командной строки и системными процессами.

```go
import "os"
```

<div className="hr-decor">✦</div>

## Аргументы командной строки - `os.Args`

```go
os.Args
```

<div className="hr-decor">✦</div>

## Работа с переменными окружения

### `os.Getenv()` - получает переменную окружения

```go
name := os.Getenv("NAME")
```

<hr />

### `os.Setenv()` - устанавливает переменную

```go
os.Setenv("NAME", "Alex")
```

<hr />

### `os.Unsetenv()` - удаляет переменную

<div className="hr-decor">✦</div>

## Работа с файлами

### `os.ReadFile()` - читает файл

```go
data, err := os.ReadFile("test.txt")
if err != nil {
    fmt.Println(err)
    return
}

fmt.Println(string(data))
```

## Завершение программы - `os.Exit()`

```go

```

Завершает программу с кодом `1` (обычно означает ошибку).
