Chi — это лёгкий, быстрый и удобный HTTP-роутер для Go.

Он построен поверх стандартного пакета `net/http`.

<div className="hr-decor">✦</div>

## Установка

```go
go get -u github.com/go-chi/chi/v5
```

<div className="hr-decor">✦</div>

## Использование

```go
import (
    "net/http"
    "github.com/go-chi/chi/v5"
)
```

```go
    r := chi.NewRouter()
    http.ListenAndServe(":3000", r)
```

<div className="hr-decor">✦</div>

## Маршруты (группировка)

Указать маршрут сразу:

```go
r.Get("/", func(w http.ResponseWriter, r *http.Request) {
    w.Write([]byte("Hello, Chi!"))
})
```

Или группировать:

```go
r.Route("/api", func(r chi.Router) {

    r.Route("/users", func(r chi.Router) {
        r.Get("/", getUsers)
        r.Post("/", createUser)
        r.Get("/{id}", getUser)
    })

    r.Route("/posts", func(r chi.Router) {
        r.Get("/", getPosts)
        r.Post("/", createPost)
    })

})
```

### URLPath NotFound

```go
r.NotFound(func(w http.ResponseWriter, r *http.Request) {
    w.Header().Set("Content-Type", "application/json")
    w.WriteHeader(http.StatusNotFound)

    json.NewEncoder(w).Encode(map[string]string{
        "error": "route not found",
    })
})
```

<hr />

### MethodNotAllowed

```go
r.MethodNotAllowed(func(w http.ResponseWriter, r *http.Request) {
    http.Error(w, "Method Not Allowed", http.StatusMethodNotAllowed)
})
```

### Dynamic path parameter

Динамический параметр маршрута (path parameter) `{}` - обозначает переменную часть URL, которая передаётся в обработчик

```go
r.Get("/URLPath/{id}", handler)
```

`{id}` — динамический параметр маршрута.

Чтобы получить его:

```go
func getUser(w http.ResponseWriter, r *http.Request) {
    id := chi.URLParam(r, "id")

    w.Write([]byte("User ID: " + id))
}
```
