В Go (Golang) циклы используются для многократного выполнения блока кода.
В отличие от многих языков программирования, в Go существует только одна конструкция цикла — `for`.
Но у неё есть несколько вариантов использования.

```go
for инициализацияСчетчика; условие; изменениеСчетчика {
    // код
}
```

1. **Инициализация** — выполняется один раз перед началом цикла.
2. **Условие** — проверяется перед каждой итерацией. Если `true`, цикл продолжается.
3. **Изменение** — выполняется после каждой итерации.

<details>
  <summary>Пример</summary>

```go
for i := 0; i < 5; i++ {
    fmt.Println(i)
}
```

</details>

## Цикл как `while`

В Go нет отдельного `while`, но его можно реализовать через `for`.

```go
for Условие {
  ...
}
```

<div className="hr-decor">✦</div>

## Бесконечный цикл

Если не указывать условие, цикл будет выполняться бесконечно.

Обычно такой цикл останавливают с помощью `break`.

```go
for {
    fmt.Println("Hello Go!")
}
```

<div className="hr-decor">✦</div>

## for range - итерация по коллекциям

`for range` позволяет пройтись по всем элементам, не управляя индексом вручную.

`for range` — это конструкция цикла, которая позволяет перебирать элементы коллекции: массивов, слайсов, строк, map и каналов (channels).

<Tabs items={['Классический', 'только value', 'только index', 'n - кол-во']}>
  <Tab value='Классический'>

    ```go
    for index, value := range numbers {
        fmt.Println(index, value)
    }
    ```

  </Tab>
  <Tab value='только value'>

    ```go
    for _, value := range numbers {
        fmt.Println(value)
    }
    ```

  </Tab>
  <Tab value='только index'>

    ```go
    for index := range numbers {
        fmt.Println(index)
    }
    ```

  </Tab>
    <Tab value='n - кол-во'>

    ```go
    for range n {             // for index := range n
        fmt.Println("Hello")  // 0 .. n - не включительно
    }
    ```

  </Tab>
</Tabs>

Здесь:

- `index` — индекс элемента.
- `value` — значение элемента.
- `range numbers` — перебирает все элементы.

<Callout title='Важно' type='warn'>

Порядок перебора элементов `map` в Go не гарантирован.

</Callout>

## Примеры (файл)

```go
package main

import (
	"fmt"
	"time"
)

// Циклы
func main() {
	// for - это единственный цикл в Go

	{ // Бесконечный цикл с условием выхода
		var counter int

		for {
			if counter == 10 {
				break // Выход из цикла
			}

			fmt.Println("Значение счётчика:", counter)

			counter++
		}
	}

	{ // Бесконечный цикл с условием продолжения
		var counter int

		for {
			fmt.Println("Значение счётчика:", counter)

			counter++

			if counter != 10 {
				continue
			}

			break
		}
	}

	{ // for инициализация ; условие; изменение счётчика {
		for i := 0; i < 10; i++ {
			fmt.Println("Значение счётчика:", i)
		}
	}

	{ // Можно так
		i := 0

		for ; i < 10; i++ {
			fmt.Println("Значение счётчика:", i)
		}
	}

	{ // Или так
		for i := 0; i < 10; {
			fmt.Println("Значение счётчика:", i)

			i++
		}
	}

	{ // И так
		i := 0

		for i < 10 {
			fmt.Println("Значение счётчика:", i)

			i++
		}
	}

	{ // Итерация по массиву
		var numbers = [5]int{1, 2, 3, 4, 5}

		for range numbers {
			fmt.Println("Привет!")
		}
	}

	{ // Тоже самое
		for range [5]int{1, 2, 3, 4, 5} {
			fmt.Println("Привет!")
		}
	}

	{ // Тоже самое. Сахар. Выводит "Привет!" 5 раз
		for range 5 {
			fmt.Println("Привет!")
		}
	}

	{ // Можно вывести индекс переменной
		for i := range []int{1, 2, 3, 4, 5} {
			fmt.Println("Индекс:", i)
		}
	}

	{ // Можно вывести индекс и значение
		for i, v := range []int{1, 2, 3, 4, 5} {
			fmt.Println("Индекс:", i, "Значение:", v)
		}
	}

	{ // Можно вывести только значение
		for _, v := range []int{1, 2, 3, 4, 5} {
			fmt.Println("Значение:", v)
		}
	}

	{ // Сахар. С индексом начиная с 0
		for i := range 5 {
			fmt.Println("Индекс", i)
		}
	}

	{ // Так нельзя // Err: range over 5 (untyped int constant) permits only one iteration variable
		//for i, v := range 5 {
		//	fmt.Println(i, v)
		//}
	}

	{ // Выход с помощью метки из вложенного цикла
	LOOP:
		for {
			for i := 0; i < 10; i++ {
				if i == 5 {
					break LOOP
				}
			}
		}
	}

	{ // Выход с помощью метки из Селекта
	loop:
		for {
			select {
			case <-time.After(time.Nanosecond):
				break loop
			}
		}
	}

	{ //

	}
}
```
