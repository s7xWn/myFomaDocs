title: "for"

В Go (Golang) циклы используются для многократного выполнения блока кода.
В отличие от многих языков программирования, в Go существует только одна конструкция цикла — `for`.
Но у неё есть несколько вариантов использования.

```go
for инициализацияСчетчика; условие; изменениеСчетчика {
    // код
}
```

1. **Инициализация** — выполняется один раз перед началом цикла.
2. **Условие** — проверяется перед каждой итерацией. Если `true`, цикл продолжается.
3. **Изменение** — выполняется после каждой итерации.

<details>
  <summary>Пример</summary>

```go
for i := 0; i < 5; i++ {
    fmt.Println(i)
}
```

</details>

<hr />

## Цикл как `while`

В Go нет отдельного `while`, но его можно реализовать через `for`.

```go
for Условие {
  ...
}
```

<hr />

## Бесконечный цикл

Если не указывать условие, цикл будет выполняться бесконечно.

Обычно такой цикл останавливают с помощью `break`.

```go
for {
    fmt.Println("Hello Go!")
}
```
