---
title: "Управление циклами (`continue`, `break`)"
---

Под «управлением циклами» обычно понимают способы влиять на ход выполнения цикла. Два основных оператора для этого — `break` и `continue`. <br/>
`break` и `continue` работают только для ближайшего (внутреннего) цикла. <br/>

<div className="hr-decor">✦</div>

## `continue`

`continue` пропускает текущую итерацию и переходит к следующей.

Когда выполняется `continue`, текущая итерация завершается, а цикл переходит к следующей.

<details>
  <summary>Пример</summary>

```go
for i := 0; i < 5; i++ {
    if i == 2 {
        continue
    }

    fmt.Println(i)
}
```

</details>

<hr />

### Переход на метку

Позволяет перейти к следующей итерации конкретного внешнего цикла.

```go
outer:
    for i := 0; i < 3; i++ {
        for j := 0; j < 3; j++ {
            if i == 1 && j == 1 {
                continue outer
            }
            fmt.Println(i, j)
        }
    }
```

<div className="hr-decor">✦</div>

## `break`

`break` полностью останавливает выполнение цикла.

Когда выполняется `break`, цикл немедленно завершается, и выполнение программы продолжается после него.

<details>
  <summary>Пример</summary>

```go
for i := 0; i < 10; i++ {
    if i == 5 {
        break
    }

    fmt.Println(i)
}
```

</details>

<hr />

### Переход на метку

Позволяет выйти из конкретного внешнего цикла, даже если циклов несколько.

```go
outer:
    for i := 0; i < 3; i++ {
        for j := 0; j < 3; j++ {
            if i == 1 && j == 1 {
                break outer
            }
            fmt.Println(i, j)
        }
    }
```

<div className="hr-decor">✦</div>

## label - метка

Метка (label) в Go — это именованная точка в коде, на которую можно перейти с помощью операторов `goto`, `break` или `continue`.

Важные особенности

- Метка объявляется внутри функции.
- Имя метки должно быть уникальным в пределах функции.
- Метка должна использоваться, иначе компилятор выдаст ошибку.
- `break` и `continue` с метками полезны при вложенных циклах.
- `goto` обычно стараются избегать, поскольку он может ухудшать читаемость кода.

<div className="hr-decor">✦</div>

## `goto`

Метка с `goto` позволяет перейти к определённому месту в функции.

```go
package main

import "fmt"

func main() {
    fmt.Println("Начало")

    goto finish

    fmt.Println("Этот код не выполнится")

finish:
    fmt.Println("Конец")
}
```
