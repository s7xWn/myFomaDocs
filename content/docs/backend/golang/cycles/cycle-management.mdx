---
title: "Управление циклами (`continue`, `break`)"
---

Под «управлением циклами» обычно понимают способы влиять на ход выполнения цикла. Два основных оператора для этого — `break` и `continue`. <br/>
`break` и `continue` работают только для ближайшего (внутреннего) цикла. <br/>

<hr />

## `continue`

`continue` пропускает текущую итерацию и переходит к следующей.

Когда выполняется `continue`, текущая итерация завершается, а цикл переходит к следующей.

<details>
  <summary>Пример</summary>

```go
for i := 0; i < 5; i++ {
    if i == 2 {
        continue
    }

    fmt.Println(i)
}
```

</details>

<hr />

## `break`

`break` полностью останавливает выполнение цикла.

Когда выполняется `break`, цикл немедленно завершается, и выполнение программы продолжается после него.

<details>
  <summary>Пример</summary>

```go
for i := 0; i < 10; i++ {
    if i == 5 {
        break
    }

    fmt.Println(i)
}
```

</details>
