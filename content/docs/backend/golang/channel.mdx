Канал (channel) в Go (Golang) - это встроенный механизм для безопасного обмена данными между горутинами (goroutines). Размер канала на стеке: 8 байт.

Проще говоря, канал - это труба, через которую одна горутина может передать данные другой.

В Go есть два вида каналов: небуферизированные (Unbuffered Channel) и буферизированные (Buffered Channel).

Главное отличие между ними - нужно ли получателю сразу забрать данные или их можно временно сохранить в канале.

## Виды каналов

### Небуферизированный канал

У такого канала нет собственной памяти для хранения ожидающих значений. Он синхронный.

#### Отправитель готов, получателя нет.

```go
ch <- 10
```

Горутина блокируется и ждёт, пока другая горутина не прочитает значение.

#### Получатель готов, отправителя нет.

```go
value := <-ch
```

Горутина блокируется и ждёт, пока кто-нибудь не отправит значение.

#### Отправитель и получатель готовы.

```go
ch <- 10
value := <-ch
```

Значение передаётся, обе операции завершаются.

<details>
  <summary>Хороший код-пример</summary>

```go
package main

import (
	"fmt"
	"time"
)

func main() {
	{ // Небуферизированный канал
		var ch = make(chan int)

		go func() {
			for {
				value, ok := <-ch
				if !ok {
					fmt.Println("Канал закрыт! Выходим")

					return
				}

				fmt.Println("Получили:", value)

				time.Sleep(time.Second)
			}
		}()

		ch <- 1 // После этого блокируемся, и разблокируемся как кто-то прочитает этот канал
		ch <- 2
		ch <- 3

		fmt.Println("Отправили все 3 значения")

		close(ch)

		time.Sleep(3 * time.Second)
	}
}
```

</details>

<details>
  <summary>Пример аналогия</summary>

Представь, что ты передаёшь человеку коробку из рук в руки. Ты не можешь просто оставить её на столе. Человек должен принять её.

```go
package main

import "fmt"

func main() {
    ch := make(chan int)

    go func() {
        ch <- 100
        fmt.Println("Отправили данные")
    }()

    value := <-ch

    fmt.Println("Получили:", value)
}
```

Что происходит:

1. Создаётся канал без буфера.
2. Запускается новая горутина.
3. Горутина пытается отправить `100`.
4. Главная горутина получает `100`.
5. Отправка завершается.

</details>

<hr />

### Буферизированный канал

Канал может временно хранить три значения.

<details>
  <summary>Пример аналогия</summary>

Представь почтовый ящик: ты можешь положить туда письма, даже если получатель ещё не пришёл.

```go
package main

import "fmt"

func main() {
    ch := make(chan int, 3)

    ch <- 10
    ch <- 20
    ch <- 30

    fmt.Println(<-ch)
    fmt.Println(<-ch)
    fmt.Println(<-ch)
}
```

Мы отправили все три значения до того, как начали их получать.

Это возможно, потому что канал имеет буфер на три элемента.

</details>

## Использование каналов

Каналы в Go можно использовать и без горутин. Но чаще всего они применяются именно для обмена данными и синхронизации между горутинами.

Разберём три ситуации.

<hr />

### Канал без горутин

Можно создать канал и отправить в него данные, но есть важный нюанс - deadlock

```go
func main() {
    ch := make(chan int)

    ch <- 10 // deadlock!

    value := <-ch
    fmt.Println(value)
}
```

Небуферизированный канал ждёт получателя, а текущая горутина заблокировалась на отправке.

Никто не сможет выполнить чтение.

<hr />

### Буферизированный канал без горутин

```go
func main() {
    ch := make(chan int, 2)

    ch <- 10
    ch <- 20

    fmt.Println(<-ch)
    fmt.Println(<-ch)
}
```

Буферизированный канал может временно хранить данные без немедленного получателя.

Но если буфер заполнится, отправка заблокируется.

<hr />

### Каналы вместе с горутинами

```go
package main

import "fmt"

func worker(ch chan int) {
    ch <- 100
}

func main() {
    ch := make(chan int)

    go worker(ch)

    result := <-ch

    fmt.Println(result)
}
```

Здесь:

- `worker` работает в отдельной горутине.
- `worker` отправляет данные в канал.
- `main` получает данные.

## Основные операции

### Создание - `make()`

#### Небуферизированный канал

```go
ch := make(chan typeName)
```

- `chan` - тип канала.
- `typeName` - тип данных, которые можно передавать. (int, string)
- `ch` - переменная канала.

#### Буферизированный канал

```go
ch := make(chan typeName, lim)
```

- `chan` - тип канала.
- `typeName` - тип данных, которые можно передавать. (int, string)
- `ch` - переменная канала.
- `lim` - кол-во значений, которые вместит буфер

<hr />

### Создание `nil` канал (Zero value)

<Callout title='' type='tip'>

Не имеет смысла

</Callout>

```go
var ch chan int
```

<hr />

### Отправить данные - `ch <-`

```go
ch <- 42
```

<hr />

### Получить данные - `<-ch`

```go
<-ch
// =
_ = <-ch
```

```go
value := <-ch
```

```go
value, ok := <-ch
if !ok {
    fmt.Println("Канал закрыт! Выходим")

    return
}
```

<hr />

### Длина канала - `len()`

```go
len(ch)
```

<hr />

### Закрыть канал - `close()`

<Callout title='' type='tip'>

Канал обычно закрывает отправитель, а не получатель.

</Callout>

```go
close(ch)
```

- Читать из канала - Можно
- Читать из пустого канала - Получим нулевое значение и `ok == false`
- Отправлять в канал - Паника (panic)
- Повторно закрывать канал - Паника (panic)

<details>
  <summary>Пример</summary>

```go
package main

import "fmt"

func main() {
	{ // Закрытие канала
		var ch = make(chan int, 1)

		ch <- 42

		close(ch)

		value, ok := <-ch
		fmt.Println("Value:", value, "IsOpen:", ok)

		value, ok = <-ch
		fmt.Println("Value:", value, "IsOpen:", ok)

		//close(ch) // Закрытие уже закрытого канала вызывает панику
		//ch <- 42 // Запись в закрытый канал тоже вызывает панику
	}
}
```

</details>

## `select`

В Go `select` - это специальная конструкция языка,
которая позволяет одновременно ожидать несколько операций с каналами (channels) и выполнить ту, которая будет готова первой.

Проще говоря, `select` для каналов - примерно то же самое, что `switch` для обычных значений.

```go
select {
case msg := <-ch1:
    fmt.Println("Получили из ch1:", msg)

case msg := <-ch2:
    fmt.Println("Получили из ch2:", msg)

default:
}
fmt.Println("Нет готовых данных")
```

<Callout title='' type='tip'>

`default` нужен просто чтобы выйти из селекта если все кейсы заблокированы. <br/>

<Callout title='' type='warn'>

Без `default` / Если несколько каналов готовы:<br/>
**выбирается один случайным образом.**

</Callout>
Чтобы упростить код, `default` оставляют пустой, а логику пишут ниже.

</Callout>

Как это работает:

- Go проверяет все `case`.
- Если готов только один - выполняет его.
- Если ни один не готов - блокируется и ждёт.
- Если есть `default` - выполняет его сразу, не ожидая канала

<details>
  <summary>Пример с двумя каналами</summary>

Здесь две горутины отправляют сообщения в разные каналы.

`select` ждёт, пока хотя бы один канал будет готов к чтению, и обрабатывает одно сообщение.

```go
package main

import "fmt"

func main() {
    ch1 := make(chan string)
    ch2 := make(chan string)

    go func() {
        ch1 <- "Привет из первого канала"
    }()

    go func() {
        ch2 <- "Привет из второго канала"
    }()

    select {
    case msg := <-ch1:
        fmt.Println(msg)

    case msg := <-ch2:
        fmt.Println(msg)
    }
}
```

</details>

<hr />

### Использование `select` с `default`

Можно проверить, есть ли данные в канале, не блокируя выполнение.

<Callout title='' type='tip'>

Это называется неблокирующим чтением.

</Callout>

<Callout title='' type='tip'>

`default` нужен просто чтобы выйти из селекта если все кейсы заблокированы. <br/>
Чтобы упростить код, `default` оставляют пустой, а логику пишут ниже.

</Callout>

```go
select {
case msg := <-ch:
    fmt.Println("Получили:", msg)

default:
}
fmt.Println("Канал пока пуст")
```

<hr />

### Использование `select` с таймером

Очень полезная возможность - ограничение времени ожидания.

```go
select {
case msg := <-ch:
    fmt.Println("Получили:", msg)

case <-time.After(3 * time.Second):
    fmt.Println("Время ожидания истекло")
}
```

<hr />

### `Select` в бесконечном цикле

Часто используется для обработки нескольких каналов:

```go
for {
    select {
    case msg := <-ch1:
        fmt.Println("Первый:", msg)

    case msg := <-ch2:
        fmt.Println("Второй:", msg)
    }
}
```

## Пример (файл)

Буферизированный канал:

```go
package main

import "fmt"

func main() {
	{ // Буферизированный канал
		var ch = make(chan int, 3)

		ch <- 1
		ch <- 2
		ch <- 3

		value := <-ch // Читаем канал и присваиваем значение в переменную

		fmt.Println(value) // 1

		<-ch // Читаем канал и отбрасываем значение

		value = <-ch

		fmt.Println(value) // 3

	}
}
```

`Select`:

```go
package main

import "fmt"

func main() {
	{ // Select - конструкция для работы с каналами
		ch1 := make(chan int, 10)
		ch2 := make(chan int, 10)
		ch3 := make(chan int, 10)

		ch1 <- 1
		ch2 <- 2
		ch3 <- 3

		var value int

		select {
		case value = <-ch1:
		case value = <-ch2:
		case value = <-ch3:
		}

		fmt.Println(value) // Случайное число: 1, 2 или 3
	}

	{ // Default
		ch1 := make(chan int, 10)
		ch2 := make(chan int, 10)

		var value int

		select {
		case value = <-ch1:
		case value = <-ch2:
		default:
		}

		fmt.Println("Default case:", value) // 0
	}

	// default нужен просто чтобы выйти из селекта если все кейсы заблокированы.
	// Чтобы упростить код, default оставляют пустой, а логику пишут ниже.
	tasks := make(chan int, 10)
	stop := make(chan int)

	{ // Вот это
		select {
		case <-stop:
			break
		default:
			tasks <- 42 // мы тут можем заблокироваться и не узнать что канал stop закрыт
		}
	}

	{ // И вот это, одно и тоже
		select {
		case <-stop:
			break
		default:
		}

		tasks <- 42 // мы тут можем заблокироваться и не узнать что канал stop закрыт
	}
}
```

Ошибки:

```go
package main

import "fmt"

func main() {
	{ // Работа с неинициализированным каналом
		var ch chan int
		ch <- 1 // fatal error: all goroutines are asleep - deadlock!
	}

	{ // Дедлок - никто не читает
		var ch = make(chan int, 1)

		ch <- 1
		ch <- 1 // fatal error: all goroutines are asleep - deadlock!
	}

	{ // Дедлок - никто не пишет
		var ch = make(chan int, 1)

		<-ch // fatal error: all goroutines are asleep - deadlock!
	}

	{ // Закрытие закрытого канала
		var ch = make(chan int, 1)
		close(ch)
		close(ch) // panic: close of closed channel
	}

	{ // Запись в закрытый канал
		var ch = make(chan int, 1)
		close(ch)
		ch <- 1 // panic: send on closed channel
	}

	{ // Чтение из закрытого канала - OK!
		var ch = make(chan int, 1)
		close(ch)

		_, ok := <-ch
		if !ok {
			fmt.Println("Channel is closed")
		}
	}

	{ // For range закрытого канала - OK!
		var ch = make(chan int, 1)

		ch <- 1

		close(ch)

		for value := range ch {
			fmt.Println("Прочитано из канала:", value)
		}

		fmt.Println("Прочитали всё из канала и вышли из цикла")
	}

	{ // Select закрытого канала - OK!
		var ch = make(chan int, 1)
		close(ch)

		select {
		case value := <-ch:
			fmt.Println("Прочитано из канала (zero value):", value)
		default:
			fmt.Println("Канал закрыт")
		}
	}
}

```
