---
title: "Go vendor (vendoring)"
---

Go vendor (vendoring) — это механизм в Go, который позволяет хранить исходный код всех внешних зависимостей проекта непосредственно внутри репозитория.

Например, вместо того чтобы при сборке скачивать библиотеки из интернета, проект использует их локальные копии из директории `vendor/`.

Использовать:

```bash
go mod vendor
```

После этого:

- Go копирует необходимые зависимости в `vendor/`.
- Исходники зависимостей хранятся вместе с проектом.
- При сборке Go может использовать локальные копии вместо загрузки модулей из сети.

## Запуск используя vendor

```bash
go run -mod=vendor .
```

<div className="hr-decor">✦</div>

## Рекомендация

Для нового проекта лучше использовать Go Modules без `vendor/`.

Vendoring имеет смысл, если:

- нужна сборка без доступа к интернету;
- есть строгие требования безопасности;
- инфраструктура CI/CD требует локальных зависимостей;
- нужно хранить весь исходный код для сборки внутри репозитория.

| Преимущество    | Объяснение                                            |
| --------------- | ----------------------------------------------------- |
| Offline builds  | Можно собирать проект без интернета                   |
| Reproducibility | Все исходники зависимостей находятся рядом            |
| Security        | Можно контролировать код зависимостей                 |
| CI/CD           | Сборка не зависит от доступности внешних репозиториев |
