title: "Битовые"
---

| Оператор | Название                        | Описание                                                             | Пример          |
| -------- | ------------------------------- | -------------------------------------------------------------------- | --------------- |
| `&`      | Побитовое И (AND)               | Устанавливает бит в 1, если оба соответствующих бита равны 1         | `5 & 3` → `1`   |
| `\|`     | Побитовое ИЛИ (OR)              | Устанавливает бит в 1, если хотя бы один соответствующий бит равен 1 | `5 \| 3` → `7`  |
| `^`      | Побитовое исключающее ИЛИ (XOR) | Устанавливает бит в 1, если соответствующие биты различаются         | `5 ^ 3` → `6`   |
| `&^`     | Побитовое И НЕ (AND NOT)        | Сбрасывает биты первого числа, которые установлены во втором         | `5 &^ 3` → `4`  |
| `<<`     | Сдвиг влево (Left Shift)        | Сдвигает биты числа влево на указанное количество позиций            | `5 << 1` → `10` |
| `>>`     | Сдвиг вправо (Right Shift)      | Сдвигает биты числа вправо на указанное количество позиций           | `5 >> 1` → `2`  |

<div className="hr-decor">✦</div>

## Примеры (файл)

```go
package main

// Побитовые операторы
func main() {
	// | побитовое ИЛИ
	_ = 5 | 2 // 7 (101 | 010 = 111)

	// & побитовое И
	_ = 6 & 2 // 2 (110 & 010 = 010)

	// ^ побитовое исключающее ИЛИ
	_ = 5 ^ 2 // 7 (101 ^ 010 = 111)

	// &^ побитовое И с очисткой
	_ = 6 &^ 2 // 4 (110 &^ 010 = 100)

	// << побитовый сдвиг влево
	_ = 1 << 2 // 4 (001 << 2 = 100)

	// >> побитовый сдвиг вправо
	_ = 4 >> 2 // 1 (100 >> 2 = 001)
}
```
