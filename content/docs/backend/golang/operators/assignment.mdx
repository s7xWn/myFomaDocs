---
title: "Присовения"
---

| Оператор | Пример   | Эквивалент  |
| :------: | :------- | :---------- |
|   `+=`   | `a += 5` | `a = a + 5` |
|   `-=`   | `a -= 5` | `a = a - 5` |
|   `*=`   | `a *= 2` | `a = a * 2` |
|   `/=`   | `a /= 2` | `a = a / 2` |
|   `%=`   | `a %= 3` | `a = a % 3` |

| Оператор | Название                          | Эквивалент   |
| -------- | --------------------------------- | ------------ |
| `&=`     | Побитовое И с присваиванием       | `a = a & b`  |
| `\|=`    | Побитовое ИЛИ с присваиванием     | `a = a \| b` |
| `^=`     | Побитовое XOR с присваиванием     | `a = a ^ b`  |
| `&^=`    | Побитовое AND NOT с присваиванием | `a = a &^ b` |
| `<<=`    | Сдвиг влево с присваиванием       | `a = a << b` |
| `>>=`    | Сдвиг вправо с присваиванием      | `a = a >> b` |
