---
title: "Присовения"
---

| Оператор | Пример    | Эквивалент   |
| :------: | :-------- | :----------- |
|   `+=`   | `a += 5`  | `a = a + 5`  |
|   `-=`   | `a -= 5`  | `a = a - 5`  |
|   `*=`   | `a *= 2`  | `a = a * 2`  |
|   `/=`   | `a /= 2`  | `a = a / 2`  |
|   `%=`   | `a %= 3`  | `a = a % 3`  |
|   `&=`   | `a &= b`  | `a = a & b`  |
|  `\|=`   | `a \|= b` | `a = a \| b` |
|   `^=`   | `a ^= b`  | `a = a ^ b`  |
|  `<<=`   | `a <<= 1` | `a = a << 1` |
|  `>>=`   | `a >>= 1` | `a = a >> 1` |
|  `&^=`   | `a &^= b` | `a = a &^ b` |
