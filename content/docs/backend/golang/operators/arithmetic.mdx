---
title: "Арифметические"
---

Используются для математических вычислений

| Оператор | Название                    | Пример  |  Результат  |
| :------: | :-------------------------- | :------ | :---------: |
|   `+`    | Сложение (Addition)         | `5 + 3` |     `8`     |
|   `-`    | Вычитание (Subtraction)     | `5 - 3` |     `2`     |
|   `*`    | Умножение (Multiplication)  | `5 * 3` |    `15`     |
|   `/`    | Деление (Division)          | `6 / 3` |     `2`     |
|   `%`    | Остаток от деления (Modulo) | `5 % 3` |     `2`     |
|   `++`   | Инкремент (Increment)       | `a++`   | `a = a + 1` |
|   `--`   | Декремент (Decrement)       | `a--`   | `a = a - 1` |
