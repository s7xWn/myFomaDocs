`fmt` — это стандартный пакет (package) в языке программирования Go (Golang), который используется для форматирования и вывода данных.

```go
import "fmt"
```

| Функция         | Описание                           | Пример                      |
| --------------- | ---------------------------------- | --------------------------- |
| `fmt.Print()`   | Выводит данные без переноса строки | `fmt.Print("Hello")`        |
| `fmt.Println()` | Выводит данные с переносом строки  | `fmt.Println("Hello")`      |
| `fmt.Printf()`  | Выводит данные с форматированием   | `fmt.Printf("Age: %d", 20)` |

| Функция          | Описание                                                                | Пример                           |
| ---------------- | ----------------------------------------------------------------------- | -------------------------------- |
| `fmt.Sprintf()`  | Создаёт отформатированную строку                                        | `fmt.Sprintf("Age: %d", 20)`     |
| `fmt.Sprint()`   | Создаёт строку из переданных значений                                   | `fmt.Sprint("Age: ", 20)`        |
| `fmt.Sprintln()` | Создаёт строку с пробелами между аргументами и переносом строки в конце | `fmt.Sprintln("Hello", "World")` |

| Функция        | Описание                               | Пример                  |
| -------------- | -------------------------------------- | ----------------------- |
| `fmt.Scan()`   | Считывает данные из стандартного ввода | `fmt.Scan(&name)`       |
| `fmt.Scanln()` | Считывает данные до перевода строки    | `fmt.Scanln(&name)`     |
| `fmt.Scanf()`  | Считывает данные по формату            | `fmt.Scanf("%d", &age)` |

| Функция          | Описание                                         | Пример                                  |
| ---------------- | ------------------------------------------------ | --------------------------------------- |
| `fmt.Fprint()`   | Записывает данные в указанный поток              | `fmt.Fprint(os.Stdout, "Hello")`        |
| `fmt.Fprintln()` | Записывает данные с пробелами и переносом строки | `fmt.Fprintln(os.Stdout, "Hello")`      |
| `fmt.Fprintf()`  | Записывает форматированные данные в поток        | `fmt.Fprintf(os.Stdout, "Age: %d", 20)` |
| `fmt.Fscan()`    | Считывает данные из указанного источника         | `fmt.Fscan(reader, &name)`              |
| `fmt.Fscanln()`  | Считывает данные до перевода строки из источника | `fmt.Fscanln(reader, &name)`            |
| `fmt.Fscanf()`   | Считывает данные из источника по формату         | `fmt.Fscanf(reader, "%d", &age)`        |
| `fmt.Errorf()`   | Создаёт форматированную ошибку                   | `fmt.Errorf("invalid age: %d", age)`    |

<hr />

## `fmt.Println()` — вывод с переносом строки

```go
fmt.Println("Hello, World!")
fmt.Println(42)
```

<hr />

## `fmt.Print()` — вывод без переноса строки

```go
fmt.Print("Hello")
```

<hr />

## `fmt.Printf()` — форматированный вывод

```go
name := "Alex"
age := 20

fmt.Printf("Меня зовут %s, мне %d лет\n", name, age)
```

### Основные спецификаторы форматирования:

| Спецификатор | Значение                       |
| ------------ | ------------------------------ |
| `%s`         | Строка                         |
| `%d`         | Целое число                    |
| `%f`         | Число с плавающей точкой       |
| `%t`         | Boolean (true / false)         |
| `%v`         | Значение в стандартном формате |
| `%T`         | Тип переменной                 |
| `%p`         | Адрес в памяти                 |

<hr />

## `fmt.Scan()` — ввод данных

```go
var name string

fmt.Print("Введите имя: ")
fmt.Scan(&name)

fmt.Println("Привет,", name)
```

<hr />

## `fmt.Sprintf()` — создание отформатированной строки

```go
name := "Alex"
age := 20

result := fmt.Sprintf("%s: %d лет", name, age)

fmt.Println(result)
```
