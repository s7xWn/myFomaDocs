## Команды[#commands]

### `install` - скачать, компилировать, установить[#install]

Команда `go install` в Go скачивает, компилирует и устанавливает исполняемую программу в директорию `bin` внутри [`GOPATH`](#env).

1. Go определяет модуль и версию, указанную в команде (@latest, @v1.2.3 и т. д.).
2. Проверяет локальный Go Module Cache [`GOMODCACHE`](#env).
3. Если нужного модуля или версии нет в кэше, обращается к источнику загрузки:
   1. Обращается к [`GOPROXY`](#env).
      - Если настроен `direct` и прокси возвращает подходящий статус ошибки (например, 404 или 410), Go обращается непосредственно к репозиторию.
   2. Получает информацию о модуле:
      - Список доступных версий (`@v/list`) — если требуется определить версию.
      - Метаданные версии (`.info`).
      - Файл зависимостей (`.mod`).
      - Исходный код (`.zip`).
4. Скачивает необходимые зависимости устанавливаемого модуля.
5. Сохраняет скачанные модули в локальный кэш [`GOMODCACHE`](#env).
6. Проверяет контрольные суммы через go.sum и checksum database (если применимо).
7. Компилирует программу.
8. Использует [`GOCACHE`](#env) для повторного использования результатов компиляции.
9. Устанавливает готовый бинарный файл в [`GOBIN`](#env) (или $[`GOPATH`](#env)/bin, если [`GOBIN`](#env) не задан).

```bash
go install <module-path>/<package-path>@<version>
```

<Callout title='' type='tip'>

Обычно ставятся инструменты для разработки

</Callout>

<details>
  <summary>Пример</summary>

```bash
go install github.com/swaggo/swag/cmd/swag@latest
```

- `github.com/swaggo/swag` - путь к Go-модулю (module path).
- `/cmd/swag` - путь к пакету внутри модуля, который содержит исполняемую программу (`package main`).
  - это **не непосредственно** путь к `main.go`, а путь к директории Go-пакета. В этой директории могут находиться несколько `.go `файлов, включая `main.go`.
- `@latest` - версия модуля, которую нужно установить.

</details>

### `mod`[#mod]

```bash
go mod init <NAME/URL>       # URL без http(s), например: gitlab.golang-school.ru/username/my-app
go mod init <NAME>           # Создаёт модуль с указанной версией
go mod download              # Загружает зависимости в кэш
go mod vendor                # Создаёт папку vendor с зависимостями
```

### `get` - добавление пакета в проект[#get]

```bash
go get <package>[@ver]
```

Необязательно:

`@ver` - Символ `@` позволяет указать конкретную версию зависимости.

1. Go проверяет `go.mod` и определяет текущие зависимости.
2. Проверяет локальный Go Module Cache [`GOMODCACHE`](#env).
3. Если нужного модуля или версии нет в кэше, обращается к источнику загрузки:
   1. Обратится к [`GOPROXY`](#env).
      - Если настроен `direct` и прокси возвращает подходящий статус ошибки (например, 404 или 410), Go обращается непосредственно к репозиторию.
   2. Получает информацию о модуле:
      - Список доступных версий (`@v/list`).
      - Метаданные версии (`.info`).
      - Файл зависимостей (`.mod`).
      - Исходный код (`.zip`).
4. Скачивает необходимые зависимости модулей.
5. Сохраняет скачанный модуль в локальный кэш. [`GOMODCACHE`](#env)
6. Проверяет контрольные суммы через `go.sum` и checksum database (если применимо).
7. Добавляет зависимость в `go.mod`.
8. Обновляет `go.sum` — файл с контрольными суммами зависимостей.

Если модуль уже есть в кэше и нужна та же версия:

- Go не скачивает его повторно без необходимости.
- Использует локальную копию.
- Может обращаться к сети для проверки доступности более новых версий или обновления метаданных — в зависимости от команды и ситуации.

Очистить кэш модулей можно командой: `go clean -modcache`

#### `-u` - обновить

Флаг `-u` означает **update** — обновить зависимости.

```bash
go get -u <package>
```

- Обновляет указанную библиотеку до последней доступной совместимой версии.
- Обновляет её зависимости (в том числе транзитивные) в пределах правил обновления Go.

### `env`[#env]

```bash
go env
```

— это команда в языке программирования Go (Golang), которая показывает настройки окружения (environment variables), используемые компилятором и инструментами Go.

| Параметр     | Значение                                                                  |
| ------------ | ------------------------------------------------------------------------- |
| `GOARCH`     | Архитектура, для которой собирается программа (целевая архитектура)       |
| `GOOS`       | Операционная система, для которой собирается программа.                   |
| `GOHOSTARCH` | Архитектура машины, на которой выполняется компилятор или процесс сборки. |
| `GOHOSTOS`   | Операционная система, на которой выполняется сборка.                      |
| `GOROOT`     | Путь к установленному Go                                                  |
| `GOPATH`     | Рабочая директория Go                                                     |
| `GOBIN`      | Папка для исполняемых файлов                                              |
| `GOMOD`      | Путь к файлу go.mod                                                       |
| `GOMODCACHE` | Скачанные и распакованные зависимости.                                    |
| `GOCACHE`    | Кэш результатов компиляции Go.                                            |
| `GOPROXY`    | Определяет, откуда Go будет скачивать зависимости (Go Modules)            |

#### `param`

Посмотреть конкретную настройку

```bash
go env <param>
```

#### `-w param`

Изменить настройку

```bash
go env -w <param>=<value>
```

## Первая минимальная программа [#first-min]

Минимальная исполняемая программа на Go состоит из двух обязательных элементов:

1. [`package main`](./packages.mdx) — объявляет пакет main, который является точкой входа для исполняемой программы.
2. [`func main()`]() — главная функция, с которой начинается выполнение программы.

```go
package main

func main() {
}
```

## Минимальный Docker-file

```dockerfile
FROM golang:1.23.5-alpine3.20 AS build

WORKDIR /app

# Modules layer
COPY go.mod go.sum ./
RUN go mod download

# Build layer
COPY . .
RUN CGO_ENABLED=0 GOOS=linux GOARCH=amd64 \
    go build -o /myapp ./cmd/app

FROM alpine:3.20 AS run

COPY --from=build /myapp /myapp

EXPOSE 8080

CMD ["/myapp"]
```

- `GOOS=linux ` - Операционная система, для которой собирается программа.
- `GOARCH=amd64` - Архитектура, для которой собирается программа (целевая архитектура)
