## Основные направления в безопасности

1. AppSec (Application Security) <br/>
   Безопасность приложений: поиск уязвимостей в коде, защита API, предотвращение SQL-инъекций и XSS. Работает в тесной связке с Backend и Frontend.
2. Pentester (Penetration Tester) <br/>
   Проверяет системы на взлом, ищет уязвимости и пытается использовать их, как это сделал бы злоумышленник, но с разрешения владельца.
3. DevSecOps <br/>
   Встраивает безопасность в разработку и инфраструктуру: проверка зависимостей, контейнеров, CI/CD и облачных систем.
4. SOC Analyst / Security Analyst <br/>
   Следит за атаками, анализирует подозрительную активность, расследует инциденты и помогает предотвращать взломы.

## Специалист, который отвечает за безопасность в целом:

- Security Engineer — технически защищает системы и инфраструктуру.
- Application Security Engineer — специализируется на безопасности программного обеспечения.
- Cybersecurity Engineer — более широкое название специалиста по кибербезопасности.
- CISO — руководитель направления информационной безопасности.
