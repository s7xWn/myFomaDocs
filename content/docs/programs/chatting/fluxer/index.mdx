Fluxer — это бесплатный мессенджер с открытым исходным кодом, похожий на Discord. Он предназначен для общения в личных сообщениях, группах и сообществах, с голосовыми и видеозвонками. Главная особенность — возможность запустить его на собственном сервере и самостоятельно контролировать свои данные.

Чем он отличается от Discord?

| Возможность                                 | Fluxer                             | Discord                          |
| ------------------------------------------- | ---------------------------------- | -------------------------------- |
| Текстовые и голосовые чаты                  | Да                                 | Да                               |
| Открытый исходный код                       | Да                                 | Нет                              |
| Установка на собственный сервер             | Да                                 | Нет                              |
| Контроль над собственным сервером и данными | Да, при самостоятельном размещении | Ограничен платформой             |
| Федерация между серверами                   | В разработке                       | Не является стандартной функцией |

## Установка - Сервера

### Windows (PS + Docker)

Установщик через PowerShell - [off. website/install.ps1](https://fluxer.dev/install.ps1)

Замените `chat.example.com` на свой настоящий домен, прежде чем выполнять команду.<br/>
Для полноценной установки с публичным доменом команда из официальной инструкции адаптируется для PowerShell так:

```cmd
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Domain chat.example.com
```

- `-ExecutionPolicy Bypass` - разрешает выполнить этот скрипт в рамках текущего запуска PowerShell, не меняя постоянную политику выполнения системы.
- `-File` - указывает, какой файл запускать.
- `-Domain` - передаёт установщику имя сервера.

После запониаем token, такого формата `874ce6e511fd862d82f3ece95188756894ef08fb0fda175e54b9133d76072099`:

```
All 26 services report healthy.
Instance ready at https://chat.example.com
Open it and enter this setup token to create the admin account:

  874ce6e511fd862d82f3ece95188756894ef08fb0fda175e54b9133d76072099

Secrets are in C:\Users\userName\fluxer\.env. Back that file up.
```

#### Ошибки с расположением файлов

```bash
cd "$HOME\fluxer"
```

```bash
docker compose config --quiet
```

#### Настройка для локальной разработки

Изменяем `.env`:

```
FLUXER_DOMAIN=localhost
FLUXER_PUBLIC_SCHEME=http
FLUXER_PUBLIC_PORT=1337
FLUXER_HTTP_PORT=1337
```

Полсе:

```bash
docker compose config --quiet
docker compose up -d
```

`docker compose ps edge` должен выводить что-то такое:

```
docker compose ps edge
NAME            IMAGE               COMMAND                  SERVICE   CREATED          STATUS                    PORTS
fluxer-edge-1   caddy:2.11-alpine   "caddy run --config …"   edge      20 seconds ago   Up 16 seconds (healthy)   0.0.0.0:443->443/tcp, 0.0.0.0:443->443/udp, [::]:443->443/tcp, [::]:443->443/udp, 0.0.0.0:1337->80/tcp, [::]:1337->80/tcp
```

### Настройка Firewall

```bash
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw allow 443/udp
sudo ufw allow 7881/tcp
sudo ufw allow 7882/udp
```
