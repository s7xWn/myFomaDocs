Fork — это приложение для работы с Git через графический интерфейс.
Оно помогает разработчикам управлять версиями кода, просматривать историю изменений и работать с ветками без необходимости постоянно вводить команды в терминале.

Есть бесплатный пробный период. Лицензия рассчитана на одного пользователя и до трёх компьютеров одновременно.
