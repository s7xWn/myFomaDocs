GitKraken — это платформа для разработчиков, в которую входит графический Git-клиент GitKraken Desktop.
GitKraken также предлагает дополнительные инструменты для командной работы и интеграции с ИИ-агентами.

## Тарифы

- Community — бесплатно: работа с локальными репозиториями и публичными удалёнными репозиториями.
- Pro и более дорогие тарифы: доступ к приватным репозиториям и дополнительные функции в зависимости от тарифа.
- Есть 14-дневный пробный период расширенных возможностей.
