## Команды

```bash
yt-dlp "https://www.youtube.com/watch?v=XXXXXXXXXXX"
```

Файл сохранится в текущую папку Terminal.

```bash
yt-dlp \
-f "bv*[vcodec^=avc1][ext=mp4]+ba[acodec^=mp4a][ext=m4a]" \
--merge-output-format mp4 \
-o "%(title)s.%(ext)s" \
"https://www.youtube.com/watch?v=243pQXC5Ebs"
```
