## Команды

### Запуск

```bash
llama serve -m "file.gguf"
```

#### Модель `-m`

Model — путь к файлу модели.

#### Размер контекстного окна `-c`

```
-c 4096    → 4K контекста
-c 8192    → 8K
-c 16384   → 16K
-c 32768   → 32K
```

#### Кол-во слоёв выгружать на GPU `-ngl`

<Callout title="Важный момент" type="warn">
  `-ngl all` не означает «использовать 100% VRAM любой ценой». Контекст,
  KV-cache и другие буферы тоже занимают память.
</Callout>

#### Имя модели `--alias`

Задаёт имя модели, которое будет показываться клиентам API.

Например, без alias клиент может увидеть длинное имя GGUF-файла.
