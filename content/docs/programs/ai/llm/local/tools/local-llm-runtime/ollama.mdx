Ollama — это программа для запуска больших языковых моделей (LLM) локально на своём компьютере.
Она позволяет скачать модель вроде Llama, Qwen, Gemma или Mistral и общаться с ней без постоянной отправки запросов в облачный сервис.

<Callout type="success">

Производительность сильно зависит от вашего **CPU/GPU** и объёма **RAM/VRAM**.

</Callout>

<hr />

## Установка

### Windows

[Устновщик](https://ollama.com/download/OllamaSetup.exe)

или

**PowerShell**:

```bash
irm https://ollama.com/install.ps1 | iex
```

### Mac

[Устновщик](https://ollama.com/download/Ollama.dmg)

### Linux

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

<hr />

## Команды

### Запуск в Harness

```
ollama launch <harness> --model <model>
```

| Harness      | Bash                                        |
| ------------ | ------------------------------------------- |
| Claude Code  | `ollama launch claude --model model_name`   |
| OpenCode     | `ollama launch opencode --model model_name` |
| Hermes Agent | `ollama launch hermes --model model_name`   |
| OpenClaw     | `ollama launch openclaw --model model_name` |
