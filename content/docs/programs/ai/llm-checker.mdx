LLM Checker — утилита, которая смотрит на твоё железо и подбирает локальные LLM, которые реально имеет смысл запускать через Ollama. Она учитывает RAM/VRAM, CPU/GPU, размер модели, скорость и контекст.

<hr />

## Установка

Нужны **Node.js 18+** и **Ollama**.

```bash
npm install -g llm-checker
```

<hr />

## Команды

| Описание                                                                | Команда                   |
| ----------------------------------------------------------------------- | ------------------------- |
| Посмотреть железо                                                       | `llm-checker hw-detect`   |
| Обновить каталог моделей                                                | `llm-checker sync`        |
| Полный анализ твоего компьютера <br/> Подбор совместимых локальных LLM. | `llm-checker check`       |
| Список моделей (модели из Ollama-каталога)                              | `llm-checker list-models` |
| Получить рекомендации (модели multi-source registry)                    | `llm-checker recommend `  |
| Найти конкретные модели                                                 | `llm-checker search `     |
