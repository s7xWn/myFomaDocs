vi — это консольный текстовый редактор в Unix/Linux,
с помощью которого можно создавать и редактировать текстовые файлы прямо в терминале, без графического интерфейса.

Он особенно полезен для редактирования конфигурационных файлов, написания скриптов и работы с серверами через SSH.

Vim (Vi IMproved) — это мощный консольный текстовый редактор, расширенная версия классического vi.
Он позволяет редактировать текстовые файлы прямо в терминале Linux, Unix и других системах.

<Callout>

Иногда vi и vim выглядят одинаково, потому что на многих Linux-системах команда `vi` запускает Vim в режиме совместимости или вообще является ссылкой на него.

Проверить можно так:

```bash
vi --version
vim --version
```

Если `vi --version` выводит информацию о Vim, значит, у тебя под именем `vi` фактически установлен Vim или совместимая реализация. На некоторых системах команда `vi` не поддерживает параметр `--version`.

</Callout>

## Vi vs Vim

Главное отличие: Vim — это расширенная версия vi, в которой добавили множество функций для более эффективного редактирования текста и кода. При этом Vim сохраняет совместимость с основными командами vi.

| Возможность                    | vi (классический)                           | vim                                            |
| ------------------------------ | ------------------------------------------- | ---------------------------------------------- |
| Основное редактирование текста | Да                                          | Да                                             |
| Поиск и замена                 | Базовые возможности                         | Расширенные возможности и регулярные выражения |
| Подсветка синтаксиса           | Обычно нет                                  | Да                                             |
| Отмена действий (u)            | Ограниченная история в классических версиях | Многоуровнечная отмена и повтор                |
| Несколько буферов              | Обычно нет                                  | Да                                             |
| Работа с несколькими окнами    | Ограничена или отсутствует                  | Да                                             |
| Автодополнение                 | Минимальное или отсутствует                 | Да                                             |
| Макросы                        | Базовые возможности зависят от реализации   | Запись и воспроизведение команд                |
| Плагины                        | Практически отсутствуют                     | Есть система расширений                        |
| Настройка                      | Ограниченная                                | Гибкая через .vimrc                            |

<details>
  <summary>Пример</summary>

Допустим, ты редактируешь файл `main.c`.

В классическом vi ты можешь:

- открыть файл;
- перемещаться по тексту;
- удалять и вставлять строки;
- искать текст;
- сохранять изменения.

В Vim ты можешь делать всё перечисленное и дополнительно:

- автоматически подсвечивать ключевые слова языка C;
- искать и заменять выражения по всему файлу;
- открывать несколько файлов в буферах;
- разделять экран на несколько окон;
- отменять цепочки изменений;
- подключать плагины для работы с кодом.

</details>

## Популярные форки

Современных форков Vim несколько, но важно различать полноценные форки редактора и редакторы, которые лишь используют Vim-подобные клавиши.

### NeoVim

Если говорить именно о наследниках Vim, то главный современный проект — [NeoVim](./nvim/index.mdx).
Остальные решают более специализированные задачи: улучшение классического Vim,
интеграция с IDE или работа с современными графическими интерфейсами.

Самый известный современный форк Vim.
Развивает API, Lua-конфигурацию, асинхронные задачи и интеграцию с LSP.
Совместим с большинством Vim-плагинов.

### EVi

Новый форк, появившийся в 2026 году на базе Vim 9.1.
Ориентирован на сохранение традиционного Vim и развитие проекта без кода, созданного с помощью LLM.
Поддерживает многие возможности Vim 9.1, но сообщество и зрелость пока существенно меньше.

<hr />

### Vim Classic

Проект, ориентированный на долгосрочное сопровождение классического Vim и отказ от кода, созданного с помощью LLM.
В отличие от Neovim, цель — не радикальная модернизация архитектуры, а сохранение привычного редактора.
