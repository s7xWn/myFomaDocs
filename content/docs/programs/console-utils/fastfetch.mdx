Fastfetch — это лёгкая консольная программа для Linux, macOS и других Unix-подобных систем, которая показывает информацию о компьютере и операционной системе прямо в терминале.

Обычно Fastfetch выводит логотип дистрибутива и рядом технические сведения:

- OS — операционная система, например Arch Linux или Ubuntu.
- Host — модель компьютера.
- Kernel — версия ядра Linux.
- Uptime — сколько времени система работает без перезагрузки.
- Packages — количество установленных пакетов.
- Shell — используемая командная оболочка, например Bash или Zsh.
- Resolution — разрешение экрана.
- CPU / GPU — процессор и видеокарта.
- Memory — использование оперативной памяти.
- Terminal — название терминала.
