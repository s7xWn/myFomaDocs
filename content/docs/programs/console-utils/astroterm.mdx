astroterm — это текстовый планетарий для терминала Linux: он показывает звёзды, планеты, созвездия и фазы Луны прямо в консоли.

<hr />

## Установка

### Linux

```bash
wget -O astroterm \
  https://github.com/da-luce/astroterm/releases/latest/download/astroterm-linux-x86_64
```

<hr />

## Использование `astroterm`

```bash
astroterm
```

### `--city`

— координаты города наблюдения.

### `--color`

— включить цвета.

### `--constellations`

— показать линии созвездий.
