Yazi — это быстрый файловый менеджер для терминала, написанный на языке Rust. Он предназначен для навигации по папкам, управления файлами и работы с архивами без графического интерфейса.

Вместо привычного проводника Windows или файлового менеджера в Linux ты получаешь удобный интерфейс прямо в терминале — с колонками, предварительным просмотром файлов и управлением с клавиатуры.

- Быстрая навигация по каталогам с помощью клавиш.
- Предварительный просмотр изображений, текста, кода и других файлов — в зависимости от терминала и установленных инструментов.
- Операции с файлами: копирование, перемещение, удаление, переименование.
- Работа с архивами и интеграция с внешними утилитами.
- Поиск и фильтрация файлов.
- Расширение возможностей с помощью плагинов и настройка внешнего вида.
- Асинхронная работа: некоторые операции выполняются в фоне, чтобы интерфейс оставался отзывчивым.

## Установка

[Документация](https://yazi-rs.github.io/docs/installation/)
[Копия документации](./installation.mdx)

Добавить ключ репозитория:

```bash
curl -fsSL https://yazi-rs.github.io/builds/yazi-keyring.gpg | sudo tee /usr/share/keyrings/yazi-keyring.gpg >/dev/null
```

Добавь репозиторий Yazi:

```bash
echo 'deb [signed-by=/usr/share/keyrings/yazi-keyring.gpg] https://yazi-rs.github.io/builds/ stable main' | sudo tee /etc/apt/sources.list.d/yazi.list >/dev/null
```

Установить:

```bash
sudo apt update
sudo apt install -y yazi
```
