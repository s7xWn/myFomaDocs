Vorssaint — это бесплатное приложение с открытым исходным кодом для компьютеров Mac, которое объединяет множество небольших системных утилит в одной программе.

- Деинсталлятор
- Homebrew
- Очистка диска
- Dynamic Island

<hr />

## Установка (Homebrew)

```bash
brew install --cask vorssaint
```
