---
title: Client - server
---

Архитектура «клиент — сервер» — это архитектурный стиль, в котором система разделена на две основные роли:

- Client (клиент) — запрашивает данные или услуги.
- Server (сервер) — предоставляет данные или услуги и обрабатывает запросы.

```
┌──────────────┐             ┌──────────────┐
│    Client    │ ──request──>│    Server    │
│              │ <──response─│              │
└──────────────┘             └──────────────┘
```

Главная идея Client–Server — разделение ответственности.

Клиенту не обязательно знать, как сервер получает или обрабатывает данные.
