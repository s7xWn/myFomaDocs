UDP (User Datagram Protocol) — это один из сетевых протоколов, который позволяет устройствам быстро передавать данные друг другу через интернет или локальную сеть.

Низкая задержка. Небольшой заголовок — всего 8 байт. Нет обязательного установления соединения. Не требуется встроенное подтверждение доставки каждого пакета.

<hr />

## Заголовок UDP

Заголовок UDP имеет фиксированный размер — 8 байт.

```

Порт        | Порт          | Длина заголовка   | Контрольная сумма |
отправителя | получателя    |                   |                   |
--------------------------------------------------------------------|
55315       | 80            | от 8 до 65515     |                   |
--------------------------------------------------------------------|
В битах: 16 | 16            | 16                | 16                |

```

<hr />

## Как работает UDP

1. Приходит сообщение с прикладного уровня.
2. Разделение данных на сегменты и каждому такому сегменту добавляется `заголовок UDP `
3. Передача получателю (IP передаёт пакет по сети. Маршрутизаторы направляют его к получателю)
4. Проверка и сборка (UDP получателя. Проверяет датаграмму и передаёт данные приложению через нужный порт)

<hr />

## Где используется UDP

- **Онлайн-игры** — передача координат игроков, движений и игровых событий с минимальной задержкой.
- **IP-телефония (VoIP)** — передача голоса во время интернет-звонков.
- **Видеоконференции и стриминг** — передача аудио и видео в реальном времени.
- **DNS (Domain Name System)** — преобразование доменных имён, например google.com, в IP-адреса.
- **DHCP (Dynamic Host Configuration Protocol)** — автоматическая выдача IP-адресов устройствам в сети.
- **NTP (Network Time Protocol)** — синхронизация времени на компьютерах и серверах.
- **Сетевое обнаружение устройств** — например, с помощью mDNS и некоторых механизмов обнаружения устройств в локальной сети.
- **VPN и туннелирование** — некоторые VPN-протоколы, например WireGuard, используют UDP для передачи данных.
