## Скриншот / screenshot

| Действие                      | Сочетание                              |
| ----------------------------- | -------------------------------------- |
| Весь экран                    | `Cmd + Shift + 3`                      |
| Весь экран в буфер обмена     | `Ctrl + Cmd + Shift + 3`               |
| Выбранная область             | `Cmd + Shift + 4`                      |
| Область в буфер обмена        | `Ctrl + Cmd + Shift + 4`               |
| Отдельное окно                | `Cmd + Shift + 4`, затем `Space`       |
| Отдельное окно в буфер обмена | `Ctrl + Cmd + Shift + 4` затем `Space` |
| Панель снимков и записи       | `Cmd + Shift + 5`                      |
