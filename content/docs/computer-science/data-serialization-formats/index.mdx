## Сериализация

Сериализация — превращение объекта или структуры данных в формат, который можно сохранить или передать.

<details>
  <summary>Пример</summary>

Представим, что в программе на JavaScript есть объект:

```js
const user = {
  name: "Alex",
  age: 25,
  isAdmin: true,
};
```

Чтобы передать его по сети или сохранить в файл, мы можем преобразовать его в JSON-строку:

```js
const json = JSON.stringify(user);
```

Результат:

```json
{
  "name": "Alex",
  "age": 25,
  "isAdmin": true
}
```

Мы преобразовали объект JavaScript в текстовый формат JSON.

</details>

<hr />

## Десериализация

Десериализация — обратное превращение этого формата в объект или структуру данных, с которыми программа может работать.

<details>
  <summary>Пример</summary>

Представим, что получили JSON:

```json
{
  "name": "Alex",
  "age": 25,
  "isAdmin": true
}
```

Чтобы снова работать с ней как с объектом JavaScript, нужно выполнить обратное преобразование:

```js
const user = JSON.parse(json);
```

Теперь `user` снова является обычным объектом JavaScript:

```js
console.log(user.name); // Alex
console.log(user.age); // 25
```

Это и есть десериализация.

</details>
