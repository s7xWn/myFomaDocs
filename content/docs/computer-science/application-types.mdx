---
title: Application Types
---

«Тип приложения» — это категория, которая описывает, для какой платформы или среды предназначено приложение.

| Тип                   | Где работает                        | Примеры                                    |
| --------------------- | ----------------------------------- | ------------------------------------------ |
| 🖥️ **Десктопные**     | Windows, macOS, Linux               | Slack, Photoshop, VS Code                  |
| 📱 **Мобильные**      | iOS, Android                        | Telegram, Instagram, банковские приложения |
| 🌐 **Веб-приложения** | В браузере, без отдельной установки | Gmail, Notion, Google Docs                 |

Промежуточные варианты:

- **Кроссплатформенные** — одно приложение для нескольких ОС, например desktop Windows + macOS + Linux.
- **PWA** — веб-приложение, которое можно установить на устройство и использовать почти как нативное.
- **Гибридные приложения** — например, мобильное приложение с web-технологиями внутри.
- **Нативные приложения** — отдельно разработанные под конкретную платформу: Swift для iOS/macOS, Kotlin для Android и т. д.
