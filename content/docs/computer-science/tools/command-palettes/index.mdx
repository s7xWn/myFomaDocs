---
title: Панели команд
---

keyboard launcher / command palette — маленькое окно, которое вызывается горячей клавишей, после чего ты начинаешь печатать и запускаешь приложения, команды, файлы и другие действия.\*\*

> Представь что-то вроде Spotlight на macOS, но с разной философией.

|                   | **Rofi**                             | **Raycast**                          | **Vicinae**                                |
| ----------------- | ------------------------------------ | ------------------------------------ | ------------------------------------------ |
| Основная идея     | Минималистичный launcher             | Универсальный productivity-tool      | Open-source аналог Raycast                 |
| Платформы         | Linux/BSD                            | macOS, Windows (частично/в развитии) | Linux, macOS, Windows                      |
| Open source       | ✅                                   | ❌                                   | ✅                                         |
| Запуск приложений | ✅                                   | ✅                                   | ✅                                         |
| Поиск файлов      | ✅                                   | ✅                                   | ✅                                         |
| Clipboard history | Через дополнительные решения/скрипты | ✅                                   | ✅                                         |
| Калькулятор       | Через конфигурацию/скрипты           | ✅                                   | ✅                                         |
| Расширения        | Скрипты/plugins                      | Большая экосистема                   | React/TypeScript + совместимость с Raycast |
| Настройка         | Очень глубокая                       | Удобная из коробки                   | Удобная + глубокая                         |
| Философия         | **Unix/Linux tool**                  | **Экосистема для продуктивности**    | **Raycast-подобный open source launcher**  |
