Marp — это инструмент для создания презентаций из обычного Markdown-текста.

Чем Marp удобен

- Слайды пишутся как Markdown — легко редактировать в VS Code.
- Можно использовать готовые темы и CSS для оформления.
- Хорошо подходит для технических презентаций, лекций и документации.
- Презентацию удобно хранить в Git и отслеживать изменения.
- Можно автоматизировать генерацию презентаций из Markdown.
