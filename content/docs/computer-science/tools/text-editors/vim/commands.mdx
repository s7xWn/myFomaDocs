## Структура команд

```
[число] [оператор] [объект/движение]
```

<hr />

## Смена режима

### Normal (`ESC`)

- `ESC`

### Insert (`i`,`a`,`o`,`O`)

#### У символа (`i`,`a`)

- `i` -> курсор слева от выбранного символа
- `a` -> курсор справа от выбранного символа

#### Новая строка (`o`,`O`)

- `o` -> курсор снизу на новой строке
- `O` -> курсор сверху на новой строке

<hr />

## Перемещение (`Normal mode`)

### Вертикальное

#### Посимвольно (`j`, `k`)

- Вниз -> `j`
- Вверх -> `k`

#### По файлу (`gg`, `G`)

- В начало -> `gg`
- В конец -> `G`

#### На строку (`<число><j/k>`,`<число>G`)

- Относительно текущего положения -> `<число><j/k>`
- На конкретную строку -> `<число>G`

<hr />

### Горизонтальное

#### Посимвольно (`h`, `l`)

- Влево -> `h`
- Вправо -> `l`

#### Построчно (`0`, `$`)

- В начало строки -> `0`
- В конец строки -> `$`

#### По словам (`w`, `b`)

- Вправо -> `w`
  - в конец слова -> `e`
- Влево -> `b`

<hr />

## Выделение (`Visual/line mode`)

Так же можно использовать команды для перемещения.

### Копирование (`y`)

- Коипрование -> `y`

<Callout type="warn">
  Если **вставить** поверх выделенного текста, то **заменяемый текст** попадёт в
  **буфер обмена**!
</Callout>

### Вставка (`p`,`P`)

- Вставить под -> `p`
- Вставить над -> `P`

### Шаги (`u`,`Ctrl + r`)

- Отмена -> `u`
- Вернуть -> `Ctrl R`

### Удаление (`d`)

- Удалить -> `d`

<Callout type="warn">
  Это работает как **Вырезать** <br />
  То что будет **удалено**, попадет в **буфер обмена**.
</Callout>
