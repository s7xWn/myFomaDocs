## Перемещение (`Normal mode`)

### Вертикальное

#### Посимвольно (`j`, `k`)

- Вниз -> `j`
- Вверх -> `k`

#### По файлу (`gg`, `G`)

- В начало -> `gg`
- В конец -> `G`

#### На строку (`<число><j/k>`,`<число>G`)

- Относительно текущего положения -> `<число><j/k>`
- На конкретную строку -> `<число>G`

<hr />

### Горизонтальное

#### Посимвольно (`h`, `l`)

- Влево -> `h`
- Вправо -> `l`

#### Построчно (`0`, `$`)

- В начало строки -> `0`
- В конец строки -> `$`

#### По словам (`w`, `b`)

- Вправо -> `w`
  - в конец слова -> `e`
- Влево -> `b`
