## Установка Sunshine

### Windows

Заходим на [Sunshine [GitHub]](https://github.com/LizardByte/Sunshine) и скачиваем `Sunshine-Windows-AMD64-installer.msi`.

При установке не менять всё подряд — если установщик предлагает компоненты вроде виртуального геймпада, их можно оставить включёнными, если планируешь играть с контроллера. Sunshine после установки обычно работает как служба Windows.

После установки запусти Sunshine.

Должна открыться веб-панель примерно по адресу:

```
https://localhost:47990
```

Создай там логин и пароль Sunshine.

Например пользователь `sunshine` с паролем `root`.
