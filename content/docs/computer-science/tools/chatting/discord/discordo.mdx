Discordo — это неофициальный консольный (терминальный) клиент для Discord. То есть вместо обычного графического приложения Discord ты работаешь с Discord прямо из терминала.

<Callout type="success">
  Особенно удобен на Linux/SSH и слабых системах.
</Callout>

Основные возможности:

- читать и отправлять сообщения;
- работать с серверами, каналами и личными сообщениями;
- получать уведомления;
- управлять Discord с клавиатуры;
