---
title: Cache
---

Cache (кэш, кеш, временное хранилище данных) — это место, где временно сохраняются часто используемые данные, чтобы в следующий раз получить к ним доступ быстрее, чем заново загружать или вычислять их.

## В браузере

Когда вы открываете сайт, браузер сохраняет:

- изображения;
- стили страницы (CSS);
- скрипты;
- некоторые данные страниц.

При следующем посещении сайт открывается быстрее, потому что часть файлов уже есть на вашем устройстве.

<hr />

## В операционной системе

Компьютер хранит часто используемые данные в быстрой памяти, чтобы программы работали быстрее.

Например:

- процессор имеет свой кэш (L1, L2, L3);
- система кэширует файлы с диска в оперативной памяти.

<hr />

## В приложениях и серверах

Сервер может сохранять результаты сложных операций:

Без кэша:

```
Пользователь → запрос → база данных → вычисление → ответ
```

С кэшем:

```
Пользователь → запрос → кэш → быстрый ответ
```

<hr />

## Минусы кэша

У кэша есть недостатки:

- **Данные могут устареть** <br/>
  Например, сайт обновил цену товара, а у вас ещё показывается старая версия из кэша.
- **Занимает место** <br/>
  Большой кэш может занимать гигабайты.
- **Иногда мешает обновлениям** <br/>
  Поэтому помогает очистка кэша, когда приложение показывает старые данные.
