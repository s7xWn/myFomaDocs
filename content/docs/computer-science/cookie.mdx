title: Cookie
---

— это **строки данных**, которые хранятся в **браузере**. Они являются частью HTTP-протокола, определённого в спецификации [RFC 6265]().

Устанавливаются **веб-сервером** при помощи **заголовка ответа** `Set-Cookie`. Затем **браузер будет автоматически добавлять их в каждый запрос** _(если удовлетворяет условиям, заданным атрибутами этой cookie)_ на тот же домен при помощи заголовка `Cookie` .

## Как работает

1. Пользователь впервые открывает сайт.
2. Сервер отвечает и отправляет заголовок:

```http
HTTP/1.1 200 OK
Set-Cookie: session_id=abc123; Path=/; HttpOnly; Secure
```

3. Браузер сохраняет cookie.
4. При следующем запросе к этому же сайту браузер автоматически добавляет:

```http
GET /profile HTTP/1.1
Host: example.com
Cookie: session_id=abc123
```

## Атрибуты cookie (флаги)

Определяют, как и когда браузер будет использовать cookie.

```http
Set-Cookie: session_id=abc123;
            HttpOnly;
            Secure;
            Path=/;
            Domain=example.com;
            Max-Age=3600;
            SameSite=Lax
```

| Атрибут              | Назначение                                                                                                                                                                                                                                                                                             |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `Domain=example.com` | Определяет домен, которому принадлежит cookie. Если указан `example.com`, cookie также будет доступна поддоменам (`api.example.com`, `shop.example.com`). Без `Domain` cookie действует только для текущего хоста.                                                                                     |
| `Expires=<date>`     | Указывает точную дату и время истечения срока действия cookie. После этого браузер удаляет cookie. Если указаны и `Expires`, и `Max-Age`, то **приоритет имеет `Max-Age`**. Если не указать ни `Expires`, ни `Max-Age`, то создается [сессионная cookie (Session Cookie)](#сессионные).                |
| `HttpOnly`           | Запрещает доступ к cookie из JavaScript (`document.cookie`). Cookie отправляется только по HTTP(S)-запросам. Защищает от кражи cookie через XSS.                                                                                                                                                       |
| `Max-Age=<секунды>`  | Задает срок жизни cookie в секундах с момента получения. Например, `Max-Age=3600` — cookie будет храниться 1 час. Если указаны и `Expires`, и `Max-Age`, то **приоритет имеет `Max-Age`**. Если не указать ни `Expires`, ни `Max-Age`, то создается [сессионная cookie (Session Cookie)](#сессионные). |
| `Path=/`             | Определяет путь, для которого действует cookie. `Path=/` означает, что cookie будет отправляться для всех страниц сайта. Например, `Path=/admin` — только для URL, начинающихся с `/admin`.                                                                                                            |
| `SameSite`           | Определяет, когда cookie можно отправлять при межсайтовых запросах. Возможные значения: `Strict`, `Lax`, `None`. Помогает защититься от CSRF-атак.                                                                                                                                                     |
| `Secure`             | Cookie передается **только по HTTPS**. По обычному HTTP не отправляется.                                                                                                                                                                                                                               |

## Виды

### Сессионные

— существуют только до закрытия браузера.

### Постоянные

— хранятся определённое время (дни, месяцы и т. д.).

### Основные (first-party)

— создаются посещаемым сайтом.

### Сторонние (third-party)

— создаются другими сервисами, например рекламными или аналитическими.
