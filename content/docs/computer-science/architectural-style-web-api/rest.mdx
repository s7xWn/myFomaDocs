title: REST
---

REST (Representational State Transfer) — это архитектурный стиль для создания веб-API. Он описывает принципы, по которым клиент (например, мобильное приложение или браузер) взаимодействует с сервером через HTTP.

> Проще говоря: REST — это набор правил, которые делают API понятными, предсказуемыми и удобными для использования.

<hr />

## Основные принципы REST

### Ресурсы

Все представляется в виде ресурсов:

- пользователь
- товар
- заказ

Каждый ресурс имеет свой URL:

```
/users
/users/42
/orders/100
```

<hr />

### HTTP-методы

Для разных действий используются стандартные методы HTTP:

| Метод  | Действие           | Пример             |
| ------ | ------------------ | ------------------ |
| GET    | Получить данные    | `GET /users/42`    |
| POST   | Создать            | `POST /users`      |
| PUT    | Полностью обновить | `PUT /users/42`    |
| PATCH  | Частично обновить  | `PATCH /users/42`  |
| DELETE | Удалить            | `DELETE /users/42` |

<hr />

### Без состояния (Stateless)

Каждый запрос должен содержать всю необходимую информацию.

<hr />

### Единообразный интерфейс

Если во всех API придерживаться одинаковых правил, разработчикам проще работать с ними.

<hr />

## Форматы передаваемых данных

REST API может передавать данные в разных форматах, если клиент и сервер это поддерживают.

Наиболее распространенные форматы:

- JSON — самый популярный сегодня.
- XML — часто встречается в старых корпоративных системах.
- HTML — если API возвращает готовую веб-страницу.
- CSV — для экспорта таблиц.
- Текст (text/plain) — для простых текстовых ответов.
- Изображения, PDF, видео — REST API может возвращать и бинарные данные.
