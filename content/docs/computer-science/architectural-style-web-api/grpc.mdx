---
title: "gRPC"
---

gRPC (Google Remote Procedure Call) — это технология для взаимодействия между сервисами по сети.
Она позволяет одному приложению вызывать функции другого приложения так, будто они находятся в одном проекте и вызываются обычным методом.

gRPC позволяет микросервисам быстро и эффективно общаться друг с другом.
