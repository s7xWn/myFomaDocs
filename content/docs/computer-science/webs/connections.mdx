## Подключение к сети

Это способ, которым устройство соединяется с другими устройствами или с роутером.

| Способ              | Описание                                   | Пример                                            |
| ------------------- | ------------------------------------------ | ------------------------------------------------- |
| Ethernet            | Проводное подключение по сетевому кабелю   | ПК подключён к роутеру кабелем                    |
| Wi-Fi               | Беспроводное подключение по радиосигналу   | Ноутбук подключён к роутеру без кабеля            |
| Bluetooth           | Беспроводная связь на небольшом расстоянии | Наушники подключены к ПК                          |
| USB                 | Подключение устройств через USB-кабель     | Смартфон подключён к ПК для передачи данных       |
| Powerline (PLC)     | Передача данных по электрической проводке  | Сетевое оборудование соединено оптическим кабелем |
| Оптоволокно         | Передача данных по оптическому кабелю      |                                                   |
| Коаксиальный кабель | Передача данных по коаксиальному кабелю    |                                                   |

<hr />

## Подключение к интернету

<Callout type="warn">
  FTTH, GPON и Active Ethernet не являются тремя равнозначными способами. FTTH
  описывает, куда проложено оптоволокно, GPON — технологию оптической сети, а
  Active Ethernet — другой способ организации Ethernet-соединения по
  оптоволокну.
</Callout>

| Способ               | Как работает                                                      | Пример                                                       |
| -------------------- | ----------------------------------------------------------------- | ------------------------------------------------------------ |
| FTTH / Fiber         | Оптоволокно проложено до дома                                     | Оптический кабель приходит в квартиру                        |
| GPON                 | Данные передаются по общей пассивной оптической сети              | Несколько квартир используют сеть с оптическим разветвителем |
| Active Ethernet      | Провайдер предоставляет подключение через Ethernet по оптоволокну | Оптическая линия идёт к порту оборудования провайдера        |
| DSL / ADSL           | Интернет поступает по телефонной медной линии                     | Старое подключение через телефонную розетку                  |
| Cable Internet       | Интернет поступает по коаксиальному кабелю                        | Кабельная сеть провайдера                                    |
| 4G / 5G              | Интернет поступает через мобильную сеть                           | SIM-карта в телефоне или роутере                             |
| Спутниковый интернет | Данные передаются через спутниковую систему                       | Спутниковая антенна на доме                                  |
