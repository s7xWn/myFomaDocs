---
title: "Модель OSI"
---

Модель OSI (Open Systems Interconnection) — это сетевая модель, которая объясняет, как устройства обмениваются данными по сети. Она делит процесс передачи информации на 7 уровней, каждый из которых отвечает за свою задачу.

| №   | Уровень       | Ключевое слово                                                           |
| --- | ------------- | ------------------------------------------------------------------------ |
| 7   | Прикладной    | HTTP, HTTPS, DNS — взаимодействие сетевых приложений с сетью.            |
| 6   | Представления | Форматирование данных, кодирование, шифрование, сжатие.                  |
| 5   | Сеансовый     | Управление сеансами взаимодействия между приложениями.                   |
| 4   | Транспортный  | TCP, UDP — доставка данных между приложениями, порты, контроль доставки. |
| 3   | Сетевой       | IP, маршрутизаторы — выбор маршрута между сетями.                        |
| 2   | Канальный     | Ethernet, Wi-Fi (канальный уровень), MAC-адреса, кадры.                  |
| 1   | Физический    | Кабели, радиосигналы, электрические и оптические сигналы, биты.          |

- L1 — физический: передаёт биты.
- L2 — канальный: передаёт кадры внутри канала или локальной сети.
- L3 — сетевой: передаёт пакеты между сетями.
- L4 — транспортный: обеспечивает взаимодействие приложений через порты.

<hr />

## Как это работает на практике?

Допустим, ты отправляешь сообщение через интернет.

1. Уровни 7–5: приложение формирует данные и организует взаимодействие.
2. Уровень 4: TCP или UDP обеспечивает передачу данных между приложениями.
3. Уровень 3: IP определяет адрес назначения и помогает доставить пакет через сети.
4. Уровень 2: данные оформляются в кадр для передачи по локальному каналу.
5. Уровень 1: биты передаются по кабелю или по радиоканалу Wi-Fi.

На устройстве получателя процесс происходит в обратном направлении.
