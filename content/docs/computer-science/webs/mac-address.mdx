---
title: "MAC-адрес"
---

MAC-адрес (Media Access Control address) — это уникальный аппаратный идентификатор сетевого интерфейса устройства. Проще говоря, это своего рода «номер» Wi-Fi- или Ethernet-адаптера, который помогает распознавать устройства в локальной сети.

```
A4:5E:60:C2:19:8F
```

Обычно он состоит из 6 пар шестнадцатеричных символов, разделённых двоеточиями или дефисами.

<Callout type="warn">
  Обрати внимание: современные телефоны часто используют случайный MAC-адрес для
  Wi-Fi, чтобы усложнить отслеживание устройства. Поэтому адрес, который
  показывает телефон для конкретной сети, может отличаться от аппаратного
  адреса.
</Callout>

<hr />

## Для чего нужен MAC-адрес

- **Подключение к Wi-Fi.** Роутер может использовать MAC-адрес для идентификации устройства.
- **Контроль доступа.** Можно настроить роутер так, чтобы к сети подключались только устройства с определёнными MAC-адресами.
- **Передача данных в локальной сети.** MAC-адреса помогают доставлять кадры нужному сетевому интерфейсу.
