OSPF (Open Shortest Path First) — это протокол динамической маршрутизации, который работает на сетевом уровне (3 уровень OSI).

Он используется для обмена информацией о состоянии каналов связи и построения оптимальных маршрутов внутри автономной системы (AS).

<details>
  <summary>Простыми словами</summary>

Представь, что у тебя есть большая корпоративная сеть с несколькими маршрутизаторами:

- Router 1.
- Router 2.
- Router 3.
- Router 4.

OSPF позволяет этим маршрутизаторам обмениваться информацией о топологии сети, узнавать, какие маршрутизаторы и сети доступны, и самостоятельно рассчитывать наиболее короткий путь до назначения.

Если один из каналов связи перестанет работать, OSPF сможет пересчитать маршруты и выбрать альтернативный путь.

</details>

## Основные характеристики OSPF

| Характеристика     | Значение                                                                 |
| ------------------ | ------------------------------------------------------------------------ |
| Назначение         | Обмен информацией о маршрутах и построение оптимальных путей внутри сети |
| Тип                | Протокол динамической маршрутизации                                      |
| Уровень OSI        | 3 (по назначению)                                                        |
| Транспорт          | IP (не использует TCP или UDP)                                           |
| Номер протокола IP | 89                                                                       |
| Алгоритм           | SPF (Shortest Path First), алгоритм Дейкстры                             |
| Тип маршрутизации  | Внутридоменная (IGP)                                                     |
| Метрика            | Cost (стоимость маршрута)                                                |
| Версии             | OSPFv2 (IPv4), OSPFv3 (изначально IPv6, также поддерживает IPv4)         |

## Как работает OSPF?

1. **Обнаружение соседей** — маршрутизаторы отправляют Hello-пакеты и находят друг друга.
2. **Установление соседства** — маршрутизаторы согласовывают параметры взаимодействия.
3. **Обмен информацией** — маршрутизаторы обмениваются LSA (Link-State Advertisements), содержащими информацию о состоянии каналов и топологии.
4. **Построение карты сети** — каждый маршрутизатор формирует собственную базу данных состояния каналов (LSDB).
5. **Расчёт маршрутов** — алгоритм SPF (Дейкстры) рассчитывает кратчайшие пути до известных сетей.
6. **Добавление маршрутов** — лучшие маршруты попадают в таблицу маршрутизации.

## Особенности OSPF

- **Areas (области)** — большую сеть можно разделить на области для уменьшения объёма служебной информации и вычислительной нагрузки. Backbone Area имеет идентификатор `0.0.0.0`.
- **Cost** — метрика, которая определяет предпочтительность маршрута. Обычно рассчитывается на основе пропускной способности интерфейса. Чем меньше Cost, тем предпочтительнее маршрут.
- **DR/BDR** — в широковещательных сетях (например, Ethernet) выбираются Designated Router и Backup Designated Router для оптимизации обмена информацией.
- **Hello-пакеты** — используются для обнаружения и поддержания соседства между маршрутизаторами.
- **Multicast** — OSPFv2 использует адреса `224.0.0.5` (AllSPFRouters) и `224.0.0.6` (AllDRouters) в IPv4-сетях.

## Как OSPF связан с другими протоколами?

- **IP (IPv4/IPv6)** — обеспечивает адресацию и доставку OSPF-пакетов.
- **OSPF** — обменивается информацией о топологии сети и рассчитывает маршруты.
- **BGP** — может обмениваться маршрутами с OSPF через перераспределение маршрутов (redistribution), например, между внутренней сетью компании и внешними сетями.

<Callout title='' type='success'>

OSPF не передаёт пользовательские данные и не заменяет IP. Он помогает маршрутизаторам построить карту сети и самостоятельно рассчитать оптимальные маршруты для IP-трафика.

В отличие от BGP, который обычно используется для маршрутизации между автономными системами, OSPF применяется внутри автономной системы.

</Callout>
