BGP (Border Gateway Protocol) — это протокол динамической маршрутизации, который работает на сетевом уровне (3 уровень OSI) в контексте его назначения.

Он используется для обмена информацией о маршрутах между автономными системами (AS) в интернете.

<details>
  <summary>Простыми словами</summary>

Представь, что интернет состоит из множества крупных сетей:

- Сеть Google.
- Сеть Amazon.
- Сеть провайдера.
- Сеть дата-центра.

BGP помогает этим сетям договариваться, через какие маршруты передавать трафик друг к другу.

</details>

## Основные характеристики BGP

| Характеристика    | Значение                                     |
| ----------------- | -------------------------------------------- |
| Назначение        | Обмен маршрутами между автономными системами |
| Тип               | Протокол динамической маршрутизации          |
| Уровень OSI       | 3 (по назначению)                            |
| Транспорт         | TCP                                          |
| Порт              | 179                                          |
| Версия            | BGP-4 — широко используемая версия           |
| Тип маршрутизации | Междоменная (между AS)                       |

### Как BGP связан с другими протоколами?

- IP (IPv4/IPv6) — обеспечивает адресацию и доставку пакетов.
- TCP — обеспечивает надёжное соединение для обмена BGP-сообщениями.
- BGP — сообщает маршрутизаторам, какие сети доступны и через какие автономные системы к ним можно попасть.

<Callout title='' type='success'>

BGP сам не передаёт пользовательские данные и не заменяет IP. Он помогает маршрутизаторам выбирать пути для IP-трафика.

</Callout>
