В JavaScript есть два основных подхода к модулям:

- ES Modules (ESM) → import / export
- CommonJS (CJS) → require / module.exports

| ESM                           | CommonJS                                                   |
| ----------------------------- | ---------------------------------------------------------- |
| `import`                      | `require()`                                                |
| `export`                      | `module.exports`                                           |
| Современный стандарт JS       | Старый Node.js-подход                                      |
| Статическая система модулей   | Более динамическая                                         |
| `.mjs` или `"type": "module"` | `.cjs` или CommonJS по умолчанию в некоторых конфигурациях |

## Зачем нам модули

- Повторное использование
  - один и тот же код можно написать один раз и использовать в разных местах проекта. Например, функцию `formatDate()` вынести в отдельный модуль.
- Возможность компоновки
  - можно собирать приложение из небольших независимых модулей, каждый из которых отвечает за свою задачу.
- Удобства разработки (в том числе совместной)
  - код разбит на части, поэтому его проще читать, изменять, тестировать и разрабатывать вместе с другими людьми.
- Изоляция
  - переменные и функции внутри модуля не попадают случайно в глобальную область видимости.
- Организация проекта
  - модули помогают структурировать код по смыслу
