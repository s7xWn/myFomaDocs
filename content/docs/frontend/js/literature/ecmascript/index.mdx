ECMAScript (или ES) — это спецификация. То есть набор правил и рекомендаций, которые должны соблюдаться языком, чтобы он считался совместимым с этой спецификацией.

JavaScript (или JS) — это язык, который соответствует спецификации ECMAScript.

Разница между ними в том, что документация ES говорит, как создать язык, который будет соответствовать «семейству» подобных ECMAScript-языков. А документация JavaScript — как использовать конкретно этот язык (JavaScript).

<details>
 <summary>А в чём смысл?</summary>
 
Дело в том, JavaScript — не единственный язык, который следует этой спецификации. Есть ещё ActionScript, TypeScript, когда-то был CoffeeScript.

Чтобы не описывать каждый язык в деталях отдельно, есть спецификация. Она описывает то, что у этих языков одинаково.

Так как JavaScript следует спецификации ES, новые фичи описываются именно в ней. Это нам нужно, чтобы понимать, как следить за развитием языка и обновлениями.

</details>

## Обновления и версии

| Версия            | Год  | Основные нововведения                                                                                                                                                                                                                                                   |     |                                                                             |
| ----------------- | ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- | --------------------------------------------------------------------------- |
| **ES1**           | 1997 | Первая официальная спецификация JavaScript.                                                                                                                                                                                                                             |     |                                                                             |
| **ES2**           | 1998 | Небольшие редакционные изменения для соответствия международному стандарту ISO.                                                                                                                                                                                         |     |                                                                             |
| **ES3**           | 1999 | `try/catch`, регулярные выражения, `do...while`, улучшенная работа со строками и массивами. Эта версия долгое время была основной.                                                                                                                                      |     |                                                                             |
| **ES4**           | —    | Планировалась, но была отменена из-за сложности и разногласий среди разработчиков.                                                                                                                                                                                      |     |                                                                             |
| **ES5**           | 2009 | Очень важное обновление: `strict mode`, `JSON.parse()`, `JSON.stringify()`, `Object.create()`, `Object.defineProperty()`, методы массивов (`forEach`, `map`, `filter`, `reduce`, `every`, `some`, `indexOf`).                                                           |     |                                                                             |
| **ES5.1**         | 2011 | Небольшие исправления и уточнения стандарта.                                                                                                                                                                                                                            |     |                                                                             |
| **ES6 (ES2015)**  | 2015 | Самое крупное обновление: `let`, `const`, стрелочные функции (`=>`), шаблонные строки, классы, модули (`import/export`), промисы, `Map`, `Set`, `Symbol`, итераторы, генераторы, деструктуризация, параметры по умолчанию, оператор расширения (`...`), rest-параметры. |     |                                                                             |
| **ES2016 (ES7)**  | 2016 | Оператор возведения в степень `**`, метод `Array.prototype.includes()`.                                                                                                                                                                                                 |     |                                                                             |
| **ES2017 (ES8)**  | 2017 | `async/await`, `Object.values()`, `Object.entries()`, `String.padStart()`, `String.padEnd()`.                                                                                                                                                                           |     |                                                                             |
| **ES2018 (ES9)**  | 2018 | Асинхронные итераторы (`for await...of`), `Promise.finally()`, rest/spread для объектов, улучшения регулярных выражений.                                                                                                                                                |     |                                                                             |
| **ES2019 (ES10)** | 2019 | `Array.flat()`, `Array.flatMap()`, `Object.fromEntries()`, `String.trimStart()`, `String.trimEnd()`, необязательный параметр в `catch`.                                                                                                                                 |     |                                                                             |
| **ES2020 (ES11)** | 2020 | `BigInt`, оператор опциональной последовательности (`?.`), оператор объединения с null (`??`), `Promise.allSettled()`, динамический импорт (`import()`).                                                                                                                |     |                                                                             |
| **ES2021 (ES12)** | 2021 | `String.replaceAll()`, логические операторы присваивания (`&&=`, `                                                                                                                                                                                                      |     | =`, `??=`), `Promise.any()`, `WeakRef`, числовые разделители (`1_000_000`). |
| **ES2022 (ES13)** | 2022 | Приватные поля и методы классов (`#field`), `Array.at()`, `Object.hasOwn()`, статические блоки классов, `Error.cause`, top-level `await`.                                                                                                                               |     |                                                                             |
| **ES2023 (ES14)** | 2023 | Методы массива без изменения исходного: `toSorted()`, `toReversed()`, `toSpliced()`, `with()`, поиск с конца `findLast()` и `findLastIndex()`.                                                                                                                          |     |                                                                             |
| **ES2024 (ES15)** | 2024 | `Object.groupBy()`, `Map.groupBy()`, `Promise.withResolvers()`, новые возможности для `Set` (`union`, `intersection`, `difference`, `isSubsetOf` и др.).                                                                                                                |     |                                                                             |
| **ES2025 (ES16)** | 2025 | Продолжение ежегодных обновлений. Включает стандартизированные улучшения языка, принятые комитетом TC39, в том числе новые возможности регулярных выражений и дополнительные усовершенствования API языка.                                                              |     |                                                                             |
