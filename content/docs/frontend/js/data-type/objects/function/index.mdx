Объекты, которые могут быть вызваны.
Функции являются первоклассными объектами, что означает, что их можно передавать как аргументы, возвращать из других функций и присваивать переменным.

:::tip
Обычно имя функции пишут стилем [camelCase]() и используют в начале глагол. Например `createBearCounter`, `getBearCalculator`, `sendBearPolice`.
:::

Переменные внутри функции существуют только внутри этой функции — этот эффект называется областью видимости.

## Параметры

### Необязательные параметры и значения по умолчанию

Функция может принимать множество параметров, но при этом часть или все параметры могут быть необязательными. <br/>
Если для параметров не передается значение, то по умолчанию они имеют значение `undefined`.

:::warning
До ES6 (ES2015) у параметров функции не было значений по умолчанию.
:::

### Variadic function (Функции с произвольным количеством параметров)

— это функция, которая может принимать произвольное количество аргументов.

#### `arguments`

До появления rest-параметров использовали объект `arguments`.

```js
function sum() {
  let result = 0;
  for (const n of arguments) result += n;
  console.log(result);
}
sum(6); // 6
sum(6, 4); // 10
sum(6, 4, 5); // 15
```

#### rest-оператор

```js
function sum(...numbers) {
  let result = 0;
  for (const n of numbers) result += n;
  console.log(result);
}
sum(6, 4, 5); // 15
```

## Arrow function

:::warning
Появился в версии EcmaScript 2015 года (ES6)
:::

— это сокращённый синтаксис для объявления функций. Они записываются с помощью оператора `=>`

:::danger
Стрелочные функции — это [функциональные выражения (Function Expression)](#function-expression), а не объявления функций (Function Declaration).
:::

```js
const sum = (a, b) => {
  return a + b;
};
```

Если функция состоит из одного выражения, return и фигурные скобки можно опустить:

```js
const sum = (a, b) => a + b;
```

## Declaration vs Expression

Они работают одинаково, но по-разному ведут себя в консоли и стеке вызовов. Допустим, мы написали программу, в которой есть ошибка.<br/>
Если наши функции были именованными, то стек вызовов покажет, какая функция вызвала какую, и что привело к ошибке.<br/>
Что привело к ошибке, вплоть до номера строки и символа. С анонимными сложнее, поскольку вместо имён функций будут лишь номера строк.

## Function Declaration

Классическое представление функций.<br/>
**Объявление функции** — это способ определения функции с использованием ключевого слова function, за которым следует имя функции.

```js
fucntion fn(){
  console.log('hello');
}
fn();
```

### Всплытие (Hoisting)

Объявления функций “всплывают” в начало своей области видимости. Это означает, что использовать функцию можно до её объявления.

```js
fn();
fucntion fn(){
  console.log('hello');
}
```

### Именованные функции

Объявления функций всегда именованные, что позволяет ссылаться на функцию по имени внутри ее тела (например, для рекурсии).

<hr />

## Function Expression

**Функциональное выражение** — это способ определения функции в виде выражения. Функция может быть анонимной (без имени) или именованной.

```js
const greet = fucntion() {
  console.log('hello');
}

// Анонимная
const greet = () => {
  console.log('hello');
}

greet();
```

### Всплытие (Hoisting)

Функциональные выражения не всплывают. Их нельзя вызвать до присвоения переменной.

```js
greet(); // ОШИБКА!
const greet = () => {
  console.log("hello");
};
```

### Анонимность

Объявления функций может быть анонимной так и именованной.

## Recursive function

— это функция, которая вызывает саму себя для решения задачи, разбивая ее на более простые подзадачи.

Чтобы рекурсия работала правильно, нужны две вещи:

- Базовый случай — условие, при котором рекурсия прекращается.
- Рекурсивный вызов — вызов функции самой себя с измененными аргументами.

```js
function factorial(n) {
  if (n === 1) {
    return 1; // базовый случай
  }

  return n * factorial(n - 1); // рекурсивный вызов
}

console.log(factorial(5)); // 120
```

## Замыкание

Это функция, которая сохраняет доступ к переменным из своего внешнего окружения, даже после того как это окружение перестало существовать.

## Higher Order Function

Функция высшего порядка — это функция, которая принимает в качестве аргумента другие функции и/или возвращает в результате своей работы функцию.

Функции высшего порядка нужны, чтобы создавать более гибкий код, строить абстракции и применять паттерны функционального программирования.

Такие функции как `setTimeout()`

## IIFE (Immediately Invoked Function Expression)

– это функция, которая выполняется сразу же после того, как была определена.

```js
(function () {
  // какие-то действия
})();
```
