title: Array

— это структура данных для хранения упорядоченного списка значений. В массиве могут содержать значения любого типа. Главная идея - у каждого элемента есть позиция (индекс), по которой к нему можно обратиться.

```js
const arr = ["яблоко", "банан", "вишня"];
let arrConstructor = new Array(42, 42, 42);
```

Если заглянуть “под капот”, массив похож на это:

```js
const arr = {
  0: "яблоко",
  1: "банан",
  2: "вишня",
  length: 3,
};
```

Узнать массив ли это

```js
Array.isArray(arr); // true
```

## Деструктуризация

Деструктуризация идёт по порядку элементов:

```js
const arr = [10, 20, 30];
const [a, b, c] = arr;
console.log(a); // 10
```

Можно пропускать элементы:

```js
const [, second] = [1, 2, 3];
console.log(second); // 2
```

### Вложенная деструктуризация

— это когда ты “достаёшь данные внутри данных”. То есть не просто из массива, а из массива внутри массива.

```js
const data = [1, [2, 3]];
const [, [b, c]] = data;

console.log(b); // 2
console.log(c); // 3
```
