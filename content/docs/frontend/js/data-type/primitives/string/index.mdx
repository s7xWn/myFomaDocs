— это примитивный тип, который представляет текстовые данные: последовательность символов, либо символ по отдельности. Строки могут быть заключены в одинарные `(')`, двойные `(")`, или обратные `(``)` кавычки.

```js
let name: string = "Alice";
let message: string = 'Hello';
let template: string = `Hi, ${name}`;
```

В JavaScript строки бывают двух типов:<br/>
**Примитивная строка (string literal)**<br/>
Это примитив (не объект). У него нет методов как у объекта напрямую, но кажется, что они есть.:

```js
let str = "Hello";
console.log(typeof str); // "string"
```

**Объект String (через конструктор)**

```js
let strObj = new String("Hello");
console.log(typeof strObj); // "object"
```

Даже если строка — примитив, JS автоматически создаёт временный объект-обёртку (String object), чтобы ты мог использовать методы:

```js
let str = "Hello";
console.log(str.toUpperCase()); // "HELLO"
```

Что происходит внутри:

- JS временно превращает str в объект new String(str).
- Вызывает метод toUpperCase().
- Возвращает результат как примитив.

После этого временный объект уничтожается.

## Специальные символы

> Когда компьютеры только появились, главным способом взаимодействия с компьютером был текст. Неформатированный текст сложно воспринимать, поэтому появились специальные символы, которые обозначали различные операции, которые нужно сделать с текстом при выводе на экран.

| Последовательность | Значение                                        |
| ------------------ | ----------------------------------------------- |
| `\n`               | Новая строка                                    |
| `\t`               | Табуляция                                       |
| `\r`               | Возврат каретки                                 |
| `\b`               | Backspace                                       |
| `\f`               | Перевод страницы (Form Feed)                    |
| `\v`               | Вертикальная табуляция                          |
| `\0`               | Нулевой символ (NULL)                           |
| `\\`               | Обратный слэш `\`                               |
| `\'`               | Одинарная кавычка `'`                           |
| `\"`               | Двойная кавычка `"`                             |
| `` \` ``           | Обратная кавычка `` ` `` (в шаблонных строках)  |
| `\xXX`             | Символ по шестнадцатеричному коду (2 цифры)     |
| `\uXXXX`           | Unicode-символ (4 шестнадцатеричные цифры)      |
| `\u{XXXXX}`        | Unicode-кодовая точка (ES6, для любых символов) |

## Шаблонные строки

:::warning
Появился в версии EcmaScript 2015 года (ES6)
:::

Строки записываются в обратных кавычках `` ` ` `` и поддерживают:

- многострочный текст
- вставки выражений через `${...}`

```
const name = "Jack";
const score = 42;

const message = `Name: ${name}, score: ${score}`;
message; // "Name: Jack, score: 42"
```

## Свойства

### str.length

Возвращает длину строки

```js
const s = "JavaScript";
s.length; // 10
```

`length` доступно у экземпляра строки, но строки неизменяемы (immutable)

```js
const str = "Hello";

str.length = 10; // ничего не произойдет

console.log(str.length); // 5
```

## Явное приведение типа

### `String()`

```js
String(123); // "123"
String(true); // "true"
String(null); // "null"
String(undefined); // "undefined"
```

### Метод объекта `.toString()`

```js
(123).toString(); // "123"
true.toString(); // "true"
```

```js
null.toString(); // ошибка
undefined.toString(); // ошибка
```

<hr />

## Неявное приведение типа

### Конкатенация со строкой

```js
123 + ""; // "123"
true + ""; // "true"
```

### Шаблонные строки (template literals)

```js
`${123}`; // "123"
`${true}`; // "true"
```
