— это примитивный тип для всех чисел в JavaScript.<br/>
Тип данных содержит числа с плавающей точкой в диапазоне от -(2<sup>53</sup> − 1) до 2<sup>53</sup> − 1.

`number` включает:

- целые числа
- дробные
- отрицательные
- NaN (Результат вычисления — не число)
- Infinity
- -Infinity

```js
let age = 25;
let price = 99.99;
let value = NaN;
```

`number` ≠ `Number`

## Экспоненциальная запись

Например, один миллион в экспоненциальной записи:

```js
const scientific = 1e6;
```

## Системы счисления

При выводе на экран они будут преобразованы в десятичную систему счисления

### Двоичная

```js
const binary = 0b11;
console.log(binary);
// 3
```

### Восьмеричная

```js
const octal = 0o77;
console.log(octal);
// 63
```

### Шестнадцатеричная

```js
const hexadecimal = 0xff;
console.log(hexadecimal);
// 255
```

## Явное приведение типа

### `Number()`

```js
Number("123"); // 123
```

### Унарный плюс `+`

```js
+"123" + // 123
  "12.5" + // 12.5
  true + // 1
  false + // 0
  "abc"; // NaN
```

### `parseInt(value, [radix])`

Извлекает целую часть числа и останавливается при первом нечисловом символе.

- игнорирует дробную часть
- останавливается при первом "нечисле"
- может принимать систему счисления (радикс)

```js
parseInt("123"); // 123
parseInt("123px"); // 123
parseInt("12.9"); // 12
parseInt("abc123"); // NaN
```

### `parseFloat(value)`

Извлекает число с дробной частью и останавливается при первом нечисловом символе.

```js
parseFloat("123.45"); // 123.45
parseFloat("123.45px"); // 123.45
parseFloat("12.99.5"); // 12.99
parseFloat("abc"); // NaN
```

- останавливается при первом "нечисле"
- всегда предполагает десятичную систему
- не принимает основание системы счисления

## Неточные вычисления

Компьютер хранит данные в двоичном виде — наборе нулей и единиц. В этой системе счисления тоже есть дроби, которые не могут быть записаны точно. В этом случае формат округляет значение до ближайшего представимого. При арифметических операциях эти неточности складываются и приводят к эффектам, подобным этому:

```js
console.log(0.2 + 0.7);
// 0.8999999999999999
```

Это не ошибка JavaScript, а фундаментальная особенность хранения дробных чисел в памяти компьютера, с ней нужно уметь работать. Для уменьшения эффекта используется комбинация подходов — использовать как можно меньше дробных значений, а когда этого невозможно избежать — округлять числа, тем самым сбрасывая накопившийся остаток.

1. Округлять результат

```js
const result = Number((0.2 + 0.7).toFixed(10));

console.log(result); // 0.9
```

2. Для сравнения чисел использовать погрешность

```js
Math.abs(0.2 + 0.7 - 0.9) < Number.EPSILON;
// true
```
