---
title: boolean
---

— это примитивный тип двух значений: `true` и `false`

```js
let isActive = true;
let isAdmin = false;
```

## Явное приведение типа

### `Boolean()`

```js
Boolean(0); // false
Boolean(1); // true
Boolean(""); // false
Boolean("hi"); // true
Boolean(null); // false
```

### Двойное отрицание `!!`

```js
!!0; // false
!!1; // true
!!"text"; // true
!!""; // false
!!null; // false
```
