Работают с булевыми значениями

## Порядок вычисления и скобки

У операторов есть приоритет (precedence). В логике часто важнее читаемость, поэтому скобки - нормальная практика.<br/>
Приоритет:

1. `!`
2. `&&`
3. `||`

```js
const status = "ok";
const isAdmin = false;

const canEdit = status === "ok" && (isAdmin || status === "ok");
console.log(canEdit); // true
```

## `&&` (логическое И)

:::info[Простое правило]
`&&` возвращает первое “ложное” значение
:::

`a && b` читается как “a и b”.
:::warning
Не возвращает `true`/`false` в строгом смысле, а возвращает одно из значений операндов.
:::

Важно поведение возврата:

- идёт слева направо
- возвращает первое `falsy` значение, если оно найдено
- иначе возвращает последнее значение

```js
console.log("ok" && 123); // 123
console.log(0 && "next"); // 0
console.log("" && "next"); // ""
console.log("a" && "b"); // "b"
```

### **Типичные паттерны**

Условное выполнение

```js
const isReady = true;
isReady && console.log("запуск");
```

Защитная проверка перед доступом к свойству

```js
const user = { profile: { name: "Sam" } };

const name = user.profile && user.profile.name;
console.log(name); // "Sam"
```

Сегодня чаще используют [optional chaining `?.`](/docs/frontend/js/operators/nullish_optional#-optional-chaining), но принцип short-circuit полезно понимать:

```js
const name2 = user.profile?.name;
console.log(name2); // "Sam"
```

## `||` (логическое ИЛИ)

:::info[Простое правило]
`||` возвращает первое “правдивое” значение
:::

`a || b ` читается как “a или b”.

:::warning
Не возвращает `true`/`false` в строгом смысле, а возвращает одно из значений операндов.
:::

Поведение возврата:

- идёт слева направо
- возвращает первое `truthy` значение
- иначе возвращает последнее значение

```
console.log("" || "default");     // "default"
console.log(0 || 10);             // 10
console.log("text" || "default"); // "text"
```

Это часто используют как “подстановка по умолчанию”, но есть нюанс: `0`, `""`, `NaN` - falsy, хотя могут быть валидными значениями.

<hr />

## `!` (логическое НЕ) / `!!` (двойное отрицание)

`!value` приводит значение к boolean и инвертирует его.

```js
console.log(!true); // false
console.log(!false); // true
console.log(!0); // true
console.log(!"text"); // false
```

`!!` часто используют, чтобы явно получить boolean:

```js
console.log(!!"text"); // true
console.log(!!0); // false
```
