`JavaScript` - высокоуровневый, динамически типизированный, слабо типизированный, однопоточный, интерпретируемый, встраиваемый, мультипарадигменный язык программирования.

Движок `JavaScript` читает и выполняет твой код синхронно. <br/>
В браузере (или в Node.js) код обрабатывает движок вроде V8:

1. Парсинг (Parsing)
   - Твой JS-код превращается в структуру данных (AST — Abstract Syntax Tree).
   - Проверяется синтаксис.
2. Компиляция
   - AST превращается в байт-код или сразу в машинный код (в современных движках).
3. Исполнение
   - Код выполняется процессором через виртуальную машину.
4. JIT-оптимизация (Just-In-Time)
   - “Горячие” участки кода ускоряются: движок оптимизирует их во время работы.

:::warning
JavaScript обычно выполняется в одном основном потоке (single-threaded execution), но с важными нюансами.

- одновременно выполняется только одна инструкция JS
- нет параллельного выполнения “чистого” JS-кода в одном контексте

Таймеры, запросы и `async` работают потому что есть [Event Loop (цикл событий)](/docs/frontend/js/EventLoop).
:::
