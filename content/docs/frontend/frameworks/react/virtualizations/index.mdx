title: "Виртуализация"
---

Виртуализация — это техника, при которой система создаёт видимость большого количества объектов или ресурсов, фактически используя более ограниченный набор реальных ресурсов.

В веб-разработке виртуализация обычно означает, что приложение показывает пользователю тысячи элементов, но реально создаёт в DOM только небольшую часть из них.

<Callout>
Слово «виртуализация» используется в разных областях IT.

| Область              | Что виртуализируют           |
| -------------------- | ---------------------------- |
| Web-разработка       | Элементы интерфейса в DOM    |
| Серверы              | Виртуальные машины           |
| Хранение данных      | Логические диски и хранилища |
| Операционные системы | Память и другие ресурсы      |

</Callout>

<hr />

## Преимущества

- Производительность. Меньше элементов в DOM — меньше работы для браузера.
- Плавная прокрутка. Особенно на длинных списках и больших таблицах.
- Меньше расход ресурсов. Снижается нагрузка на создание и обновление DOM-элементов.
- Масштабируемость интерфейса. Можно работать с десятками или сотнями тысяч записей, если правильно организовать данные и рендеринг.

<hr />

## Места применения

- Большие таблицы с тысячами строк.
- Чаты с длинной историей сообщений.
- Ленты новостей и каталоги товаров.
- Деревья файлов и сложные иерархические списки.
- Большие выпадающие списки с поиском.

Главное отличие: TanStack Virtual даёт максимальную свободу, React Virtuoso предлагает больше готовых решений, а react-window ориентирован на более простую виртуализацию.

- **TanStack Virtual** <br/>
  Headless-библиотека: самостоятельно создаёшь разметку, стили и поведение списка. Подходит для сложных таблиц, деревьев, сеток и кастомных интерфейсов.
- **React Virtuoso** <br/>
  Предоставляет готовые компоненты для списков, групп, таблиц и сеток. Умеет измерять высоту элементов, что удобно для чатов, лент и контента переменного размера.
- **react-window** <br/>
  Минималистичное решение для виртуализации списков и сеток. Может быть хорошим выбором для простой задачи, но нужно учитывать версию API: актуальные версии отличаются от распространённых старых примеров.
- **Virtua** <br/>
  щё один современный вариант, ориентированный на удобную виртуализацию с готовыми компонентами и поддержкой нескольких UI-фреймворков. Стоит рассмотреть, если хочется меньше ручного кода, чем с TanStack Virtual.

#### Рекомендации по выбору

| Сценарий                                       | Рекомендуемая библиотека    |
| ---------------------------------------------- | --------------------------- |
| Кастомный интерфейс с полным контролем над DOM | TanStack Virtual            |
| Чат или лента сообщений                        | React Virtuoso              |
| Простой виртуализированный список в React      | react-window                |
| Сетка карточек или каталог                     | TanStack Virtual или Virtua |
| Сложная таблица с большим количеством функций  | AG Grid                     |
| Таблица в приложении на Material UI            | MUI X Data Grid             |

**Примечание:** динамическая высота, производительность и доступные функции зависят от версии библиотеки и конкретной реализации. TanStack Virtual — headless-библиотека виртуализации, тогда как AG Grid и MUI X Data Grid — полноценные табличные компоненты.
