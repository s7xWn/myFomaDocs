TanStack Virtual — это библиотека для JavaScript и TypeScript, которая позволяет эффективно отображать большие списки и таблицы в веб-приложениях, не создавая DOM-элементы для каждой строки сразу.

Её главная идея — виртуализация (virtualization): браузер отображает только видимые элементы и небольшое количество элементов вокруг них, а остальные создаются по мере прокрутки.
