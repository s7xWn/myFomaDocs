— это специальные функции, которые позволяют использовать возможности React (состояние, жизненный цикл, контекст и т.д.) в функциональных компонентах, не прибегая к классовым компонентам.

:::important
По существующим соглашениям имя хука должно предваряться префиксом `use`.

:::danger[Правила хуков]
Хуки следует вызывать лишь непосредственно в теле компонента. <br/>
Помещать вызовы хуков в условные выражения, циклы и тела вложенных функций не допускается и приводит к ошибке. <br/>
:::

## Custom hooks

Кастомные хуки в React создают для того, чтобы вынести повторяющуюся логику из компонентов, переиспользовать её и сделать код проще для поддержки.

Обычный компонент часто начинает смешивать несколько вещей:

- отображение UI;
- работу с состоянием;
- запросы к API;
- подписки на события;
- работу с браузерными API;
- обработку сложной бизнес-логики.

Кастомный хук позволяет отделить эту логику.
