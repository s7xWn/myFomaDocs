— это один из базовых хуков в React, который позволяет функциональным компонентам хранить и изменять состояние (state).

:::important
Если изменение значения должно привести к обновлению интерфейса — используй `useState`. Если нет — обычную переменную.
:::

> До появления хуков состояние можно было использовать только в классовых компонентах.

```jsx
import { useState } from "react";
```

<br /> <br />

`useState` в React возвращает массив из двух элементов:

<Tabs items={['JSX', 'TSX']}>
  <Tab value="jsx">

    ```jsx
    const [state, setState] = useState(initialValue);
    ```

  </Tab>
  <Tab value="tsx">

    ```tsx
    const [state, setState] = useState<typeOfValue>(initialValue);
    ```

  </Tab>
</Tabs>

- `state` — текущее значение состояния.
- `setState` — функция для обновления состояния.
- `initialValue` — начальное значение.

React запоминает значение `state` между рендерами. <br/>
После вызова `setState`, React сохраняет новое значение. **Планирует повторный рендер компонента.** <br/>
При следующем рендере `state` уже равен переменной, которая была передана через `setState`.

:::important
Обновление состояния происходит не мгновенно — React планирует новый рендер.

```jsx
console.log(count); // старое значение
setCount(5);
console.log(count); // всё ещё старое значение
```

:::

`useState` имеет две формы вызова:

```jsx
useState(initialValue);
useState(() => initialValue);
```

Во втором случае React понимает:

> "Мне передали функцию для получения начального значения. Я вызову её один раз при первом рендере и запомню результат."

<hr />

## Ленивое создание начального значения

— это способ сказать React: "вычисли начальное значение только один раз, при первом рендере". <br/>
Вместо значения в `useState` передается функция.

```jsx
const [value, setValue] = useState(() => expensiveCalculation());
```

или

```jsx
const [value, setValue] = useState(() => expensiveCalculation);
```

<hr />

## Обновление состояния

Когда новое значение не зависит от предыдущего можно использовать:

```jsx
setState(newState);
```

В отсальных случаях ( когда требуется прошлое состояние ) использовать [Обновление состояния через функцию](#обновление-состояния-через-функцию)

<hr />

## Обновление состояния у объектов, массивов (через функцию + spread)

Правильное обновление состояния:

<Tabs items={['Через функцию', 'Обычное']}>
  <Tab value="func">
    ```jsx
    setUser(prev => ({
        ...prev,
        age: prev.age + 1,
    }));
    ```
  </Tab>
  <Tab value="def">
    ```jsx
    setUser({
        ...user,
        age: 26,
    });
    ```
  </Tab>
</Tabs>

:::warning
Если сделать так:

```jsx
user.age = 26;
setUser(user);
```

React может не заметить изменения, потому что ссылка на объект осталась прежней.
:::

<hr />

## Обновление состояния через функцию

Когда новое значение зависит от предыдущего, лучше использовать функцию:

```jsx
setCount((prev) => prev + 1);
```

Это безопаснее, потому что React может объединять несколько обновлений состояния.

```jsx
setCount((prev) => prev + 1);
setCount((prev) => prev + 1);
setCount((prev) => prev + 1);
// +3

setCount(count + 1);
setCount(count + 1);
setCount(count + 1);
// +1
```

Простое правило

> Чтобы вычислить новое значение, мне нужно знать старое?

- Да → используй функцию `setState(prev => ...)`
- Нет → передавай значение напрямую `setState(newValue)`

## Обращению к данным в состоянии, которых еще нет.

<details>

<summary>Пример ошибки</summary>

Представим, что ты загружаешь пользователя с сервера:

```jsx
const [user, setUser] = useState();
```

Сразу после первого рендера React пытается выполнить код:

```jsx
<h1>{user.name}</h1>
```

Но `user` еще `undefined`, потому что запрос не успел выполниться.

Получишь ошибку:

```
Cannot read properties of undefined (reading 'name')
```

</details>

### 1. Проверять существование объекта

Если `data` еще нет, React просто выведет ничего вместо ошибки.

```jsx
<h1>{data?.name}</h1>
```

### 2. Условный рендеринг

Можно вообще не показывать компонент, пока данные не загрузились.

```jsx
if (!data) {
  return <div>Loading...</div>;
}

return <h1>{data.name}</h1>;
```

### 3. Задать начальное значение

Если заранее известна структура объекта или будет массив:

```jsx
const [user, setUser] = useState({
  name: "",
  age: 0,
});

const [arr, setArr] = useState([]);
```

Если объект большой или его структура неизвестна заранее, создавать "пустую копию" неудобно.
