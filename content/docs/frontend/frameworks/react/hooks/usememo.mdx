---
title: useMemo
---

— это хук React, который запоминает (мемоизирует) результат вычисления и пересчитывает его только тогда, когда изменяются указанные зависимости.

Это помогает избежать дорогостоящих вычислений при каждом рендере компонента.

```jsx
import { useMemo } from "react";
```

```jsx
const memoizedValue = useMemo(callback, deps);
```

- `callback` — функция, которая возвращает результат вычислений.
- `deps` — массив зависимостей. Если зависимости не изменились, React вернет сохраненное значение, не вызывая функцию повторно.

:::warning
`useMemo` — это оптимизация производительности, а не гарантия логики программы. React может при необходимости отбросить закэшированное значение и пересчитать его снова. Поэтому код внутри `useMemo` должен быть чистой функцией: он не должен иметь побочных эффектов (например, отправлять запросы или изменять внешние переменные).
:::

## Как работает

1. Компонент рендерится.
2. React смотрит на массив зависимостей.
3. - Если элементы массива зависимостей не изменились → React берет старое сохранённое значение.
   - Если элементы массива зависимостей изменились → React вызывает callback внутри useMemo заново.
