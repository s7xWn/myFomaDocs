---
title: useNavigation
---

— это хук, который даёт доступ к текущему состоянию навигации в приложении. <br/>
Он используется в основном в приложениях с Data Router API (то есть с [`createBrowserRouter`](../data-mode/create-browser-router), [`RouterProvider`](../data-mode/router-provider), [`loaders`](../data-mode/route-object#loader)/[`actions`](../data-mode/route-object#action)), чтобы понимать, происходит ли переход между страницами, отправка формы или загрузка данных.

```tsx
import { useNavigation } from "react-router-dom";
```

```tsx
const navigation = useNavigation();
```

:::danger
`useNavigation()` не работает с простым `<BrowserRouter>` в старом стиле. Он предназначен для Data Router!
:::

## Возвращает

```tsx
{
  state: "idle" | "loading" | "submitting",
  location: Location,
  formData: FormData,
  formAction: string,
  formMethod: string
}
```

### `state`

| `navigation.state` | Когда возникает                                        | Что означает                                                                                         | Типичный сценарий                                                                 | Что можно сделать                                                     |
| ------------------ | ------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| `"idle"`           | Нет активной навигации                                 | Приложение находится в обычном состоянии, переходов и отправок нет                                   | Пользователь просто просматривает страницу                                        | Скрыть загрузчики, включить кнопки, убрать индикаторы                 |
| `"loading"`        | Идёт переход между маршрутами или выполняется `loader` | React Router загрузает новый маршрут или ждёт данные                                                 | Пользователь нажал `<Link>`, вызвал `navigate()`, открывается страница с `loader` | Показать глобальный спиннер, прогресс-бар, skeleton UI                |
| `"submitting"`     | Отправляется форма через `action`                      | React Router выполняет серверное действие (`action`) после `<Form method="post">` или `fetcher.Form` | Пользователь нажал «Сохранить», «Удалить», «Отправить»                            | Заблокировать кнопку, показать "Сохранение...", сделать optimistic UI |
