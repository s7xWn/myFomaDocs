---
title: useLocation
---

— это хук, который возвращает текущий объект местоположения (URL location) в приложении React. С его помощью можно узнать, где находится пользователь: путь, параметры строки запроса, состояние перехода и т.д.

```tsx
import { useLocation } from "react-router";
```

```tsx
const location = useLocation();
```

Объект `location` выглядит примерно так:

```js
{
  pathname: "/users/123",
  search: "?tab=profile",
  hash: "#settings",
  state: null,
  key: "abc123"
}
```

## Поля `location`

| Поле       | Описание                                   |
| ---------- | ------------------------------------------ |
| `pathname` | путь URL                                   |
| `search`   | query-параметры                            |
| `hash`     | часть после `#`                            |
| `state`    | данные, переданные при навигации           |
| `key`      | уникальный идентификатор текущего перехода |
