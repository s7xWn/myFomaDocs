---
title: <Navigate>
---

— это компонент для программного перенаправления (редиректа) пользователя на другой маршрут.

```tsx
import { Navigate } from "react-router-dom";
```

```tsx
if (!isLoggedIn) {
  return <Navigate to="/login" />;
}
```

## Свойства

| Свойство  | Описание                  |
| --------- | ------------------------- |
| `to`      | куда перейти              |
| `replace` | заменить историю браузера |

```tsx
<Navigate to="/login" replace />
```
