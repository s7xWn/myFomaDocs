---
title: <Outlet>
---

— это компонент, который показывает место, куда будет вставлен дочерний маршрут (nested route) внутри родительского компонента.

Родительский маршрут (layout) рисует общий каркас (например, меню, шапку, сайдбар), а `Outlet` — это «окно», где появится содержимое выбранного дочернего маршрута.
