## Режимы использования роутера

- **Declarative** — если у вас обычное SPA и данные вы уже загружаете через React Query, RTK Query, SWR или useEffect.
- **Data** — если хотите использовать встроенные возможности React Router для загрузки данных, форм и обработки навигации без перехода на полноценный фреймворк.
- **Framework** — если начинаете новый проект и хотите получить опыт, близкий к Remix или Next.js: файловый роутинг, SSR, серверные функции и другие возможности "из коробки".

### Использование Declarative Mode (декларативный)

Вы просто описываете маршруты как React-компоненты.

Подходит, если:

- приложение небольшое;
- данные загружаются через useEffect, React Query, SWR и т.п.;
- не нужны встроенные механизмы загрузки данных.

Минусы

- загрузку данных приходится организовывать самостоятельно;
- нет встроенных `loader`, `action`, обработки форм и т.д.

1. Обернуть приложение в [`<BrowserRouter>`](./declarative-mode/browser-router)
2. Создать [`Routes`](./declarative-mode/routes) и использовать [`Route`](./declarative-mode/route) по необходимости с [`layout`](./declarative-mode/route#вложенные-маршруты--layout)
3. Для навигации использовать [`useNavigate`](./hooks/usenavigate) или [`<Link>`](./components/link)

### Использование Data Mode

1. Создаём файл(`./routes/router.ts`) с [`createBrowserRouter`](./data-mode/create-browser-router) и настриваем в нём роуты с помощью [`RouteObject`](./data-mode/route-object)
   - настриаваем [`loader`](./data-mode/route-object#loader), [`action`](./data-mode/route-object#action)
2. Подключаем [`RouterProvider`](./data-mode/router-provider) в главном файле приложения.
3. Для навигации использовать [`useNavigate`](./hooks/usenavigate) или [`<Link>`](./components/link)

#### Pending UI (loader)

В Data Mode **pending UI** обычно реализуется через состояние навигации из [`useNavigation()`](./hooks/usenavigation). В отличие от Framework Mode, где есть `HydrateFallback` и `pending UI` на уровне маршрутов, в Data Mode вы сами контролируете отображение загрузки через `navigation.state`.

1. Глобальный Pending UI через Layout

<details>
  <summary> Пример </summary>

```tsx
import { Outlet, useNavigation } from "react-router";

export default function RootLayout() {
  const navigation = useNavigation();
  const isNavigating = Boolean(navigation.location);

  return <>{isNavigating ? <Spinner /> : <Outlet />}</>;
}
```

</details>

2. Локальный Pending UI для конкретной страницы

<details>
  <summary> Пример </summary>

```tsx
import { useNavigation } from "react-router";

export default function Users() {
  const navigation = useNavigation();

  const pending =
    navigation.state === "loading" && navigation.location.pathname === "/users";

  return (
    <>
      {pending && <Spinner />}

      <UsersTable />
    </>
  );
}
```

</details>
