Next.js — это фреймворк для разработки веб-приложений на базе React.

<hr />

## Установка

<Tabs items={["npm", "yarn", "pnpm", "bun"]}>
  <Tab value="npm">
    
    ```bash
    npx create-next-app@latest my-app
    ```

  </Tab>
  <Tab value="yarn">
    
    ```bash
    yarn create next-app@latest my-app
    ```

  </Tab>
  <Tab value="pnpm">
    
    ```bash
    pnpm create next-app@latest my-app
    ```

  </Tab>
  <Tab value="bun">

    ```bash
    bun create next-app@latest my-app
    ```

  </Tab>
</Tabs>

`--yes` -> автосоглашение
