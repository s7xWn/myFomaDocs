<Tabs items={["npm", "yarn", "pnpm", "bun"]}>

    ```bash
    npx shadcn@latest init
    ```

  </Tab>
  <Tab value="yarn">

    ```bash
    yarn dlx shadcn@latest init
    ```

  </Tab>
  <Tab value="pnpm">
    
    ```bash
    pnpm dlx shadcn@latest init
    ```

  </Tab>
  <Tab value="bun">

  </Tab>

### Templates `-t [framework]`

В конце добавить один из шаблонов: "Supported templates: `next`, `vite`, `start`, `react-router`, and `astro`."

```bash
npx shadcn@latest init -t [framework]
```
