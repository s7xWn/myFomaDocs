— это лёгкая библиотека для управления состоянием в React-приложениях.

:::important
Zustand является **`multi-store`**! <br/>
Нет глобального “единственного `store`”, как в классическом Redux-подходе. <br/>
Вместо этого ты можешь **создавать сколько угодно независимых `store’ов`**
:::

## Создание и использование

Для начала создаём [`Store`](./store) <br/>
Импортируем наш `store` и используем в нашем компоненте:

<Tabs items={["Без селектора", "С селектором"]}>
  <Tab value="woselector">
    
    Ты получаешь весь объект состояния стора (или весь объект, который возвращает хук). <br/>
    Если в сторе изменится любое поле, компонент будет перерендерен.

    ```jsx
    import useStore from "./store";

    function Counter() {
      const { count, increment } = useStore();
      return (
        <div>
          <p>{count}</p>
          <button onClick={increment}>+</button>
        </div>
      );
    }
    ```

  </Tab>
  <Tab value="selector">
    
    Здесь используется селектор. <br/>
    Компонент подписывается только на `state.count`.
    Он перерендерится только когда изменится `count` или `increment`.

    ```jsx
    import useStore from "./store";

    function Counter() {
      const count = useStore((state) => state.count);
      const increment = useStore((state) => state.increment);
      return (
        <div>
          <p>{count}</p>
          <button onClick={increment}>+</button>
        </div>
      );
    }
    ```

  </Tab>
</Tabs>
