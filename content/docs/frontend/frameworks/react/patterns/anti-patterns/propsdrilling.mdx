---
title: Props drilling
---

— это ситуация, когда данные передаются через множество уровней компонентов вниз по дереву, хотя промежуточные компоненты эти данные вообще не используют.

Структура:

```
App → Page → Sidebar → Menu → MenuItem
```

И только `MenuItem` нуждается в `user`. Компоненты `Page`, `Sidebar`, `Menu` — просто «проводники» данных.

## Решение

- Использовать `state manager`
- Использовать паттерны slot и mediator
