<details>
  <summary>Пояснение</summary>

Когда ты запускаешь приложение в development:

```bash
npm run dev
```

А когда делаешь production build:

```bash
npm run build
```

`process.env.NODE_ENV` становится: `"production"`

## Использование

Создаём `<QueryClientProvider>` с `QueryClient()` в `main.tsx`:

```ts
import { QueryClient, QueryClientProvider } from "@tanstack/react-query";
```

```ts
const queryClient = new QueryClient();
```

```ts
<QueryClientProvider client={queryClient}>
  <App />
</QueryClientProvider>
```

<details>
  <summary>Примерный `main.ts`</summary>

```ts
import { StrictMode } from 'react'
import { createRoot } from 'react-dom/client'
import { QueryClient, QueryClientProvider } from '@tanstack/react-query'
import App from './App'
import './index.css'

const queryClient = new QueryClient()

createRoot(document.getElementById('root')!).render(
  <StrictMode>
    <QueryClientProvider client={queryClient}>
      <App />
    </QueryClientProvider>
  </StrictMode>,
)
```

</details>

Теперь этот провайдер доступен в любом месте приложения.

Используем хук [`useQuery`](./hooks/use-query.mdx) для запросов.

- или другие хуки [`useQueries`](./hooks/use-queries.mdx),[`useSuspenseQuery`](./hooks/use-suspensequery.mdx),[`useSuspenseQueries`](./hooks/use-suspensequeries.mdx),

Используем [`AbortController`](./hooks/use-query.mdx#abortcontroller-%D0%B4%D0%BB%D1%8F-queryfn) и [остановку запросов `cancelQueries()`](./hooks/use-queryclient.mdx#останавливает-запрос-cancelqueries)

### Работа с кешом на уровне `QueryClient`

Это значение будет дефолтным для всех queries.

### Актуальность кеша в мс `staleTime`

```ts
const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      staleTime: 1000 * 60 * 5, // 5 minute
    },
  },
});
```

### Автоудаление кеша в мс `gc`

```ts
const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      gcTime: 1000 * 60 * 60, // 1 час
    },
  },
});
```
