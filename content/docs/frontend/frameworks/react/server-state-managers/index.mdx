---
title: Server state managers
---

— это менеджеры server state (или инструменты управления server cache / data fetching layer). <br/>
В целом их можно называть server state managers, но с важной оговоркой: это не “полноценные state managers” в классическом смысле вроде Redux, MobX или Zustand.

:::note
лучше уточнять, что это именно инструменты для server cache + data fetching, а не универсальные state managers.
:::

Решают проблемы:

- получение данных с сервера (fetching)
- кэширование
- синхронизация с сервером
- рефетчинг / инвалидация
- дедупликация запросов
- управление “устареванием” данных

:::important[Это НЕ просто “state managers”]
“State manager” обычно подразумевает:

- глобальное клиентское состояние (UI state)
- локальные флаги, модалки, темы, формы
- предсказуемые редьюсеры / стор

А эти библиотеки:

- почти не предназначены для UI state
- не заменяют Redux/Zustand
- не хранят “истинное состояние приложения”, а только кешируют серверные данные

:::

## Примеры инструментов

- TanStack Query (React Query)
- Redux Toolkit Query
- SWR
