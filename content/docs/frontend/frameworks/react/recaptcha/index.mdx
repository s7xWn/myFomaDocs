## Google

| Пакет                       | Когда использовать                                                                             |
| --------------------------- | ---------------------------------------------------------------------------------------------- |
| `@google-recaptcha/react`   | Универсальный вариант: поддерживает reCAPTCHA v3, v2 Checkbox и Invisible, а также TypeScript. |
| `react-google-recaptcha-v3` | Популярный вариант для reCAPTCHA v3 с хуком useGoogleReCaptcha.                                |
| `react-google-recaptcha`    | Если нужен классический виджет reCAPTCHA v2 с чекбоксом «Я не робот».                          |
