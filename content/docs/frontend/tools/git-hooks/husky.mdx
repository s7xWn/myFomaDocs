— это инструмент для автоматизации Git-хуков, которые автоматически выполняются при определённых событиях Git.

Проще говоря: Husky позволяет запускать проверки и задачи до или после действий в Git, чтобы поддерживать качество кода.

## Устновка

<Tabs items={["npm", "yarn", "pnpm"]}>
  <Tab value="npm">
    
    ```bash
    npm install --save-dev husky
    ```

  </Tab>
  <Tab value="yarn">
    
    ```bash
    yarn add --dev husky
    ```

  </Tab>
  <Tab value="pnpm">
    
    ```bash
    pnpm add --save-dev husky
    ```

  </Tab>
</Tabs>

Инициализация:

```bash
npx husky init
```

- создаст папку `.husky/`;
- добавит пример hook `pre-commit`;
- добавит настройку [`prepare`](/docs/frontend/tools/package-managers/npm#prepare) в `package.json`.

<hr />

## Как это работает

<details>
  <summary>Пример</summary>

Когда ты делаешь, например, `git commit`, Husky может автоматически:

- запустить линтер (например, ESLint),
- проверить форматирование (Prettier),
- прогнать тесты,
- запретить коммит, если есть ошибки.

</details>

## Основные git-hooks

| Hook                 | Когда запускается                           | Типичные задачи                                             |
| -------------------- | ------------------------------------------- | ----------------------------------------------------------- |
| `pre-commit`         | Перед созданием коммита                     | Линтер, форматирование, тесты                               |
| `prepare-commit-msg` | Перед открытием редактора сообщения коммита | Автоматическая вставка шаблона сообщения                    |
| `commit-msg`         | После ввода сообщения коммита               | Проверка формата сообщения (например, Conventional Commits) |
| `post-commit`        | После успешного коммита                     | Уведомления, логирование                                    |
| `pre-merge-commit`   | Перед созданием merge-коммита               | Проверки перед слиянием                                     |
| `post-merge`         | После успешного merge                       | Обновление зависимостей, миграции                           |
| `pre-push`           | Перед `git push`                            | Запуск тестов, проверка сборки                              |
| `post-rewrite`       | После `git commit --amend` или rebase       | Обновление ссылок/метаданных                                |
| `pre-rebase`         | Перед `git rebase`                          | Запрет опасных rebase                                       |
| `post-checkout`      | После `git checkout` или `git switch`       | Настройка окружения                                         |
| `post-receive`       | На сервере после получения push             | Деплой, уведомления                                         |
| `update`             | На сервере перед обновлением ветки          | Проверка прав, ограничений                                  |
| `pre-receive`        | На сервере перед принятием push             | Серверные проверки                                          |
| `push-to-checkout`   | На сервере при обновлении рабочей копии     | Автоматический checkout                                     |
| `post-update`        | На сервере после обновления ссылок          | Уведомления                                                 |
