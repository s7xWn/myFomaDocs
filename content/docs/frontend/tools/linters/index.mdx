— это инструмент, который автоматически проверяет код на ошибки, стиль и потенциальные проблемы ещё до запуска программы.

> **Компилятор** проверяет, работает ли код;
>
> **Linter** проверяет, насколько код качественный, чистый и безопасный.

Linter может заметить:

- неиспользуемые переменные;
- забытые ;;
- неправильные отступы;
- подозрительные конструкции;
- нарушение стиля команды;
- потенциальные баги.

Популярные линтеры

- JavaScript / TypeScript → **ESLint**
- Python → **Pylint, Flake8, Ruff**
- Go → **golangci-lint**
- Rust → **Clippy**
- CSS, SCSS / Sass, Less, Vue / React style blocks → **Stylelint**

## ESLint vs Biome

Для нового JavaScript/TypeScript-проекта я бы выбрал Biome, а для сложного проекта с большим количеством правил и плагинов — ESLint.

Они решают похожие задачи, но есть важное различие: ESLint прежде всего линтер, а Biome объединяет линтинг и форматирование в одном инструменте.

| Критерий                            | ESLint                                                             | Biome                                        |
| ----------------------------------- | ------------------------------------------------------------------ | -------------------------------------------- |
| Скорость                            | Обычно медленнее                                                   | Обычно быстрее                               |
| Линтинг JavaScript/TypeScript       | Отличный                                                           | Отличный                                     |
| Форматирование кода                 | Требуется Prettier или аналог                                      | Встроенное                                   |
| Экосистема плагинов                 | Очень большая                                                      | Более ограниченная                           |
| Настройка                           | Может быть сложной                                                 | Обычно проще                                 |
| React / JSX                         | Широкая поддержка через плагины                                    | Поддержка встроена                           |
| Type-aware linting                  | Широкие возможности через typescript-eslint                        | Более ограниченные возможности               |
| Монорепозитории                     | Хорошая поддержка                                                  | Хорошая поддержка                            |
| Кастомные правила                   | Гибкая система плагинов и правил                                   | Более ограниченные возможности               |
| Единый инструмент для lint и format | Нет, обычно нужны дополнительные инструменты                       | Да                                           |
| Подходит для новых проектов         | Да                                                                 | Да                                           |
| Лучший сценарий использования       | Сложные проекты с особыми правилами и большим количеством плагинов | Новые проекты, где важны скорость и простота |

- **Biome** — хороший выбор для новых JavaScript/TypeScript-проектов, если нужны быстрый линтинг и форматирование с минимальной настройкой.
- **ESLint** — лучший выбор, если нужны специфические плагины, сложные правила или расширенный type-aware linting.
- **ESLint + Prettier** — проверенная комбинация для проектов, которым необходимы возможности экосистемы ESLint и отдельный форматтер.
