---
title: Linters
---

— это инструмент, который автоматически проверяет код на ошибки, стиль и потенциальные проблемы ещё до запуска программы.

> **Компилятор** проверяет, работает ли код;
>
> **Linter** проверяет, насколько код качественный, чистый и безопасный.

Linter может заметить:

- неиспользуемые переменные;
- забытые ;;
- неправильные отступы;
- подозрительные конструкции;
- нарушение стиля команды;
- потенциальные баги.

Популярные линтеры

- JavaScript / TypeScript → **ESLint**
- Python → **Pylint, Flake8, Ruff**
- Go → **golangci-lint**
- Rust → **Clippy**
- CSS, SCSS / Sass, Less, Vue / React style blocks → **Stylelint**
