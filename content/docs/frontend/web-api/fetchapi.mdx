— это встроенный Web API для выполнения HTTP-запросов (GET, POST и т.д.). Он пришёл на замену старому `XMLHttpRequest` и работает на основе [`Promise`](/docs/frontend/js/data-type/Objects/Promise/).

`fetch()` — это функция браузера, которая позволяет отправлять запросы на сервер и получать ответы.

```
fetch('http://example.com/movies.json')
  .then((response) => {
    return response.json()
  })
  .then((data) => {
    console.log(data)
  })
```

Браузер формирует объект запроса (`Request`) с:

- URL
- методом (GET, POST, PUT…)
- заголовками
- телом (если есть)

## Response

Когда сервер отвечает, `fetch` возвращает `Promise`, который резолвится в объект `Response`, который содержит:

- [`status`](/docs/computer-science/http/http-status-codes) (200, 404, 500…)
- [`headers`](/docs/computer-science/http/http-headers)
- `body` (поток данных — stream)
