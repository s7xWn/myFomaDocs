title: WebSocket API
---

> `new WebSocket("ws://example.com/test")` <br/>
> `new WebSocket("wss://example.com/test")`

— это протокол связи, который позволяет установить постоянное двустороннее (полнодуплексное) соединение между браузером пользователя (клиентом) и сервером, которые могут отправлять данные друг другу в любое время.

## Как это работает

- Клиент шлет специальный HTTP-запрос (начинается с `GET ... Upgrade: websocket`).
- Сервер отвечает согласием **«Switch Protocols»**.
- После этого соединение «переключается» с `HTTP` на `WebSocket`, и оба участника могут слать данные в любой момент.
