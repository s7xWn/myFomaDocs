## 1) Вариант через сравнение `outer` и `iner`

```js
function windowSizeCheck(params) {
  let windowWidthDiff = 0;
  let windowHeightDiff = 0;

  windowWidthDiff = window.outerWidth - window.innerWidth;
  windowHeightDiff = window.outerHeight - window.innerHeight;

  return windowWidthDiff >= 80 || windowHeightDiff >= 120;
}

if (windowSizeCheck()) {
  // что делать при детекции
}
```

`80` и `120` нужно выбирать аккуратно, т.к. могут быть ложные срабатывания

- Появляется панель закладок (сверху или сбоку)
- Или zoom страницы (через зажатый ctrl и колёсико), особый кейс в других браузерах

Фикс zoom этого через `devicePixelRatio`

```js
function windowSizeCheck(params) {
  let windowWidthDiff = 0;
  let windowHeightDiff = 0;

  windowWidthDiff =
    window.outerWidth - window.innerWidth * window.devicePixelRatio;
  windowHeightDiff =
    window.outerHeight - window.innerHeight * window.devicePixelRatio;

  return windowWidthDiff >= 80 || windowHeightDiff >= 120;
}

if (windowSizeCheck()) {
  // что делать при детекции
}
```

Фикс zoom для Firefox

```js
function windowSizeCheck(params) {
  let windowWidthDiff = 0;
  let windowHeightDiff = 0;

  if (isFireFox) {
    windowWidthDiff =
      (window.outerWidth - window.innerWidth) * window.devicePixelRatio;
    windowHeightDiff =
      (window.outerHeight - window.innerHeight) * window.devicePixelRatio;
  } else {
    windowWidthDiff =
      window.outerWidth - window.innerWidth * window.devicePixelRatio;
    windowHeightDiff =
      window.outerHeight - window.innerHeight * window.devicePixelRatio;
  }

  return windowWidthDiff >= 80 || windowHeightDiff >= 120;
}

if (windowSizeCheck()) {
  // что делать при детекции
}
```

## 2) Вариант через `debugger` ловушки

При откытых dev tools срабатывает `debugger`

```js
function debuggerChek() {
  const t1 = perfomance.now();
  debugger;
  const t2 = perfomance.now();
  return t2 - t1 > 5;
}
```

Можно добавить анонимную функцию вместо `debugger`:

```js
new Function("debugger")();
```
