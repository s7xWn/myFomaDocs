---
title: Architecture patterns
---

— это типовые способы организации кода приложения, которые помогают сделать его более **понятным**, **масштабируемым** и **удобным для сопровождения**.
Они определяют, как разделить ответственность между различными частями приложения, а не то, как писать отдельные функции или компоненты.

Наиболее распространенные архитектурные паттерны:

<details>
  <summary>Component-Based Architecture (компонентная архитектура)</summary>

    Идея:

    - интерфейс разбивается на независимые компоненты;
    - каждый компонент отвечает за свою часть UI;
    - компоненты можно переиспользовать.

</details>

<details>
  <summary>Layered Architecture (слоистая архитектура)</summary>

    Код разделяется на слои. Каждый слой знает только о следующем.

</details>

<details>
  <summary>Feature-Based Architecture</summary>

    Один из самых популярных подходов сегодня.

</details>

| Размер проекта     | Рекомендуемый подход                                                          |
| ------------------ | ----------------------------------------------------------------------------- |
| Лендинг            | Component-Based Architecture                                                  |
| Небольшое SPA      | Component-Based + Layered Architecture                                        |
| Среднее приложение | Feature-Based + Layered Architecture                                          |
| Большое приложение | Feature-Sliced Design или Clean Architecture                                  |
| Enterprise         | Clean Architecture + FSD + управление состоянием (например, Redux или аналог) |

## Уровни принятия архитектурных решений

— от самых абстрактных до конкретного кода. Часто используют в архитектурных обзорах, при проектировании больших систем и в enterprise-разработке.

```
┌────────────────────────────┐
│ Уровень организации        │
│ Экосистема компании        │
└───────────────┬────────────┘
                │
┌───────────────▼────────────┐
│ Уровень решения            │
│ Архитектура продукта       │
└───────────────┬────────────┘
                │
┌───────────────▼────────────┐
│ Уровень приложения         │  <-- Frontend разработка тут
│ Архитектура frontend       │
└───────────────┬────────────┘
                │
┌───────────────▼────────────┐
│ Уровень кода               │
│ Компоненты, хуки, классы   │
└────────────────────────────┘
```
