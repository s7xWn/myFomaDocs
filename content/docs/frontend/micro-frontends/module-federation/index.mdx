---
title: Module Federation
---

— это механизм, позволяющий нескольким независимым JavaScript-приложениям динамически обмениваться модулями во время выполнения, без необходимости собирать их в один бандл. Изначально он был представлен в Webpack 5 и стал одним из ключевых инструментов для построения архитектуры микрофронтендов.

## Как это работает

Есть две роли:

- Remote — приложение, которое публикует свои модули.
- Host — приложение, которое подключает чужие модули.
