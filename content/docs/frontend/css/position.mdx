title: position
---

```css
position: [static | relative | absolute | fixed | sticky];
```

## static

— это значение свойства position в CSS по умолчанию для всех HTML-элементов. <br/>
Находится в обычном потоке документа; располагается сверху вниз так, как браузер рассчитывает автоматически.

не реагирует на свойства:

- top
- right
- bottom
- left
- z-index

## relative

> `position: relative` часто ставят родителю, чтобы внутри него работал `position: absolute`

— это способ сдвинуть элемент относительно его обычного места, не вырывая его из потока документа.

- место под элемент сохраняется
- другие элементы ведут себя так, будто он не двигался

## absolute

— это способ абсолютного позиционирования элемента на странице.

Выпадает из обычного потока документа (другие элементы ведут себя так, будто его нет);<br/>
Размещается относительно ближайшего родителя с `position` ≠ `static` (`relative`, `absolute`, `fixed`, `sticky`); Если такого родителя нет — позиционируется относительно всей страницы (`body`/`viewport`).

## fixed

— это способ закрепить элемент относительно окна браузера. Такой элемент остаётся на одном месте даже при прокрутке страницы.

Элемент «выпадает» из обычного потока документа; Координаты (`top`, `right`, `bottom`, `left`) считаются от окна браузера; При скролле он не двигается.

## sticky

— это способ “приклеить” элемент к краю контейнера при прокрутке.

Элемент ведёт себя сначала — как обычный (`position: relative`) <br/>
Когда страница доходит до заданной точки `top` — становится “липким”. Остаётся закреплённым, пока не закончится его родительский контейнер

`sticky` НЕ будет работать, если:

- Не указан `top`, `bottom`, `left` или `right`
- У родителя `overflow: hidden/auto/scroll`
- Родитель слишком маленький

```css
.header {
  position: sticky;
  top: 0;
}
```
