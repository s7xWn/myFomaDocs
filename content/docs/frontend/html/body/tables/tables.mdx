## `<table>`

HTML-тег для создания таблиц на веб-страницах.

:::note
Ширина таблицы по умолчанию подстраивается под контент внутри, если не задавать дополнительные CSS-свойства.
:::

Он нужен, когда данные имеют табличную структуру: строки и столбцы. <br/>
Встречая этот тег в разметке, браузер понимает, что дальше будет таблица.

Таблица состоит из строк и столбцов и предназначена для структурирования данных. Часто в таблицах размещают однотипные данные.

:::tip
В современной верстке `<table>` используют только для табличных данных. <br/>
Для построения макета страницы применяют CSS-инструменты вроде `flexbox` и `grid`, а не таблицы.
:::

В HTML элементы `<thead>`, `<tbody>` и `<tfoot>` не являются обязательными. <br/>
Они помогают логически разделить части таблицы - **семантическая разметка**. <br/>
Минимальная таблица может выглядеть так:

```html
<table>
  <tr>
    <th>Заголовок 1</th>
    <th>Заголовок 2</th>
  </tr>
  <tr>
    <td>Ячейка 1</td>
    <td>Ячейка 2</td>
  </tr>
  <tr>
    <td>Ячейка 3</td>
    <td>Ячейка 4</td>
  </tr>
</table>
```

Браузер при разборе такого **HTML** фактически создаст `<tbody>` автоматически в **DOM**:

```html
<table>
  <tbody>
    <tr>
      <th>Заголовок 1</th>
      <th>Заголовок 2</th>
    </tr>
    <tr>
      <td>Ячейка 1</td>
      <td>Ячейка 2</td>
    </tr>
    <tr>
      <td>Ячейка 3</td>
      <td>Ячейка 4</td>
    </tr>
  </tbody>
</table>
```

> Внимательно считайте количество ячеек в строках таблицы. Оно должно быть одинаковым. Особенно важно это делать, если растягиваете ячейки по горизонтали (`colspan`) или вертикали (`rowspan`). Не удивляйтесь, если снизу таблицы или сбоку в одной из строк внезапно будет торчать ячейка, нарушая красоту вашей таблицы. Вы просто где-то забыли удалить лишнюю ячейку.

## `<tr>` (table row) — строка

Создает строку.

## `<th>` (table header) — заголовочная ячейка

Создает ячейку-заголовок.

> По умолчанию браузер отображает текст в `<th>` жирным и по центру.

```html
<table>
  <tr>
    <th>Имя</th>
    <th>Возраст</th>
  </tr>
  <tr>
    <td>Иван</td>
    <td>25</td>
  </tr>
</table>
```

### `colspan`

— это атрибут HTML-таблиц, которые позволяют объединять ячейку по горизонтали (на несколько столбцов).

```
<td colspan="3">Ячейка, которая занимает 3 блока по горизонтали</td>
```

`colspan` не создаёт и не удаляет ячейки, а задаёт, на сколько колонок сетки таблицы растягивается конкретная ячейка; остальные `<td>` просто размещаются в следующих доступных позициях этой сетки.

```html
<tr>
  <td colspan="2">Иван Петров</td>
  <td>ivan@example.com</td>
  <td>Активен</td>
</tr>
```

```
+----------------------+------------------+------------------+
|        Имя           |      Email       |     Статус       |
+----------------------+------------------+------------------+
| Иван Петров                             | ivan@example.com | Активен          |
+----------------------+------------------+------------------+
| Анна Смирнова        | anna@example.com | Ожидает          |
+----------------------+------------------+------------------+
| Максим Козлов        | max@example.com  | Заблокирован     |
+----------------------+------------------+------------------+
```

<hr />

### `rowspan`

— это атрибут HTML-таблиц, которые позволяют объединять ячейку по вертикали (на несколько строк).


`rowspan` не создаёт и не удаляет ячейки, а задаёт, на сколько строк таблицы растягивается конкретная ячейка; остальные `<td>` просто размещаются в следующих доступных позициях этой сетки.

```html
<tr>
  <td rowspan="2">Иван Петров</td>
  <td>ivan@example.com</td>
  <td>Активен</td>
</tr>
```


## Семантическая структура

— это HTML-теги, которые используются для логической структуры таблицы (`<table>`). <br/>
Эти теги помогают лучше читать разметку сложных таблиц: структурные части таблицы друг от друга. Например: сложную шапку от тела с данными, и всё это — от результатов подсчёта в подвале.

> К тому же, правильно свёрстанная таблица может отобразиться в поисковике в виде сниппета.

```

┌───────────────┐
│ thead │ ← заголовки
├───────────────┤
│ tbody │ ← данные
│ tbody │
│ tbody │
├───────────────┤
│ tfoot │ ← итоги
└───────────────┘

```

```html
<table>
  <thead>
    <tr>
      <th>Название</th>
      <th>Количество</th>
      <th>Цена</th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <td>Ноутбук</td>
      <td>1</td>
      <td>1000$</td>
    </tr>
    <tr>
      <td>Мышь</td>
      <td>2</td>
      <td>20$</td>
    </tr>
    <tr>
      <td>Клавиатура</td>
      <td>1</td>
      <td>50$</td>
    </tr>
  </tbody>

  <tfoot>
    <tr>
      <td colspan="2">Итого</td>
      <td>1090$</td>
    </tr>
  </tfoot>
</table>
```

### `<caption>`

— это заголовок (подпись) таблицы. В заголовоке лучше всего написать обобщающую информацию.

Тег `<caption>` должен идти сразу после открывающего тега `<table>`. По умолчанию подпись визуально располагается сразу перед таблицей. Но её положением можно управлять при помощи свойства `caption-side`. Вне зависимости от визуального расположения подписи скринридер прочитает её перед таблицей.

Внутри тега можно располагать любые другие теги, нужные для группировки и оформления подписи.

<hr />

### `<thead>`

Содержит заголовок таблицы.

Внутри этого тега могут располагаться одна или более строк с заголовками таблицы. `<thead>` должен располагаться в разметке сразу за открывающим `<table>` или после `<caption>`, но строго до `<tbody>` и `<tfoot>`.

`<thead>` по своей семантике похож на тег `<header>`, только его «влияние» распространяется в пределах таблицы.

```html
<thead>
  <tr>
    <th>Имя</th>
    <th>Возраст</th>
  </tr>
</thead>
```

<hr />

### `<tbody>`

Содержит основную часть данных таблицы.

Внутрь него помещаются строки с данными. Можно использовать несколько `<tbody>` внутри таблицы, разделяя тем самым данные на отдельные блоки.

Этот тег схож по семантике с `<main>`, но в пределах таблицы.

```html
<tbody>
  <tr>
    <td>Иван</td>
    <td>25</td>
  </tr>
</tbody>
```

<hr />

### `<tfoot>`

Содержит итоговые или служебные данные внизу таблицы. <br/>
В таблице может быть только один блок `<tfoot>`.

Браузер всегда отрисовывает `<tfoot>` внизу таблицы, даже если этот блок идёт в разметке не последним (хоть это и не очень логично).<br/>
Если по какой-то причине вы не использовали в таблице `<thead>` или `<tbody>`, то футер будет отрисован после всех `<tr>`.

По семантике этот тег похож на `<footer>`, только в пределах таблицы.

```html
<tfoot>
  <tr>
    <td>Средний возраст</td>
    <td>30</td>
  </tr>
</tfoot>
```
