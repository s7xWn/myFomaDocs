title: <dl>
---

Контейнер всего списка определений.

- [`<ul>`](../ul) — список без порядка (маркированный список)
- [`<ol>`](../ol) — список с порядком (нумерованный список)
- `<dl>` — список "термин → описание"

```html
<dl>
  <dt>HTML</dt>
  <dd>Язык разметки для создания структуры веб-страниц.</dd>

  <dt>CSS</dt>
  <dd>Язык стилей для оформления внешнего вида веб-страниц.</dd>

  <dt>JavaScript</dt>
  <dd>Язык программирования для добавления интерактивности на сайты.</dd>
</dl>
```

## Где обычно используют `<dl>`

1. Словари и глоссарии

   ```html
   <dl>
     <dt>API</dt>
     <dd>Набор правил для взаимодействия программ.</dd>
   </dl>
   ```

2. Часто задаваемые вопросы (FAQ)
3. Метаданные или характеристики товара
