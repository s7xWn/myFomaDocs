---
title: <dt>
---

Термин (название, слово, понятие), которое нужно описать.

```html
<dl>
  <dt>HTML</dt>
  <dd>Язык разметки для создания структуры веб-страниц.</dd>

  <dt>CSS</dt>
  <dd>Язык стилей для оформления внешнего вида веб-страниц.</dd>

  <dt>JavaScript</dt>
  <dd>Язык программирования для добавления интерактивности на сайты.</dd>
</dl>
```
