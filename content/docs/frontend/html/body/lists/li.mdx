---
title: <li>
---

— (list item) это HTML-тег, который обозначает элемент списка. Он используется только внутри списков:

- [`<ul>`](./ul) — маркированный список (с точками или другими маркерами).
- [`<ol>`](./ol) — нумерованный список.

Внутри `<li>` можно размещать не только текст, но и другие HTML-элементы: ссылки, изображения, таблицы и даже вложенные списки.

Для тега `<li>` браузеры добавляют псевдоэлемент `::marker`, который выводит маркер или цифру, в зависимости от типа списка.
По умолчанию, в неупорядоченном списке [`<ul>`](./ul) это маркер в виде точки (`disc`), в упорядоченном списке [`<ol>`](./ol) — арабская цифра с точкой (`decimal`)

:::important
`<li>` нельзя использовать самостоятельно — он должен находиться внутри [`<ul>`](./ul), [`<ol>`](./ol) (или реже `<menu>`)
:::

## `value`

Значением `value` может быть любое целое положительное число

Можно установить номер пункта `<li>`, с которого начнётся нумерация списка (только для [`<ol>`](./ol))

```html
<ol>
  <li value="3">Белка</li>
  <li>Лиса</li>
  <li>Ёж</li>
</ol>
```

## `type`

С помощью атрибута `type` можно установить вид маркера. Значение будет зависеть от внешнего контейнера [`<ol>`](./ol) или [`<ul>`](./ul).

```html
<ul>
  <li type="disc">Белка</li>
  <li type="circle">Лиса</li>
  <li type="square">Ёж</li>
</ul>

<ol>
  <li type="A">Правила</li>
  <li>Тесты</li>
  <li>Ответы</li>
</ol>
```
