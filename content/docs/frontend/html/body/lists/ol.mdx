---
title: <ol>
---

— это тег для создания упорядоченного списка (ordered list). Элементы такого списка автоматически нумеруются. (1. , 2. , 3. и т.д.)

:::warning
Без элементов [`<li>`](./li) использовать `<ol>` не имеет смысла.

Дочерними тегами для тега `<ol>` могут быть исключительно теги [`<li>`](./li). Любые другие теги обязательно должны находиться внутри пунктов списка [`<li>`](./li).
:::

:::tip
Тег `<ol>` чаще всего используется для разметки нумерованных списков в тексте. Другой вариант использования часто можно увидеть на медиасервисах: упорядоченными списками свёрстаны плейлисты в музыкальной библиотеке.

## `type`

Изменяет тип нумерации

Возможные значения `type`:

`1` — числа (по умолчанию)
`A` — заглавные буквы (A, B, C)
`a` — строчные буквы (a, b, c)
`I` — римские цифры (I, II, III)
`i` — строчные римские цифры (i, ii, iii)

```html
<ol type="A">
  <li>Первый</li>
  <li>Второй</li>
</ol>
```

## `start`

Начинает нумерацию с другого числа (включительно это число)

```html
<ol start="5">
  <li>Пятый пункт</li>
  <li>Шестой пункт</li>
</ol>
```

## `reversed`

Обратная нумерация

```html
<ol reversed>
  <li>Третий</li>
  <li>Второй</li>
  <li>Первый</li>
</ol>
```
