— это элемент, который создает неупорядоченный список (unordered list). Обычно элементы такого списка отображаются с маркерами (●, ○, ■ и т. п.). <br/>
Тег `<ul>` является своеобразной обёрткой, указывающей браузеру на начало и конец списка. Сами пункты списка размечаются при помощи тега [`<li>`](./li). Таким образом, полностью список верстается с использованием обоих этих тегов.

:::warning
Без элементов [`<li>`](./li) использовать `<ul>` не имеет смысла.

Дочерними тегами для тега `<ul>` могут быть исключительно теги [`<li>`](./li). Любые другие теги обязательно должны находиться внутри пунктов списка [`<li>`](./li).
:::

:::tip
Неупорядоченным списком на сайтах, как правило, верстается навигация, рубрикаторы, пагинация, кнопки соцсетей в подвале и другие перечни однотипных элементов:
:::

## Примеры

Дочерними тегами обязательно должны быть [`<li>`](./li), в которые уже могут быть вложены любые другие теги.

<details>
<summary>Вложенный список</summary>

```html
<ul>
  <li>Молоко</li>
  <li>
    Хлеб
    <!-- В этот пункт вложен еще один полноценный список: -->
    <ul>
      <li>Белый</li>
      <li>Ржаной</li>
    </ul>
    <!-- Закрывающий тег родительского пункта: -->
  </li>
</ul>
```

</details>
