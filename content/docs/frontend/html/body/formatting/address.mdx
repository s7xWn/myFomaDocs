— это HTML-тег, который используется для указания контактной информации о человеке, организации или авторе страницы.

:::danger
Тег `<address>` влияет не столько “магически на позиции”, сколько через семантику, а это важно и для **SEO**, и для доступности.
:::

:::note
По умолчанию содержимое тега `<address>` выделяется на вёрстке курсивом.
:::

Тег `<address>` обычно содержит:

- имя автора или владельца сайта,
- почтовый адрес,
- email,
- телефон,
- ссылки на контактные страницы.

:::important
Обычно относится к ближайшему разделу (статье, странице или сайту в целом).
:::

:::warning
Есть ряд ограничений на содержимое тега `<address>`:

- Нельзя вкладывать теги `<address>` друг в друга.
- Нельзя вкладывать в параграф с текстом, это не фразовый элемент.
- Внутри нельзя использовать заголовки, секционные теги (`<section>`, `<article>`, `<aside>`, `<nav>`), а также теги `<header>` и `<footer>`.

:::

### SEO: Комбинация с `Schema.org`

Лучший эффект даёт связка: семантический HTML (`<address>`) + структурированные данные (`Schema.org`) <br/>
Они не конкурируют — они усиливают друг друга.

Пример правильной комбинации:

```html
<footer>
  <address>
    <strong>ACME Sp. z o.o.</strong><br />
    ul. Marszałkowska 10<br />
    00-001 Warszawa, Polska<br />
    Email: kontakt@acme.pl<br />
    Tel: +48 123 456 789
  </address>
</footer>
```

Добавляется в `<head>` или внизу страницы:

```html
<script type="application/ld+json">
  {
    "@context": "https://schema.org",
    "@type": "Organization",
    "name": "ACME Sp. z o.o.",
    "url": "https://acme.pl",
    "address": {
      "@type": "PostalAddress",
      "streetAddress": "ul. Marszałkowska 10",
      "postalCode": "00-001",
      "addressLocality": "Warszawa",
      "addressCountry": "PL"
    },
    "email": "kontakt@acme.pl",
    "telephone": "+48 123 456 789"
  }
</script>
```

Когда у тебя есть и `<address>`, и `Schema`:

1. **Google** получает 2 уровня понимания: HTML (“человеческий” смысл) + Schema (“машинная” структура)
2. Улучшение локального SEO
   - Google Business Profile
   - “near me” запросов
   - карточек организаций

   Schema помогает попасть в:
   - knowledge panel
   - расширенные сниппеты
   - корректное отображение адреса

3. Меньше ошибок интерпретации
   Без Schema Google может: неправильно понять адрес, спутать контакты с обычным текстом
