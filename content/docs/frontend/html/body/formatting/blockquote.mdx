title: <blockquote>
---

— это HTML-тег, который используется для оформления **большых** цитат.

> Для цитаты, которая скрывается в дебрях текста (внутристрочная) есть свой отдельный тег — `<q>`

Используйте `<blockquote>`, если:

- цитируете несколько предложений или целый абзац;
- текст взят из внешнего источника.

Для обычного текста внутри `<blockquote>` рекомендуется использовать `<p>`, так как это делает разметку более семантичной и удобной для дальнейшей стилизации:

```html
<blockquote>
  <p>
    Ваша работа заполнит большую часть жизни и единственный способ быть
    полностью довольным — делать то, что по-вашему является великим делом. И
    единственный способ делать великие дела — любить то, что вы делаете.
  </p>
</blockquote>
```

## `cite`

Атрибут `cite` содержит URL источника цитаты. Он предназначен для машинной обработки и обычно не отображается пользователю.

```html
<blockquote cite="https://example.com/article">
  <p>Ваша работа заполнит большую часть жизни...</p>
</blockquote>
```

## `<cite>`

В тег `<cite>` помещают название произведения или источника, из которого взята цитата.<br/>
Обычно источник цитаты размещают за пределами тега `<blockquote>`, а URL источника при необходимости указывают в атрибуте cite тега `<blockquote>`.

По умолчанию браузеры обычно отображают содержимое `<cite>` курсивом.<br/>
Если нужно сделать источник кликабельным, внутри `<cite>` можно использовать тег `<a>`.

```html
<blockquote cite="https://example.com/article">
  <p>Ваша работа заполнит большую часть жизни...</p>
</blockquote>

<p>— <cite>Речь Стива Джобса в Стэнфорде</cite></p>
```
