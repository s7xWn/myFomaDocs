title: <!DOCTYPE>

— это специальная декларация в HTML-документе, которая сообщает браузеру, в каком стандарте HTML написана страница.

Браузер использует `<!DOCTYPE>` чтобы понять, как правильно интерпретировать HTML и CSS.
Без неё он может перейти в так называемый quirks mode (режим совместимости), где поведение страницы становится непредсказуемым и может напоминать старые браузеры.

:::note
`<!DOCTYPE>` всегда ставится самой первой строкой в HTML-файле, даже до `<html>`
:::

Есть несколько исторических версий HTML, включая специальную — XHTML.
Все они обозначались своими доктайпами и их вариациями, которые вы можете встретить в старом коде.

<hr />

## Современный вариант (HTML5)

Сегодня почти всегда используется самый простой вариант, говорит браузеру: «используй современный стандарт HTML5»:

```html
<!DOCTYPE html>
```

<hr />

## HTML 3.2

```html
<!DOCTYPE html PUBLIC "-//W3C//DTD HTML 3.2 Final//EN">
```

Очень старый стандарт HTML (примерно 1997 год).

Особенности:

- Почти нет строгой структуры
- Много устаревших тегов (например `<font>`, `<center>`)
- Нет CSS как обязательного элемента

<hr />

## HTML 4.01 Transitional

```html
<!DOCTYPE html PUBLIC "-//W3C//DTD HTML 4.01 Transitional//EN" "http://www.w3.org/TR/html4/loose.dtd">
```

HTML 4.01 в «переходном» (Transitional) режиме. Transitional позволял:

- использовать старые теги (как в HTML 3.2)
- постепенно переходить на CSS

Особенности:

- Частично строгий, но с «послаблениями»
- Поддерживал устаревшие элементы ради совместимости

<hr />

## XHTML 1.0 Strict

```html
<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Strict//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-strict.dtd">
```

XHTML — это HTML, но написанный по правилам XML.

Strict означает:

- нельзя использовать устаревшие теги (например `<font>`)
- обязательна строгая структура XML
- теги должны быть правильно закрыты:
  ```html
  <br />
  <!-- обязательно закрытие -->
  <img src="a.jpg" alt="a" />
  ```

Особенности:

- очень строгий синтаксис
- ошибки ломают страницу (в отличие от HTML)
