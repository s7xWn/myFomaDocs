В HTML тег `<head>` — это раздел документа, который содержит служебную информацию о странице, а не сам видимый контент. Браузер использует данные из `<head>` для правильной загрузки и отображения страницы.

## title - название страницы

```html
<title>Мой сайт</title>
```

Показывается во вкладке браузера.

## meta - метатеги (информация о странице)

Метатеги (`<meta>`) в HTML — это специальные теги внутри `<head>`, которые передают служебную информацию о веб-странице браузерам, поисковым системам и другим сервисам. Они не отображаются на странице, но влияют на её работу, SEO и отображение.

```html
<meta charset="UTF-8" />
<meta name="description" content="Описание сайта" />
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

### charset - Кодировка страницы

```html
<meta charset="UTF-8" />
```

Указывает кодировку текста страницы.
UTF-8 — самая распространённая кодировка, поддерживает почти все языки.

### description - Описание страницы

```html
<meta name="description" content="Сайт о программировании и веб-разработке" />
```

Краткое описание сайта. <br/>
📌 Используется поисковыми системами и может показываться в результатах поиска.

### keywords - Ключевые слова

```html
<meta name="keywords" content="HTML, CSS, JavaScript, программирование" />
```

Список ключевых слов страницы.
⚠️ Сейчас почти не используется поисковыми системами.

### author - Автор страницы

```html
<meta name="author" content="Иван Иванов" />
```

Указывает автора сайта или страницы.

### viewport - Адаптация под мобильные устройства

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

Очень важный метатег для адаптивных сайтов. Он говорит браузеру:

- ширина страницы = ширина экрана устройства
- начальный масштаб = 1

Без него сайт может плохо выглядеть на телефонах.

### Обновление страницы / редирект

Страница обновится через 5 секунд.

```html
<meta http-equiv="refresh" content="5" />
```

Редирект.

```html
<meta http-equiv="refresh" content="5; url=https://example.com" />
```

Используется:

- Автоматическое обновление данных
  - табло с результатами
  - мониторинг серверов
  - страницы со статистикой
- Автоматический редирект
- Страницы после действий пользователя
  - отправки формы
  - регистрации <br/>
    _("Спасибо за регистрацию. Через 5 секунд вы будете перенаправлены на главную страницу.")_
  - оплаты
- В старых или очень простых сайтах <br/>
  Раньше этот способ редиректа применяли вместо: JavaScript,
  серверных редиректов (301 / 302).
  Сейчас используется реже.

## script - подключение скриптов
