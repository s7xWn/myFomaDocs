title: Test Management System
---

Test Management System (TMS) — система для хранения, организации и отслеживания тестов.

## Что обычно можно делать в TMS

- Создавать тест-кейсы — пошаговые инструкции, как проверить функцию.
- Составлять тестовые наборы (test suites) — объединять тесты по функциональности, релизу и т. д.
- Запускать тесты и отмечать результат: Passed, Failed, Blocked, Skipped.
- Связывать тесты с багами — например, если тест упал, создать или привязать соответствующий defect.
- Смотреть отчёты — сколько тестов пройдено, сколько упало, какой процент покрытия.
- Распределять тестирование между QA.
- Связывать требования → тест-кейсы → результаты → баги, чтобы понимать, что именно проверено.

## Примеры программ

| Программа          | Для чего используется                                       | Интеграция с Jira | Кому подходит                             |
| ------------------ | ----------------------------------------------------------- | ----------------- | ----------------------------------------- |
| **TestRail**       | Тест-кейсы, тест-раны, отчёты, результаты тестирования      | ✅                | QA-командам разного размера               |
| **Xray**           | Управление тестированием непосредственно в Jira             | ✅ Отличная       | Командам, которые активно используют Jira |
| **Zephyr**         | Тест-кейсы, тест-циклы, отчётность                          | ✅                | Agile/Scrum-командам                      |
| **qTest**          | Управление большими объёмами тестирования и автоматизацией  | ✅                | Крупным компаниям                         |
| **PractiTest**     | Тест-кейсы, требования, баги, отчёты                        | ✅                | Средним и крупным QA-командам             |
| **Allure TestOps** | Управление тестами и результатами автоматизированных тестов | ✅                | Командам с большим количеством автотестов |
| **Testmo**         | Test management + manual testing + automation               | ✅                | Современным QA-командам                   |
| **Testiny**        | Управление тест-кейсами и тестовыми запусками               | ✅                | Небольшим и средним командам              |
