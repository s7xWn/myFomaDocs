---
title: HTTP/S Proxy
---

HTTP Proxy (HTTP-прокси) — это посредник между твоим приложением и интернетом, через который проходят HTTP/HTTPS-запросы.

```
Без Proxy:

Приложение ────────────────→ Сервер
            Internet


С Proxy:

Приложение ───→ HTTP Proxy ───→ Сервер
                    │
                    ↓
                 анализ
```

<hr />

## Сравннение платных аналогов

**Charles**, **Proxyman** и **Fiddler**

Если коротко: все три решают одну базовую задачу — перехватывать и анализировать HTTP/HTTPS-трафик, но философия у них разная.

- Proxyman — мой выбор для macOS/iOS-разработки.
- Charles — универсальный и очень проверенный вариант для ручного дебага web/mobile.
- Fiddler Everywhere — сильнее, если нужны API testing, сложные правила, replay, командная работа и разные ОС.

<hr />

## Сравннение бесплатных аналогов

**HTTP Toolkit** и **mitmproxy**

- HTTP Toolkit — удобнее для ручного дебага
- mitmproxy — мощнее для автоматизации, скриптов и сложных сценариев перехвата.
