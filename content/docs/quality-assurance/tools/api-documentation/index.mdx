## OpenAPI

OpenAPI — это открытый стандарт для описания REST API в машиночитаемом формате. Он позволяет точно определить, какие эндпоинты есть у API, какие параметры они принимают, что возвращают и как с ними работать.

<details>
  <summary>Пример</summary>

Вместо того чтобы описывать API только словами:

> **GET** `/users/{id}` возвращает пользователя по ID

В OpenAPI это выглядит примерно так:

```yaml
openapi: 3.1.0
info:
  title: Users API
  version: 1.0.0

paths:
  /users/{id}:
    get:
      summary: Получить пользователя
      parameters:
        - name: id
          in: path
          required: true
          schema:
            type: integer
      responses:
        "200":
          description: Успешный ответ
          content:
            application/json:
              schema:
                type: object
                properties:
                  id:
                    type: integer
                  name:
                    type: string
```

</details>
