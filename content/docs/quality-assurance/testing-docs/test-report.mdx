## Отчёт о тестировании (Test Report)

— это документ, в котором подводятся итоги проведённого тестирования программного обеспечения.
Он показывает, что было протестировано, каковы результаты, какие дефекты обнаружены и готов ли продукт к выпуску.

Этот документ используют тестировщики, менеджеры проектов, разработчики и заказчики для оценки качества продукта и принятия решения о релизе.

### Основные разделы Test Report

1. Общая информация
   - название проекта;
   - версия продукта;
   - дата тестирования;
   - автор отчёта.

2. Цель тестирования
   - зачем проводилось тестирование;
   - какие задачи проверялись.

3. Объём тестирования (Scope)
   - что было протестировано;
   - что не вошло в тестирование (если применимо).

4. Тестовая среда
   - операционная система;
   - браузеры;
   - устройства;
   - версии ПО;
   - серверы и базы данных.

5. Выполненные тесты

   Например:
   - всего тест-кейсов — 250;
   - выполнено — 245;
   - успешно пройдено — 235;
   - не пройдено — 10;
   - заблокировано — 5.

6. Найденные дефекты

   Обычно указывают:
   - количество багов;
   - распределение по приоритету или серьёзности.

     | Severity | Количество |
     | -------- | ---------: |
     | Critical |          2 |
     | High     |          5 |
     | Medium   |          8 |
     | Low      |         12 |

7. Основные проблемы и риски
   - Перечисляются наиболее важные дефекты и возможные последствия для пользователей.

8. Выводы и рекомендации

   Например:
   - продукт готов к релизу;
   - релиз возможен после исправления критических ошибок;
   - требуется повторное тестирование.
