## Тест-кейс (Test Case)

— это документ с четким описанием того, что нужно проверить, как это сделать и какой результат ожидается.
Он помогает тестировщикам убедиться, что функциональность приложения работает правильно.

Обычно тест-кейс включает:

- ID — уникальный номер (например, TC-001).
- Название — краткое описание проверки.
- Предусловия — что должно быть выполнено до начала теста.
- Шаги — последовательность действий.
- Тестовые данные — логины, пароли, значения полей и т.д.
- Ожидаемый результат — что должно произойти после выполнения шагов.
- Фактический результат — что произошло на самом деле (заполняется после выполнения).
- Статус — Passed, Failed, Blocked и т.д.

### Виды тест-кейсов

В практике встречаются разные типы:

- Позитивные — проверяют корректную работу при правильных данных.
- Негативные — проверяют реакцию системы на неверные данные или ошибки пользователя.
- Граничные — проверяют значения на границах допустимого диапазона.
- Регрессионные — убеждаются, что после изменений старый функционал продолжает работать.
- Smoke-тесты — быстро проверяют основные функции после новой сборки.

### Пример

Название: Проверка успешного входа в систему.

Предусловия:

- Пользователь зарегистрирован.
- Есть действующий логин и пароль.

Шаги:

1. Открыть страницу входа.
2. Ввести корректный логин.
3. Ввести корректный пароль.
4. Нажать кнопку «Войти».

Ожидаемый результат:

- Пользователь успешно входит в систему.
- Открывается главная страница.
- Отображается имя пользователя.

### Отличие от чек-листа

| Чек-лист                                  | Тест-кейс                                  |
| ----------------------------------------- | ------------------------------------------ |
| Краткий список проверок                   | Подробная инструкция проверки              |
| Содержит только пункты проверки           | Содержит шаги, данные, ожидаемый результат |
| Быстрее создавать и выполнять             | Требует больше времени на подготовку       |
| Подходит для регрессии и быстрых проверок | Подходит для детального тестирования       |

Чек-лист:

- ☐ Проверить авторизацию с неверным паролем

Тест-кейс:

1. Открыть страницу входа
2. Ввести существующий логин
3. Ввести неправильный пароль
4. Нажать кнопку "Войти"
5. Ожидаемый результат: появляется сообщение "Неверный пароль"
